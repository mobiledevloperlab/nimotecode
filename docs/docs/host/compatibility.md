# Nimote Connect package compatibility

Choose a package for the development computer’s operating system and CPU architecture. App-guided installation is available on macOS and Linux; install directly on Windows. Version 1.2.0 provides CLI packages for all six targets. Choose a GUI package only if the release includes one for the computer.

| Computer target | CLI archive type |
| --- | --- |
| `darwin-amd64` | `.tar.gz` |
| `darwin-arm64` | `.tar.gz` |
| `linux-amd64` | `.tar.gz` |
| `linux-arm64` | `.tar.gz` |
| `windows-amd64` | `.zip` |
| `windows-arm64` | `.zip` |
