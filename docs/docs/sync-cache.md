# Sync and Cache

<div class="doc-section">
<div class="doc-section__copy">

## Select a transfer direction

**Sync** transfers local project content to a remote workspace. **Cache** brings remote content to local storage. Confirm the connection and displayed path before starting. Sync / Cache requires Pro access.

## Start and verify a transfer

Use **Change** if the displayed location is not the intended project, then start the operation. Review the result and recent history after completion. Resolve which copy should be authoritative before transferring files; cache history is not a substitute for version control or backups.
