## Your first five minutes

1. Open a local project, add a Remote Explorer SSH profile, or install Local Linux on a supported Android device.
2. Open a file, make a small edit and save it.
3. Run `pwd`, `ls`, or your project test command to verify the workspace.
4. Configure an AI provider only if you want AI Chat or AI Agent.
