# IDE de Android para codificación SSH, Git y AI


Android puede ser más que un dispositivo para comprobar servidores. Con las herramientas adecuadas, se convierte en un entorno práctico para el trabajo de desarrollo: conéctese a través de SSH a su propia máquina de desarrollo, abra el repositorio, realice un cambio específico y verifíquelo, todo desde un teléfono o tableta.


NimoteCode es un **IDE de Android** creado en torno a ese flujo de trabajo. Combina un Explorer, un editor de código, un terminal SSH, una revisión de Git, un LSP, un depurador y un chat y agente AI en un espacio de trabajo móvil, por lo que Android se convierte en una forma práctica de seguir trabajando en proyectos que aún se encuentran en su computadora de escritorio, portátil o servidor.

## Qué debe hacer un IDE de Android


Un IDE de Android debe mantener todo el ciclo en un solo lugar: comprender el proyecto, editar un archivo, ejecutar un comando, obtener una vista previa del resultado y revisar lo que se enviará. Esto es diferente de un editor de código independiente para archivos locales y diferente de un cliente SSH que solo muestra texto de shell. El proyecto, la terminal y el historial de Git pertenecen al mismo espacio de trabajo.


## Cuando es útil


- Estás lejos de tu computadora portátil y necesitas investigar o arreglar un servicio.

- Quieres revisar una diferencia y enviar un pequeño cambio desde un teléfono o tableta.

- Te conectas a tu Mac, Linux o servidor a través de SSH y quieres el editor y la vista Git al lado del terminal.

- Quiere ayuda de IA que lea el proyecto real en lugar de un fragmento pegado.


## Cómo encaja NimoteCode


Conéctese a su máquina de desarrollo con un [espacio de trabajo SSH](/docs/ssh) y seleccione la raíz del proyecto. El proyecto permanece en el host remoto; Los archivos y la salida del terminal viajan a través de la conexión SSH, por lo que nunca necesitará sincronizar una copia con el dispositivo. Para un proyecto almacenado en el dispositivo, el Explorador local funciona de la misma manera.


## Un flujo de trabajo real en Android


1. Guarde un perfil SSH para su host de desarrollo y abra la raíz del proyecto.

2. Busque el archivo relevante en el Explorador en lugar de memorizar rutas.

3. Realiza el cambio seguro más pequeño en el editor.

4. Ejecute el comando de prueba, compilación o registro relevante en [Terminal](/docs/terminal).

5. Inspeccione los [cambios de Git](/docs/source-control) antes de confirmar o entregar.

6. Pídale a [AI Chat and Agent](/docs/ai) que le explique el código o planifique el siguiente paso cuando sea necesario.


## Características relevantes para el desarrollo de Android


- **Espacio de trabajo SSH**: exploración y edición remota de proyectos con manejo consciente de la reconexión.

- **Editor**: edición con pestañas con paneles divididos en pantallas más grandes y entrada compatible con teclado móvil.

- **Terminal**: sesiones de comando con contexto de proyecto y búsqueda de resultados.

- **Git** — inspecciona el estado, las diferencias y el historial; flujos de trabajo de escritura cerrados con Pro.

- **AI Chat and Agent**: asistencia basada en el espacio de trabajo con ejecución orientada a la confirmación.

- **LSP y depuración**: servidores de idiomas y adaptadores de depuración configurados en el host remoto.


## Limitaciones de un IDE de Android


Android no puede reemplazar un escritorio para cada tarea. La compilación local pesada, las refactorizaciones largas de múltiples archivos y la depuración de múltiples monitores son aún más cómodas en una computadora. El trabajo remoto a través de SSH depende de una conexión estable con el host, y el host hace el trabajo pesado: un teléfono no puede compensar un servidor con poca potencia. NimoteCode se enfoca en momentos enfocados y de alto valor: correcciones, revisiones, trabajo de guardia y pequeñas funciones.
