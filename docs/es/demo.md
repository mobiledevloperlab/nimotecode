# Demostración de NimoteCode: un flujo de trabajo de desarrollo móvil real


La demostración de NimoteCode muestra el flujo de trabajo para el que está diseñado el producto: pasar de una conexión SSH remota a la inspección de proyectos, edición de código, verificación de terminales, revisión de Git y asistencia de IA sin cambiar las herramientas.

## Lo que muestra la demostración


### 1. Abrir un espacio de trabajo de desarrollo móvil


NimoteCode comienza desde el proyecto, no desde un símbolo del sistema independiente. Utilice Local Explorer para un proyecto en el dispositivo o conéctese a un host remoto a través de [SSH Workspace](/docs/ssh). El Explorador y el editor mantienen los archivos detrás de una tarea visibles y accesibles.


### 2. Inspeccionar y editar el código.


Abra el archivo afectado, siga el código cercano a través de las pestañas del editor y realice un cambio específico. El objetivo no es escribir una función importante en un teléfono; es hacer posible el trabajo urgente o bien previsto cuando no hay una computadora portátil disponible.


### 3. Ejecutar comandos de terminal en contexto


Utilice Terminal para inspeccionar registros, ejecutar pruebas, comprobar el estado del servicio o validar la edición. Debido a que la terminal vive en el mismo espacio de trabajo, el código y la salida permanecen conectados. Consulte [Terminal](/docs/terminal) para obtener detalles operativos.


### 4. Revisa Git antes de realizar el envío


El flujo de trabajo finaliza con un cambio revisable. [Control de fuente](/docs/source-control) coloca diferencias, preparación, confirmaciones y contexto de rama junto a los archivos que editaste. Esto es lo que separa una solución rápida de shell de un ciclo de desarrollo controlado.


### 5. Pídale ayuda a la IA con la próxima decisión


AI Chat puede ayudar a explicar el código o la salida de error. AI Agent puede ayudar en tareas controladas de varios pasos. En ambos casos, el espacio de trabajo real sigue siendo la fuente de la verdad y usted debe revisar los comandos y cambios propuestos antes de aplicarlos.


## Para quién es este flujo de trabajo


La demostración es especialmente relevante para desarrolladores, ingenieros de DevOps y personal de guardia que necesitan inspeccionar, arreglar o revisar un proyecto real desde un teléfono o tableta. Explore [Mobile IDE](/mobile-ide), [SSH IDE](/ssh-ide) y [Mobile AI Coding](/mobile-ai-coding) para conocer los casos de uso detrás del flujo de trabajo.
