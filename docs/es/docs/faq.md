# Preguntas frecuentes sobre NimoteCode


## ¿NimoteCode es solo un cliente SSH?


No. NimoteCode puede abrir un proyecto local, usar Android Local Linux o conectarse a un espacio de trabajo SSH, y reúne el Explorador, el Editor, la Terminal, los flujos de trabajo de Git, la asistencia de IA y los paneles de diagnóstico en el mismo contexto del proyecto.


## ¿Puedo usarlo sin Pro?


Sí. Gratis incluye espacios de trabajo locales, Android Local Linux y SSH, el editor, terminal básico, AI Chat y tareas básicas. Linux local requiere Android 8+ en un dispositivo ARM64 o x86_64 de 64 bits y no está disponible en iOS. AI Agent y la búsqueda remota están disponibles a través de Early Access Pro a medida que se amplía la disponibilidad. Consulte [Pro](/pro) para conocer los flujos de trabajo cerrados.


## ¿Qué proveedores de IA puedo configurar?


La aplicación incluye 14 plantillas de proveedores integradas y admite puntos finales personalizados compatibles. La disponibilidad del proveedor, el acceso al modelo y el costo están determinados por su propia cuenta y configuración de proveedor. Consulte [Configuración](/docs/configuration).


## ¿Qué admite el control de código fuente?


Source Control permite a cada usuario inspeccionar el estado, las diferencias y el historial del repositorio. Se requiere Pro para flujos de trabajo de escritura Git cerrados, como confirmaciones, envíos y acciones ocultas. Lea [Control de fuente](/docs/source-control).


## ¿Las tareas son locales o remotas?
Las 

Tasks están diseñadas para flujos de trabajo de comandos repetibles en un espacio de trabajo SSH. Aclare el host, la raíz del proyecto y el riesgo de cada comando antes de ejecutarlo.


## ¿LSP y Debug funcionan para todos los proyectos?


Dependen de que se configure un servidor de idioma compatible o un adaptador de depuración en el host remoto y de la configuración del proyecto. Son flujos de trabajo Pro; consulte [LSP](/docs/lsp) y [Depurar](/docs/debug).
