# Compatibilidad de paquetes de Nimote Connect

Elige según el sistema operativo y la CPU del equipo de desarrollo. La instalación guiada funciona en macOS y Linux. En Windows, instala directamente en el equipo. La versión 1.2.0 ofrece paquetes CLI para los seis destinos. Elige GUI solo si esa versión incluye un paquete para el equipo.

| Destino del equipo | Archivo CLI |
| --- | --- |
| `darwin-amd64` | `.tar.gz` |
| `darwin-arm64` | `.tar.gz` |
| `linux-amd64` | `.tar.gz` |
| `linux-arm64` | `.tar.gz` |
| `windows-amd64` | `.zip` |
| `windows-arm64` | `.zip` |
