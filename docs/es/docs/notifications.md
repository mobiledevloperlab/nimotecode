# Notificaciones


 Aparecen notificaciones completadas o actividad en el espacio de trabajo que merece atención en el dispositivo. Utilice la notificación como señal para regresar al espacio de trabajo relevante y luego verifique el host activo, el directorio y el resultado antes de realizar la siguiente acción.


<ImagePlaceholder image-key="notifications" alt="Notifications on NimoteCode for phone">
  <strong>Workspace notifications</strong>
</ImagePlaceholder>

## Un flujo de trabajo de notificación seguro


1. Abra el espacio de trabajo relacionado en lugar de asumir que la notificación refleja el estado remoto actual.

2. Compruebe el host activo y el directorio del proyecto.

3. Lea el resultado del terminal, tarea o agente en contexto.

4. Revise cualquier comando propuesto o cambio de archivo antes de aplicarlo.


Para el trabajo de rutina, mantenga los nombres de [Tareas](/docs/tasks) y [Terminal](/docs/terminal) explícitos para que una notificación sea fácil de interpretar en una pantalla pequeña.
