# Notificaciones

## Abrir la actividad relacionada

Las notificaciones indican actividades del espacio de trabajo que han terminado o requieren atención. Abra el espacio correspondiente y consulte la tarea, la cronología de Agent o la salida del terminal. Una notificación no comprueba el estado actual del host remoto.

## Identificar las sesiones

Asigne nombres descriptivos a las [pestañas del terminal](/es/docs/terminal) y las [tareas](/es/docs/tasks) para asociar cada actividad con su proyecto. Después de reconectar, confirme el host y el directorio antes de continuar.
