## Tus primeros cinco minutos


1. Abra un proyecto local, agregue un perfil SSH de Explorador remoto o instale Linux local en un dispositivo Android compatible.

2. Abra un archivo, realice una pequeña edición y guárdelo.

3. Ejecute `pwd`, `ls` o el comando de prueba de su proyecto para verificar el espacio de trabajo.

4. Configure un proveedor de IA solo si desea AI Chat o AI Agent.
