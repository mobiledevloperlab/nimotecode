## Agregado recientemente al espacio de trabajo

- **[Un espacio de trabajo personalizable.](/es/docs/plugins)** Plugin Center permite gestionar capacidades y crear complementos con paneles, formularios, flujos de trabajo, vistas de artefactos y trabajos de script locales o SSH. Revise los cambios de permisos antes de instalar o actualizar.
- **[Colaboración continua con Agent.](/es/docs/ai)** Añada instrucciones de seguimiento a un Agent activo, responda preguntas interactivas y siga trabajos largos con vistas renovadas de contexto, historial, edición de prompts y cronología.
- **[Git, terminal y conexiones más directos.](/es/docs/source-control)** Busque, cree y cambie ramas desde el encabezado de Git; envíe salida de terminal a AI cuando necesite interpretarla. Los espacios SSH también admiten proxies SOCKS5 y HTTP CONNECT.


- **[Directorios de espacio de trabajo flexibles.](/es/docs/ssh)** Los proyectos locales y SSH pueden cambiar a otro directorio y conservar ubicaciones recientes para un retorno rápido.

- **[Confiabilidad de Android Local Linux.](/es/docs/local-linux)** El entorno Ubuntu ahora tiene límites de acceso a archivos más claros y una configuración más confiable, Git y manejo de archivos de tareas. Estas mejoras se aplican sólo a Android.

- **[Un bucle de vista previa más completo.](/es/docs/editor)** La edición dividida, las instantáneas HTML en vivo, la vista previa de medios integrada y la apertura de enlaces compartidos hacen que sea práctico inspeccionar un resultado antes de abandonar el espacio de trabajo.

- **[Flujos de trabajo de agentes que se adaptan a su entorno.](/es/docs/ai)** Los tiempos de ejecución de ACP externos, la finalización de comandos de barra diagonal, el manejo del entorno de inicio de sesión SSH compartido y los diagnósticos de entornos seguros mantienen alineados Terminal, Tareas, Depuración, servidores de idiomas, Git y agentes.


## Una forma práctica de utilizar las funciones


1. Conéctese a través de [SSH Workspace](/docs/ssh), abra un proyecto local o use [Android Local Linux](/docs/local-linux) en un dispositivo compatible.

2. Localice y edite el archivo en [Editor](/docs/editor).

3. Verifíquelo en [Terminal](/docs/terminal); salida de búsqueda o contenido remoto cuando sea necesario.

4. Pídale a [AI Chat y Agente](/docs/ai) que explique un error o planifique un cambio.

5. Utilice [Control de fuente](/docs/source-control) para revisar el resultado; Se requiere Pro cuando el paso de entrega necesita una acción de escritura Git cerrada.


> Las funciones tienen en cuenta deliberadamente los permisos y el entorno. Por ejemplo, LSP y Debug dependen del servidor de idioma o del adaptador de depuración que se configure en el host remoto, y la salida de AI debe revisarse antes de usarse en sistemas sensibles.
