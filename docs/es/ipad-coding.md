# Codificación de iPad con un espacio de trabajo de desarrollo real


Un iPad te ofrece más espacio en la pantalla que un teléfono, pero la codificación desde el iPad sigue funcionando mejor cuando el espacio de trabajo está diseñado para ello. Necesita una manera fácil de moverse entre el árbol del proyecto, el código, la salida del terminal y los cambios de Git sin perder el hilo de la tarea.


NimoteCode reúne esas herramientas en iPad como un **Espacio de trabajo de desarrollo de IA móvil**: Editor + Explorador + SSH + Terminal + Git + Chat y agente de IA. Está disponible en la App Store con el mismo conjunto de funciones que la versión de Android.

## Un ciclo de codificación productivo para iPad


### Usa la pantalla más grande para ver el contexto


Comience desde el Explorador para mantener visible la estructura del proyecto, luego abra los archivos relacionados en las pestañas del editor. En una tableta, ese espacio visual adicional hace que sea más fácil seguir una ruta de código o comparar un cambio de configuración con la salida del comando que lo motivó.


### Mantener el entorno remoto cerca


Conéctese a un proyecto con [SSH Workspace](/docs/ssh), luego use Terminal para los comandos que validan su comprensión: pruebas, comprobaciones de registros, resultados de compilación o estado del servicio. No es necesario convertir el iPad en un reemplazo de escritorio para que una tarea breve y enfocada tenga sentido.


### Revisar antes de enviar


Utilice [Git y control de código fuente](/docs/source-control) para inspeccionar la diferencia producida por su edición. Esto es particularmente útil para la codificación de iPad porque cierra el ciclo dentro del mismo espacio de trabajo en lugar de hacer que la revisión sea una ocurrencia tardía.


## Dónde encaja la IA


AI es más útil cuando tiene un trabajo claro: explicar un módulo desconocido, convertir un error en un plan de depuración o proponer el siguiente pequeño cambio. [AI Chat y Agent](/docs/ai) están integrados con el espacio de trabajo de desarrollo para que la conversación pueda permanecer conectada al archivo y la tarea reales. Mantenga habilitada la revisión de comandos y cambios para trabajo remoto o de producción.
