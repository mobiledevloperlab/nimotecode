# Codificación de IA móvil que permanece conectada al trabajo


La codificación de IA móvil debería ser más que enviar un fragmento de código pegado a un chatbot. La respuesta resulta útil cuando puedes inspeccionar el proyecto, aplicar un cambio enfocado, ejecutar un comando y revisar la diferencia sin perder el contexto.


NimoteCode coloca AI Chat y AI Agent dentro de un **Espacio de trabajo de desarrollo de AI móvil** con Editor, Explorer, SSH, Terminal y Git. Eso significa que la IA puede respaldar la tarea donde ocurre, ya sea que el espacio de trabajo sea local o esté conectado a un host remoto.

## AI Chat para comprensión y planificación


Utilice AI Chat cuando desee mantener el control de los pasos: explicar un error, aclarar una función, trazar una refactorización o preparar un plan de prueba. El archivo activo y el espacio de trabajo constituyen un mejor punto de partida que un fragmento copiado, y puede pasar de la explicación directamente al editor o terminal.


## AI Agente para trabajo controlado de varios pasos


AI Agent es para tareas que naturalmente abarcan varias acciones: inspeccionar archivos relevantes, proponer ediciones, ejecutar una verificación y resumir el resultado. No es motivo para saltarse la revisión. NimoteCode está diseñado con ejecución controlada y flujos de trabajo orientados a la confirmación para que pueda inspeccionar comandos y cambios, especialmente en espacios de trabajo SSH remotos.


Para conocer la disponibilidad de funciones y la configuración del proveedor, consulte [Chat y agente AI](/docs/ai) y [Seguridad y protección](/docs/security).


## Por qué es importante el espacio de trabajo circundante


| AI coding need | Mobile workspace advantage |
|---|---|
| Understand an error | Read the code, inspect terminal output and ask a question in one place |
| Prepare a small fix | Move from an AI plan to the precise file and test it immediately |
| Work on a remote project | Keep SSH, remote files and agent context together |
| Review generated changes | Inspect Git diff before a commit or push |
| Continue while mobile | Preserve the current task instead of reconstructing it across apps |

AI hace que el trabajo móvil sea más útil cuando reduce el costo del cambio de contexto. El espacio de trabajo aún le brinda los controles de ingeniería: archivos fuente, salida del shell, historial de Git y verificación deliberada.


## Buenos casos de uso para la codificación de IA móvil


- Explica un servicio desconocido mientras estás de guardia.

- Planifique una solución de producción limitada antes de editar.

- Interpretar un comando fallido o mensaje de diagnóstico.

- Revise un pequeño cambio y escriba un mensaje de confirmación claro.

- Continuar una tarea basada en SSH desde un teléfono o tableta cuando no haya una computadora portátil disponible.


## Donde la codificación de IA móvil es limitada


AI en un teléfono no cambia los fundamentos de ingeniería. Es más difícil razonar sobre refactorizaciones grandes y transversales en una pantalla pequeña, y las ejecuciones prolongadas de agentes aún se benefician de una ventana gráfica de escritorio. Las sugerencias de IA deben verificarse con el proyecto real: un LLM no puede ver su servicio en ejecución. Y para trabajos remotos adyacentes a la producción, debe mantener activados los comandos y las confirmaciones de cambios. Utilice codificación de IA móvil para tareas específicas y con un alcance bien definido; mantenga el gran trabajo de diseño en una computadora de escritorio.


## Preguntas frecuentes


### ¿En qué se diferencia la codificación de IA móvil de un chat de IA independiente?


NimoteCode mantiene AI Chat y Agent junto con el editor, el Explorador de proyectos, el terminal SSH y el contexto Git, para que las sugerencias se puedan inspeccionar y verificar en el espacio de trabajo real.


### ¿Puede AI Agent realizar cambios en un espacio de trabajo remoto?


AI Agent puede ayudar en tareas de varios pasos, pero el trabajo remoto y adyacente a la producción debe revisarse con los controles de comando y cambio habilitados.


### ¿La IA reemplaza la revisión de Git?


No. La IA puede ayudar a explicar, planificar y ayudar en una tarea; La revisión de Git y los comandos de prueba o verificación apropiados siguen siendo parte del flujo de trabajo de entrega.
