# IDE móvil para codificación SSH, Git y AI


La mayoría de las herramientas de codificación móviles resuelven una parte del trabajo: abrir un archivo, conectarse a un servidor o ejecutar un comando. Un **IDE móvil** debe mantener todo el ciclo de desarrollo unido: explorar el proyecto, comprender el código, realizar cambios, verificarlo y revisar lo que se enviará.


NimoteCode es un **Espacio de trabajo de desarrollo de IA móvil** para ese bucle. Las versiones de Android e iOS traen un Editor, Explorer, SSH, vista previa web y multimedia en la aplicación, Terminal, Git, AI Chat y Agent en un solo espacio de trabajo. En los dispositivos Android compatibles, Local Linux también proporciona un entorno Ubuntu incluido con Bash, Git y SSH sin acceso de root.

## ¿Qué hace que un IDE móvil sea útil para el trabajo real?


| Need | A single-purpose app | NimoteCode workspace |
|---|---|---|
| Understand a project | Open individual files | Browse the project in Explorer and keep files in tabs |
| Work remotely | Switch between an SSH app and editor | Connect to an SSH workspace and work on its files |
| Validate a change | Copy commands into another app | Run commands in the workspace terminal |
| Preview a web change | Switch to a separate browser | Open a local or remote web project from the workspace or a Terminal URL |
| Compare related code | Flip between files | Keep two files visible in split editor panes |
| Ship carefully | View a raw diff elsewhere | Review Git changes next to the edited code |
| Get help | Paste snippets into a separate AI chat | Use AI Chat or AI Agent with workspace context |

El objetivo no es reemplazar un escritorio para cada larga sesión de programación. Se trata de hacer productivos los momentos en los que solo tienes un teléfono o una tableta: una investigación de guardia, un pequeño arreglo de producción, una revisión mientras viajas o un seguimiento asistido por IA de un trabajo que ya está en progreso.


## Un flujo de trabajo completo, sin saltos de aplicaciones


Inicie en Local Explorer cuando el proyecto esté en su dispositivo, use Local Linux cuando necesite Ubuntu incluido en un dispositivo Android compatible o conéctese a través de [SSH Workspace](/docs/ssh) a una máquina o servidor de desarrollo remoto. Desde allí, abra archivos uno al lado del otro en el editor, obtenga una vista previa del contenido HTML actual antes de guardar o abra un proyecto web local o remoto cuando sea necesario, ejecute pruebas o comandos de inspección en [Terminal](/docs/terminal) y use [Control de código fuente](/docs/source-control) para inspeccionar la diferencia resultante.


Cuando una tarea necesita más contexto, [AI Chat and Agent](/docs/ai) puede explicar el código o planificar un cambio. AI Agent está diseñado para un trabajo controlado de varios pasos; en un espacio de trabajo SSH también puede utilizar un tiempo de ejecución ACP externo compatible configurado. Podrás inspeccionar lo que propone y dejar en tus manos la decisión final.


## Diseñado para limitaciones móviles


El buen desarrollo móvil no es una interfaz de usuario de escritorio comprimida en una pantalla pequeña. NimoteCode está diseñado en torno a teclados táctiles, móviles, paneles enfocados y trabajo remoto consciente de la reconexión. La versión actual también hace que las sesiones largas sean más estables con un manejo SSH más resistente, recursos de vista previa limitados y una entrada de terminal móvil más confiable. En una tableta, la pantalla más grande le brinda más espacio para edición dividida, navegación de proyectos y salida de terminal; en un teléfono, el mismo espacio de trabajo permanece enfocado en la siguiente acción.


Para obtener detalles sobre las funciones, consulte [Funciones](/features). Para la configuración de SSH y el acceso al proyecto, consulte [flujo de trabajo de desarrollo remoto de SSH](/docs/ssh). Para obtener instrucciones de configuración, comience con [Inicio rápido](/docs/quick-start).


## Donde el escritorio sigue ganando


Un IDE móvil es un complemento, no un reemplazo completo. El trabajo prolongado e ininterrumpido de funciones, la compilación local intensa, las refactorizaciones extensas de múltiples archivos y la depuración de múltiples monitores siguen siendo mejores en una computadora de escritorio. En un teléfono, el enfoque se reduce naturalmente al siguiente paso concreto: inspeccionar, editar, verificar, revisar. Esa división del trabajo es la razón por la que el desarrollo remoto a través de SSH (reutilizar la potencia informática que ya tienes) suele ser el camino productivo en lugar de intentar compilar grandes proyectos localmente en un teléfono.


## Preguntas frecuentes


### ¿NimoteCode es solo un cliente SSH?


No. NimoteCode combina Editor, Explorer, SSH, Terminal, Git, AI Chat y Agent en un espacio de trabajo de desarrollo móvil.


### ¿Puedo trabajar en un proyecto remoto desde un teléfono o tableta?

Sí. Conéctese a través de SSH, inspeccione archivos, edite código, ejecute comandos de terminal y revise los cambios de Git en el mismo espacio de trabajo.


### ¿NimoteCode está disponible para Android e iOS?


NimoteCode está disponible para Android en Google Play y para iPhone y iPad en App Store.
