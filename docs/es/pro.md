# NimoteCode Pro


NimoteCode se puede iniciar de forma gratuita: abra proyectos locales o SSH, o use Android Local Linux en un dispositivo compatible; edite archivos, ejecute comandos y use AI Chat en el plan gratuito. **NimoteCode 1.1.8 presenta Early Access Pro** para AI Agent, búsqueda remota, multiterminal, escrituras Git, LSP, depuración y sincronización/caché. La disponibilidad y los precios mostrados varían según la tienda, la cuenta y la región.


<PricingFeatureSystem lang="en" mode="full" />

## Por qué Pro


Pro existe para los momentos en que el trabajo móvil tiene que terminar con un resultado cuidadosamente revisado: una confirmación de Git cerrada después de verificar la diferencia, varios contextos de terminal a la vez, comentarios de LSP configurados, una sesión de depuración o una tarea del Agente AI. No elimina la necesidad de revisar comandos, diferencias o sugerencias de IA, especialmente en sistemas de producción.


Para verificación de suscripción, restauración de compras y comportamiento de acceso, consulte [Cuenta y suscripción](/docs/account-subscription).
