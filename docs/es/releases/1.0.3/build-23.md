## 1.0.3 · Compilación 23 · 20 de junio de 2026


NimoteCode lanza su espacio de trabajo de desarrollo móvil.


- **Nuevo:** Explore proyectos, edite código, use una terminal, revise Git y obtenga ayuda de IA en una sola aplicación.

- **Mejorado:** Las experiencias táctiles, de teclado y de lectura están optimizadas para teléfonos y tabletas.
