## NimoteCode 2.2.0

La versión 2.2.0 incorpora los flujos de GitHub a NimoteCode. Inicia sesión, explora repositorios y abre proyectos desde una página dedicada de GitHub; después trabaja con ramas, incidencias, pull requests y CI desde el espacio de trabajo que ya conoces. Esta versión también añade herramientas de desarrollo experimentales para Android Local Linux, refuerza la fiabilidad de la búsqueda y unifica los paneles y las conversaciones de toda la aplicación.

<span id="release-new"></span>

### Nuevo · 3

- **Flujos de desarrollo nativos de GitHub.** Inicia sesión con la autorización de dispositivo del navegador o con un token, explora tus repositorios, ramas y detalles de repositorio, y clona y abre proyectos en espacios de trabajo locales o SSH.
- **Colaboración con incidencias, pull requests y CI.** Consulta y filtra incidencias, pull requests, revisiones y comprobaciones. Inicia una tarea de Agent con el contexto de una incidencia y, cuando el trabajo esté listo, crea ramas, envía cambios, haz fork y abre pull requests.
- **Herramientas de Android Local Linux (experimentales).** Instala bajo demanda herramientas esenciales de línea de comandos, Python y Web. Crea, ejecuta y abre proyectos de ejemplo sin reinstalar Linux ni sobrescribir proyectos existentes. La instalación inicial requiere acceso a Internet.

<span id="release-improved"></span>

### Mejorado · 5

- **Operaciones de GitHub más fiables.** El inicio de sesión, la clonación de proyectos y las operaciones del espacio de trabajo Local Linux son más fiables, con pasos más claros para recuperar envíos y publicaciones fallidos.
- **Búsqueda del espacio de trabajo más sólida.** Los resultados de búsqueda, el resaltado y las interacciones móviles son más fiables. La búsqueda de código en Android Local Linux funciona sin configuración adicional.
- **Un entorno de trabajo más coherente.** Configuración, control de código fuente, GitHub, búsqueda y otros paneles comparten ahora superficies, tipografía, controles y comportamiento en diseños estrechos más claros. Los diseños de conversación y resumen también son más fáciles de examinar.
- **Estados de las herramientas más claros.** Consulta estimaciones de descarga y almacenamiento antes de instalar; después céntrate en ejemplos y comprobaciones de herramientas. Los registros de tareas, reintentos y avisos de interrupción ayudan a recuperarte; salir de la página no cancela una tarea. La tipografía, el espaciado, los botones y los diálogos de confirmación ahora coinciden con el entorno de trabajo.
- **Comentarios de copia coherentes.** Copiar desde paneles comunes ahora ofrece comentarios claros y uniformes.

<span id="release-fixed"></span>

### Corregido · 2

- Se corrigieron fallos transitorios de la API de GitHub, clonación HTTPS móvil, cancelación y recuperación del destino de clonación, manteniendo las credenciales fuera de las operaciones Git que no deben usarlas.
- Se mejoraron los resultados y el resaltado de búsqueda en espacios de trabajo remotos para reducir bloqueos y problemas de visualización con resultados grandes e interacción móvil.
