## NimoteCode 2.3.0

La versión 2.3.0 permite cambiar entre IDE, Terminal e IA conservando el proyecto y el estado del Explorador. También mejora plugins, espacios Windows SSH, colaboración con Agent, controles de terminal, revisión móvil de Git y Docker en hosts SSH.

<span id="release-new"></span>

### Novedades · 6

- Cambia entre IDE, Terminal e IA conservando el mismo proyecto y el estado del Explorador.
- Los plugins pueden declarar contribuciones y dependencias versionadas y validarse antes de instalar. Las herramientas, habilidades y flujos aprobados pueden ofrecerse al Agent integrado.
- Explora espacios Windows remotos mediante PowerShell/SFTP y usa búsqueda, Git, terminal, servicios de lenguaje y Agent.
- Los Agents ACP compatibles aceptan instrucciones adicionales mientras la tarea sigue en curso.
- Administra contenedores, imágenes, volúmenes, redes y Compose en hosts SSH; consulta registros y estadísticas, usa exec, busca en Docker Hub y controla servicios individuales.
- Crea o reconstruye Dev Containers desde devcontainer.json y abre un espacio aislado con el entorno configurado.

<span id="release-improved"></span>

### Mejoras

- Mejoras en paneles de terminal, navegación desde la salida al editor y análisis con IA, historial de comandos, preferencias guardadas, zoom y prompts por conexión. También mejoran Git móvil, Windows SSH, diagnóstico de Agent, recuperación Docker y permisos en tiempo real.
