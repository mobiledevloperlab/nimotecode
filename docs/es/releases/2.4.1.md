# NimoteCode 2.4.1 · Espacio Host y transferencia de archivos

19 de noviembre de 2026 · Build 66

<LatestReleaseLink />

[← Todas las versiones](/es/releases/)

2.4.1 renueva la interfaz y el diseño para tabletas e incorpora el espacio Host para gestionar sesiones remotas de terminal y Agent. Añade transferencias de archivos y detección de tareas, con mejoras en GitHub CI, búsqueda del historial y guardado remoto.

<span id="release-new"></span>

### Nuevo

- **Espacio Host**: Instala e inicia un NimoteHost compatible de forma remota y conecta por SSH para consultar y retomar sesiones de terminal y Agent.
- **Sesiones Agent en Host**: Utiliza conversaciones estructuradas, aprobaciones, comandos y controles de modelos en las sesiones compatibles.
- **Bandeja de tareas Host**: Revisa tareas, resultados de verificación y diffs, o envía Issues de GitHub a un Agent. Las funciones dependen de las capacidades y configuración del Host.
- **Plugins Host**: Accede a plugins compatibles del Host y vincula tareas del proyecto con terminales del espacio de trabajo.
- **Transferencia de archivos y carpetas**: Transfiere entre el dispositivo y espacios SSH, o importa y exporta archivos y carpetas localmente.
- **Detección de tareas**: Descubre tareas compatibles de npm, Taskfile, Makefile, justfile y definiciones de tareas de VS Code.

<span id="release-improved"></span>

### Mejoras

- **Interfaz y tabletas**: Rediseño del espacio de trabajo y mejoras en disposición horizontal, tabletas, controles del editor y revisión Git móvil. Explorer muestra colores de estado Git.
- **Modos y plugins**: Alterna entre IDE, Terminal e IA conservando el proyecto y Explorer. Mejoras en plugins, instrucciones durante la ejecución de Agents compatibles y espacios Windows SSH.
- **Uso del terminal**: Mejoras en respuesta, búsqueda, desplazamiento, portapapeles y programas interactivos. Búsqueda del historial conservado, selección de caracteres anchos y entrada del ratón.
- **Terminal y herramientas**: Abre ubicaciones de archivo desde la salida, envía selecciones a la IA y consulta los registros de comandos compatibles. Paneles adaptativos, Docker y Compose por SSH y creación de Dev Containers.
- **GitHub CI**: Filtra ejecuciones de flujos y consulta registros por paso y contexto de errores.
- **Configuración y accesibilidad**: Entrada unificada de configuración y mejor compatibilidad con movimiento reducido. Configura sonido y vibración de Agent, números de línea y minimapa horizontal.
- **SSH y guardado remoto**: Mejoras en verificación de hosts y fiabilidad del guardado remoto, incluido el guardado en hosts Windows.

<span id="release-fixed"></span>

### Correcciones

- Corrección de varios errores.

Las funciones Host requieren un NimoteHost compatible. La disponibilidad de Agents y plugins depende de sus capacidades y configuración.
