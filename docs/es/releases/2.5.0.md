# NimoteCode 2.5.0 · SSH a equipos vinculados, terminales persistentes e instalación de NimoteHost

Próximamente · Build 68

[Versión publicada · 2.4.1](/es/releases/2.4.1) · [← Historial de versiones](/es/releases/)

### Conexiones remotas y Host

- Elige un equipo vinculado en el selector de conexiones y usa su IP de Tailscale o nombre MagicDNS sincronizado. Inicia sesión con tu contraseña o clave SSH habitual. Puedes desvincular el equipo en NimoteCode y seguir usando SSH manual.
- El acceso público a Internet de Nimote Connect está previsto. Las cuotas Free y Pro aún no se han definido. SSH estándar y Tailscale personal están disponibles.
- Mejoran la conexión y la recuperación SSH en redes lentas, la entrada y salida de terminal, el cambio de tamaño y las lecturas SFTP. Android mejora la compatibilidad con archivos de claves SSH.
- El panel Host muestra el estado y la versión de NimoteHost. Puedes confirmar la instalación, el inicio o la actualización por SSH con la versión que ofrece el panel Host. Los errores muestran el motivo y permiten reintentar. La aplicación pide permiso si la actualización requiere detener sesiones.
- **Confianza y recuperación.** Relay muestra por separado la autorización, la confirmación del equipo, la apertura del túnel y el inicio de sesión SSH. Desvincular el equipo revoca su acceso por Relay. Un Host compatible permite volver al mismo espacio desde rutas verificadas del mismo equipo.

### Terminal

- Con Pro, crea o reanuda sesiones persistentes desde el menú de terminal en hosts SSH compatibles con tmux instalado. Cerrar la pestaña local deja el trabajo en marcha. El mismo menú permite finalizar la sesión remota.
- Mejoran el desplazamiento por el historial de tmux, el primer renderizado, el cursor y el teclado en horizontal. La búsqueda avanzada espera a que termine la composición del texto en chino.
- Mejora la selección de palabras y caracteres anchos. En aplicaciones que capturan el ratón, como Codex o Claude Code, arrastra con Mayús y copia desde el menú contextual. La selección se conserva tras el redibujado.
- **Terminal.** Reanuda tmux desde el historial o la lista remota, incluso desde otro cliente con el mismo usuario SSH. En horizontal, el teléfono muestra teclas como Esc y Ctrl si está abierto el teclado y hay espacio. Los menús siguen accesibles durante los avisos.

### Espacio de trabajo, editor y Git

- Los teléfonos en vertical incorporan una barra de navegación flotante. IDE y Host comparten controles más coherentes y el editor de un solo panel permite abrir el explorador desde el estado vacío.
- La búsqueda abre el archivo y resalta la coincidencia. Mejoran la búsqueda por SSH, la apertura de directorios grandes y el manejo de selecciones y pestañas en paneles divididos.
- Abre el historial Git del archivo desde el editor. El historial sigue los cambios de nombre y permite reintentar la carga. Las listas de cambios se cargan bajo demanda en repositorios grandes.
- También mejoran el contraste de la selección, la copia, el selector de carpetas remotas y el bloqueo de campos mientras se guarda o elimina una tarea.
- **Historial Git y revisión de Agent.** El historial de archivos y líneas distingue los resultados vacíos de los errores, permite reintentar y admite alias de carpetas remotas. Si falta una captura, la tarjeta de revisión indica el motivo y enlaza con el diff actual de Git.

### IA y plataformas

- Codex integrado responde más rápido y mejora la cancelación y las llamadas a herramientas. Agent conserva los turnos cancelados al recuperar conversaciones y mejora la búsqueda y el acceso a archivos en repositorios grandes.
- Linux local de Android admite kits definidos por manifiestos, también para contribuciones de la comunidad. iOS mejora el inicio y el ciclo de vida de la aplicación. Los clientes de escritorio mejoran el inicio de sesión por correo y los permisos de escritorio dependen de la cuenta.
- Free permite ver el estado y las diferencias de Git, preparar y retirar cambios y crear commits. Las operaciones gráficas de push, pull, ramas y stash, Git AI y la integración avanzada de GitHub requieren Pro. Docker y los Dev Containers requieren Pro y un host compatible. La depuración requiere Pro y un adaptador configurado.
- **Espacio de trabajo y plataformas.** El menú incluye GitHub y el proyecto de ejemplo. El campo de IA tiene un área táctil mayor y la conversación vacía se desplaza en pantallas bajas. Las tareas y los plugins muestran los destinos de terminal de cada plataforma. Linux local está disponible en Android.
