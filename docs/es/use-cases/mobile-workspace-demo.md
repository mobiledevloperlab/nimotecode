# Demostración del espacio de trabajo móvil


Este flujo de trabajo muestra el ciclo de desarrollo diario que NimoteCode trae a un teléfono. Comience desde un proyecto local o un espacio de trabajo SSH, mantenga conectados los archivos, el editor, el terminal y el control de fuente, y pase de la inspección a un resultado revisable sin cambiar de herramienta.

## El bucle móvil enfocado


1. Abra un proyecto local o conéctese al host SSH deseado y a la raíz del proyecto.

2. Inspeccione el archivo relevante y luego realice una edición específica en el editor.

3. Utilice Terminal para verificar registros, ejecutar una prueba o verificar el comportamiento modificado.

4. Revise la diferencia resultante en Control de código fuente antes de un paso de confirmación o entrega.


El flujo de trabajo está diseñado para un trabajo real y limitado fuera de un escritorio, no como un reemplazo de la revisión, los controles de acceso y la validación que requiere su proyecto.
