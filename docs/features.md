<ProductFeatures />

<div class="product-reference">

<details>
<summary>Search, language services, and debugging</summary>

- [Project search](/docs/search): search file contents in SSH workspaces, with case-sensitive and regular-expression options.
- [Language services](/docs/lsp): diagnostics, symbol navigation, and code actions from a compatible language server installed and configured on the workspace target.
- [Debugging](/docs/debug): breakpoints, call stacks, variables, and watch expressions through a configured debug adapter.

</details>

<details>
<summary>GitHub, tasks, and plugins</summary>

- [GitHub](/docs/source-control): clone repositories to the device, Local Linux, or an SSH host; work with issues, pull requests, reviews, checks, and workflow runs according to account permissions.
- [Tasks](/docs/tasks): save named commands and run them from the SSH or Local Linux project directory.
- [Plugins](/docs/plugins): create panels with forms, workspace data, file actions, HTTP requests, and scripts. File, network, and execution actions require confirmation.

</details>

<details>
<summary>Model providers and external tools</summary>

- [Model configuration](/docs/configuration): configure a provider, model, and credentials. Provider accounts and model usage charges are separate from NimoteCode.
- [External ACP Agents](/docs/ai): run a separately configured, compatible Agent in a supported environment. Credentials, tool permissions, and execution policy belong to that runtime.
- [MCP servers](/docs/ai): connect tools through stdio or Streamable HTTP. Starting a stdio server and invoking MCP tools require approval.

</details>

<details>
<summary>Feature access</summary>

The app shows feature access for the current account and platform. Git write operations, multiple terminals, Agent execution, Docker, LSP, and debugging depend on the applicable Pro, trial, or Early Access entitlement.

See [account and subscription](/docs/account-subscription) for access and restoration, or [Early Access](/pro) for current terms.

</details>

</div>
