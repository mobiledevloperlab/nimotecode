## Everything you get for free

The free tier is a full workspace, not a preview. Everything below works without a Pro subscription unless marked **Pro**.

| Feature | What it gives you | Access |
| --- | --- | --- |
| **[Local & SSH workspaces](/docs/ssh)** | Open local projects and saved SSH workspaces. | Free |
| **[Code editor](/docs/editor)** | Work in tabs or two independent split panes; save, use clipboard and undo/redo, follow cursor context, and inspect images or supported audio/video without leaving the app. | Free |
| **[Web & media preview](/docs/editor)** | Open local or remote web projects in-app, preview the current HTML contents—including unsaved changes—with workspace CSS, JavaScript, and image assets, or open links from Terminal, AI replies, and tool output. | Free |
| **[Terminal & SSH environment](/docs/terminal)** | Run commands in the active workspace, search output, use shortcuts, and reconnect reliably. SSH workspaces load the account’s normal shell environment, so PATH, locale, SSH agent, and custom variables are available consistently to remote tools. | Free |
| **[Git review](/docs/source-control)** | Inspect repository status, diffs, branches, and history. In Android Local Linux, Git operates inside the Linux workspace so status and history match its files. | Free |
| **[AI Chat](/docs/ai)** | Explain code, inspect error output, and plan or continue a task with current-file, workspace, recent-task, and Agent context. | Free |
| **[Tasks](/docs/tasks)** | Save repeated workspace commands, organize them in groups, and run them directly where the project lives. | Free |

## Recently added to the workspace

- **[A workspace you can customize.](/docs/plugins)** Plugin Center lets you manage capabilities and create custom plugins for panels, forms, workflows, artifact views, and local or SSH script jobs. Permission changes are visible for review before an install or update.
- **[Continuous Agent collaboration.](/docs/ai)** Give a running Agent follow-up instructions, answer its interactive questions, and keep longer work understandable with rebuilt context, history, prompt editing, and timeline views.
- **[More direct Git and terminal assistance.](/docs/source-control)** Search, create, and check out branches from the Git header; quieter editor change markers and clearer syntax-highlighted diffs improve review. Send terminal output to AI when you want help interpreting it.
- **[Flexible remote connections.](/docs/ssh)** SSH workspaces can connect through SOCKS5 or HTTP CONNECT proxies when a network requires one.
- **[Flexible workspace directories.](/docs/ssh)** Local and SSH projects can switch to another directory and retain recent locations for quick return.
- **[Android Local Linux reliability.](/docs/local-linux)** The Ubuntu environment now has clearer file-access boundaries and more dependable setup, Git, and Task file handling. These improvements apply only to Android.
- **[A more complete preview loop.](/docs/editor)** Split editing, live HTML snapshots, built-in media preview, and shared link opening make it practical to inspect a result before leaving the workspace.
- **[Agent workflows that fit your environment.](/docs/ai)** External ACP runtimes, slash-command completion, shared SSH login-environment handling, and safe environment diagnostics keep Terminal, Tasks, Debug, language servers, Git, and agents aligned.



## A practical way to use the features

1. Connect through [SSH Workspace](/docs/ssh), open a local project, or use [Android Local Linux](/docs/local-linux) on a supported device.
2. Locate and edit the file in [Editor](/docs/editor).
3. Verify it in [Terminal](/docs/terminal); search output or remote content when needed.
4. Ask [AI Chat and Agent](/docs/ai) to explain an error, plan a change, or continue an active task.
5. Use [Source Control](/docs/source-control) to review the result; Pro is required when the delivery step needs a gated Git write action. Use Plugin Center when your workflow needs a custom panel, form, workflow, artifact view, or script job.

> Features are deliberately permission- and environment-aware. For example, LSP and Debug depend on the language server or debug adapter being set up on the remote host, and AI output should be reviewed before use on sensitive systems.
