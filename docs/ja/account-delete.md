# アカウントとデータの削除

<p class="trust-meta">最終更新：2026-11-05 · NimoteCode</p>

アプリ内で削除できます。ログインできない場合やアンインストール済みでも、本ページから申請でき、再インストールは不要です。

<div class="trust-summary">

**削除は購読の解約ではありません。** 更新を希望しない場合は別途解約してください。削除申請は購読期限を待つ必要はありません。

[Apple の購読](https://apps.apple.com/account/subscriptions) · [Google Play の購読](https://play.google.com/store/account/subscriptions)

</div>

## アプリ内 {#in-app}

1. **設定 → アカウント削除**を開きます。
2. 説明を読み、`DELETE` を入力します。
3. 必要な再認証を行い、削除を確認します。

成功時に認証アカウント、主ユーザー記録を削除し、現在の購読所有者との関連を解除します。エラーや成功表示がない場合はサポートへ確認してください。

## ウェブから申請 {#request}

<a class="trust-action" href="mailto:support@nimotecode.com?subject=NimoteCode%20account%20and%20data%20deletion">削除申請メールを作成 →</a>

[support@nimotecode.com](mailto:support@nimotecode.com) に NimoteCode アカウントと関連個人データの削除希望、メール（分かる場合）、ログイン方法、iOS / Android を記載してください。Apple の転送メールも使用できます。ゲスト利用や識別情報不明の場合はその旨をお知らせください。

ボタンは草稿を開くだけです。**送信して申請を完了**してください。メールアプリがない場合はアドレスをコピーできます。元のアカウント・メールによる本人確認を行う場合があります。パスワード、認証コード、秘密鍵、完全な決済情報を送らず、公開 Issue を使用しないでください。

## 削除対象と保持 {#scope}

| データ | 処理 |
| --- | --- |
| 認証・主ユーザー記録 | 正常な削除で除去。 |
| 購読・試用 | 現在の所有者との関連を解除。取引、元ユーザー ID を含む削除関連記録、不正防止の試用ハッシュは保持する場合があります。試用資格はリセットされません。 |
| RevenueCat・解析・サポート | すべてが自動削除されるわけではありません。関連データの削除希望も記載できます。必要な法的・目的別保持は別途案内します。 |
| ローカル履歴・報告・認証情報・ファイル・外部 Agent | 自動では削除されません。端末、アプリ、ホスト、各サービスで管理してください。 |
| ストア・AI・GitHub アカウント | 削除・解約されません。各提供元で管理してください。 |

履歴保存の停止と既存履歴の削除、報告消去、SSH・AI 設定の削除は個別操作です。トークンのローカル削除と提供元での失効も別です。

## 進捗 {#timing}

自動処理はアプリで結果を表示します。メールの初回返信目安は 2–3 営業日で、本人確認後に範囲、予定、完了結果を案内します。追加処理には時間がかかる場合があり、法定期限が優先されます。保持が必要な記録は理由と期間の扱いを説明します。

アカウントを残して特定データのみ削除する場合は範囲を明記してください。[プライバシー](/ja/privacy#retention) · [サポート](/ja/support)。
