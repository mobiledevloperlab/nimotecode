# SSH、Git、AIコーディング用のAndroid IDE


Android は、サーバーをチェックするためのデバイス以上の役割を果たします。適切なツールを使用すると、開発作業のための実用的な環境になります。SSH 経由で独自の開発マシンに接続し、リポジトリを開いて、焦点を絞った変更を加えて検証します。すべて携帯電話またはタブレットから実行できます。


NimoteCode は、そのワークフローを中心に構築された **Android IDE** です。 Explorer、コード エディター、SSH ターミナル、Git レビュー、LSP、デバッガー、AI チャットとエージェントが 1 つのモバイル ワークスペースに組み合わされているため、Android は、デスクトップ、ラップトップ、またはサーバー上にまだ存在しているプロジェクトで作業を続けるための実用的な方法になります。

## Android IDE が行うべきこと


Android IDE では、ループ全体を 1 か所に保持する必要があります。つまり、プロジェクトの理解、ファイルの編集、コマンドの実行、結果のプレビュー、および出荷される内容の確認を行います。これは、ローカル ファイル用のスタンドアロン コード エディターや、シェル テキストのみを表示する SSH クライアントとは異なります。プロジェクト、ターミナル、および Git 履歴は同じワークスペースに属します。


## 役立つ場合


- ラップトップから離れているため、サービスを調査または修正する必要があります。

- 携帯電話またはタブレットから差分を確認し、少額の小銭を発送したいと考えています。

- SSH 経由で Mac、Linux ボックス、またはサーバーに接続し、ターミナルの横にエディタと Git ビューを表示したいとします。

- 貼り付けられたスニペットではなく実際のプロジェクトを読み取る AI ヘルプが必要です。


## NimoteCode の適合性


[SSH ワークスペース](/docs/ssh) を使用して開発マシンに接続し、プロジェクト ルートを選択します。プロジェクトはリモート ホスト上に残ります。ファイルと端末出力は SSH 接続経由で送信されるため、コピーをデバイスに同期する必要はありません。デバイスに保存されているプロジェクトの場合、ローカル エクスプローラーは同じように機能します。


## Android での実際のワークフロー


1. 開発ホストの SSH プロファイルを保存し、プロジェクトのルートを開きます。

2. パスを記憶する代わりに、エクスプローラーで関連ファイルを検索します。

3. エディタで最小限の安全な変更を加えます。

4. [ターミナル](/docs/terminal)で関連するテスト、ビルド、またはログコマンドを実行します。

5. コミットまたはハンドオフの前に、[Git の変更](/docs/source-control) を検査してください。

6. [AI チャットとエージェント](/docs/ai) に、必要に応じてコードの説明や次のステップの計画を依頼します。


## Android開発に関連する機能


- **SSH ワークスペース** - 再接続を意識した処理によるリモート プロジェクトの参照と編集。

- **エディタ** — 大きな画面での分割ペインとモバイルキーボード対応の入力によるタブ編集。

- **ターミナル** — プロジェクトコンテキストと出力検索を使用したコマンドセッション。

- **Git** — ステータス、差分、履歴を検査します。 Pro を使用したゲート書き込みワークフロー。

- **AI チャットとエージェント** — 確認指向の実行によるワークスペースを意識した支援。

- **LSP とデバッグ** - リモートホスト上に構成された言語サーバーとデバッグアダプタ。


## Android IDEの制限事項


Android では、すべてのタスクのデスクトップを置き換えることはできません。大量のローカル コンパイル、長時間にわたるマルチファイルのリファクタリング、およびマルチモニターのデバッグは、コンピューター上で行う方がさらに快適です。 SSH を介したリモート作業はホストへの安定した接続に依存しており、ホストが面倒な作業を行います。つまり、電話ではサーバーの能力が不足していることを補うことはできません。 NimoteCode は、修正、レビュー、オンコール作業、小さな機能など、集中的で価値の高い瞬間をターゲットにしています。


## よくある質問


### Android スマートフォンまたはタブレットで実際の開発を行うことはできますか?

はい、集中的な一連のタスクの場合。 NimoteCode のような Android IDE を使用すると、SSH 経由で開発マシンに接続し、プロジェクトを参照し、ファイルを編集し、ターミナル コマンドを実行し、Git の変更をレビューし、特に修正、レビュー、小さな機能について AI 支援を使用することができます。


### NimoteCode は iOS でも利用できますか?


NimoteCode は、Android では Google Play で、iPhone および iPad では App Store で入手できます。


### Android は重いローカル ビルドまたは完全な IDE を実行できますか?


デスクトップの場合とは異なります。長時間のローカル コンパイルや大規模な複数ファイルのリファクタリングはデスクトップで行う方が適しています。 Android では、通常、既存のマシンへの SSH 経由のリモート開発が生産的なパスです。
