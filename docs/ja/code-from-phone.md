# 電話からコーディングできますか?


はい — デスクトップの置き換えではなく、集中的な開発作業に使用します。問題の調査、小さな修正の作成、コマンドの実行、差分の確認、既存のプロジェクトでの AI エージェントの駆動は、ツールが構築されている電話機からすべて現実的に実行できます。


NimoteCode は、SSH 経由で独自の開発マシンに接続し、プロジェクト エクスプローラー、エディター、ターミナル、Git、AI を 1 つのワークスペースに配置することで、**電話からのコーディング**を実用化します。計算とツールはそのマシン上に残りますが、電話機は同じリポジトリ上で動作します。

## 電話からのコーディングの実際の意味


電話からのコーディングは、ループが短い場合に機能します。プロジェクトを開いて、関連するコードを読み、わずかな変更を加え、チェックを実行して結果を確認します。ツールによってアプリ間でファイルやスニペットのコピーが強制される場合、または携帯電話でローカルに大規模なプロジェクトをコンパイルしようとすると、問題が発生します。信頼できるパターンは、すでに所有しており信頼できるマシンに接続することです。


## やる価値があるとき


- 通話中のため、エラーを調査するか、簡単な修正を適用する必要があります。

- ラップトップから離れた場所でプルリクエストまたは差分をレビューしたいと考えています。

- 旅行中に小さなタスクを実行し続ける必要があります。

- 貼り付けられたフラグメントではなく、実際のプロジェクトに対するワークスペース対応の AI ヘルプが必要です。


## NimoteCode の適合性


デバイス上にすでにあるプロジェクトの[ローカルワークスペース](/docs/ssh)を開くか、SSHワークスペースを使用してMac、Linuxマシン、またはサーバーに接続します。そこから、ファイルを参照し、エディタで編集し、[ターミナル](/docs/terminal)でコマンドを実行し、[Gitの変更](/docs/source-control)を確認し、[AIチャットとエージェント](/docs/ai)を使用します。これはデスクトップで実行するのと同じワークフローであり、モバイル画面向けに形成されています。


## 現実的な電話コーディング セッション


1. SSH 経由で開発ホストに接続し、プロジェクトのルートを開きます。

2. エクスプローラーで関連ファイルを見つけます。

3. エディタで最小限の安全な変更を加えます。

4. ターミナルでフォーカスされた検証コマンドを実行します。

5. コミットする前にソース管理で差分を確認してください。

6. 行き詰まった場合は、AI にコードの説明を依頼したり、次のステップを計画したりしてください。


## 電話からのコーディングが制限される場合


携帯電話の画面は小さいため、長時間にわたるファイル間リファクタリングや重い設計セッションはより困難になります。大規模なプロジェクトをローカルでコンパイルすることは、電話ではほとんど実用的ではありません。代わりにリモート マシンを使用してください。ネットワークの品質はすべてのリモート セッションに影響を与えるため、AI の提案とエージェントの実行を絞り込んで検証する必要があります。これらは実際の制約です。有益な質問は、どのタスクがその中にまだ収まるかということです。


## よくある質問


### 電話からコーディングするのは現実的ですか?


集中的な作業の場合ははいです。問題の調査、小さな修正の作成、コマンドの実行、差分の確認、既存のプロジェクトでの AI エージェントの駆動などです。長編の長編作品や重いコンパイルは、デスクトップ上でより快適に行えます。


### 電話から実際にコーディングするにはどうすればよいですか?


信頼できるパターンは、モバイル開発ワークスペースを使用して SSH 経由で独自の開発マシンに接続し、アプリ間でファイルやスニペットをコピーするのではなく、プロジェクトを参照、編集、実行、レビューすることです。


### NimoteCode を実行できる携帯電話はどれですか?


NimoteCode は、Android スマートフォンとタブレットでは Google Play で、iPhone と iPad では App Store で利用できます。
