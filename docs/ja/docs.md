# NimoteCode ドキュメント


モバイル デバイスからローカル プロジェクト、Android Local Linux、または SSH プロジェクトで作業するための短いタスク指向のガイド。長い機能マニュアルではなく、必要なワークフローから始めてください。

<div class="product-card"><strong>リモート ワーク</strong><span><a href="/docs/ssh">SSH ワークスペース</a> をセットアップし、同じプロジェクト コンテキストで <a href="/docs/terminal">ターミナル</a> を使用します。</span></div>
<div class="product-card"><strong>Android 開発環境</strong><span>サポートされている Android デバイスで root なしでバンドルされた Ubuntu には、<a href="/docs/local-linux">ローカル Linux</a> を使用します。</span></div>
<div class="product-card"><strong>安全な配信</strong><span>コミットまたは同期する前に、<a href="/docs/source-control">Source Control</a> を使用して変更を確認してください。</span></div>
<div class="product-card"><strong>AI 支援</strong><span>複数ステップのタスクを実行する前に、<a href="/docs/ai">AI チャットとエージェントの境界を理解してください</a>。</span></div>
<div class="product-card"><strong>技術リソース</strong><span>環境を選択する前に、<a href="/resources/">mobile、Android Linux、SSH、AI コーディング ワークフローを比較してください</a>。</span></div>
