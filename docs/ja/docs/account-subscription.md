# アカウントとサブスクリプション

## アカウント状態を確認する

**Settings** を開いてサインインし、アカウントとサブスクリプションの欄を確認します。表示される利用権限によって Pro 機能へのアクセスが決まります。利用可否と購入方法は、ストア、アカウント、地域、配信チャネルによって異なります。

**Pro を14日間無料で試す** — アプリで14日間の無料トライアルを開始できます。終了後、有料サブスクリプションや Early Access などの有効な Pro 利用権限がなければ、自動で無料版に戻ります。対象条件はアプリで確認してください。

## 購入を復元する

購入済みの権限が認識されない場合は、プラットフォームのストアアカウントを確認して **Restore Purchase** を選択します。復元後の権限を確認してから機能を再試行してください。アカウント固有の問題は[サポート](/ja/support)にお問い合わせください。

## 利用できる機能

以下の上限は公開予定の 2.5.0 のプラン比較に基づきます。インストール済みのバージョンと[無料版と Pro](/ja/pro)で利用権限を確認してください。

Free では Git の状態と差分の確認、ステージング、ステージ解除、コミットができます。GUI でのプッシュ、プル、ブランチとスタッシュの操作、Git AI、高度な GitHub 連携には Pro が必要です。 Docker と Dev Container には Pro と対応ホストが必要です。 デバッグには Pro と設定済みのデバッグアダプターが必要です。

NimoteHost、永続リモートターミナル、デバイス間の AI セッション引き継ぎには、有効なトライアルまたは Early Access を含む Pro 権限が必要です。

Nimote Connect のインターネット経由の接続は計画中です。Free と Pro の利用枠は未定です。通常の SSH と個人用 Tailscale を利用できます。

[無料版と Pro](/ja/pro)をご覧ください。

AI モデルは BYOK（API キー持ち込み）方式です。自分のプロバイダーと API キーを設定してください。モデル利用料はプロバイダーから別途請求され、利用枠は含まれません。
