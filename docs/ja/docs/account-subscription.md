# アカウントとサブスクリプション


NimoteCode は、アカウントとサブスクリプションの状態を使用して **早期アクセス プロ** アクセスを確認します。正確な可用性、購入、および復元のオプションは、プラットフォーム ストア、アカウント、地域、および現在のリリース チャネルによって異なります。


## サインインの使用目的


- 検証済みの Pro アクセスをアカウントに関連付けます。

- サポートされているストアフローを通じて対象となる購入を復元します。

- トライアルおよびプロゲートワークフローへのアクセスを確認します。


## プロがロックを解除するもの


Pro は、Git 書き込みワークフロー、高度なマルチターミナル、AI エージェント、リモート検索、LSP、デバッグおよび同期 / キャッシュを有効にします。機能は使用時にチェックされるため、ワークスペースではどのアクションにアクセスする必要があるかが明確になります。


## アクセスが間違っている場合


サインインしているアカウントを確認し、アプリでサブスクリプションステータスを更新し、同じサポート対象プラットフォームで以前に購入したことがある場合は、利用可能な購入の復元アクションを使用します。最近確認された資格は、ネットワークが一時的に中断されている間も、短期間使用し続けることができます。


完全な比較については、[NimoteCode Pro](/pro)を参照してください。アカウント固有の問題に関するサポートが必要な場合は、アプリまたはサイトのフッターにあるサポート ルートをご利用ください。
