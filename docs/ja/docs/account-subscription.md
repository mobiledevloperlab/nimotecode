# アカウントとサブスクリプション

## アカウント状態を確認する

**Settings** を開いてサインインし、アカウントとサブスクリプションの欄を確認します。表示される利用権限によって Pro 機能へのアクセスが決まります。利用可否と購入方法は、ストア、アカウント、地域、配信チャネルによって異なります。

## 購入を復元する

購入済みの権限が認識されない場合は、プラットフォームのストアアカウントを確認して **Restore Purchase** を選択します。復元後の権限を確認してから機能を再試行してください。アカウント固有の問題は[サポート](/ja/support)にお問い合わせください。

## 利用できる機能

Pro 機能には AI Agent、プラグインのワークフロー、Git の書き込み操作、リモート検索、複数のターミナル、LSP、デバッグ、Sync / Cache が含まれます。モデルの利用料金はプロバイダーから別途請求されます。比較は[無料版と Pro](/ja/pro)をご覧ください。
