# モバイルコードエディタ


エディタでは、ワークスペースが変更されます。ローカル プロジェクト、SSH ワークスペース、または検索結果からファイルを開きます。次に、ファイルを別のアプリ間を移動するのではなく、ターミナル、AI、およびソース管理に接続したままにします。

## 集中的な編集向けに設計


- 小さな変更を行う間、複数のファイルをタブで開いたままにします。

- 関連するコードを並べて比較または編集する必要がある場合は、分割ペインで 2 つのファイルを開きます。

- 画像を検査し、サポートされているオーディオまたはビデオをエディタで直接再生します。

- モバイルエディタからコピー、切り取り、貼り付け、すべて選択、元に戻す、やり直しを使用します。

- エラーまたはコメントの確認中に作業中に現在の行と列を追跡します。

- シンボル情報が利用可能な場合はアウトラインを使用します。

- アクティブなファイルを[AIチャットおよびエージェント](/docs/ai)のコンテキストとして利用できるようにします。

## 優れたモバイル編集ループ


1. エクスプローラーまたは[検索](/docs/search)でファイルを見つけます。

2. 有用な最小限の編集を行って保存します。

3. プロジェクトが URL を提供する場合、アプリでローカルまたはリモートの Web 変更をプレビューし、[ターミナル](/docs/terminal)で検証コマンドを実行します。

4. [ソース管理](/docs/source-control)で結果の差分を検査します。配信にゲートされた Git 書き込みアクションが必要な場合は、Pro を使用してください。


長期にわたる探索的な作業では、依然としてデスクトップの方が優れたツールである可能性があります。エディターは、現在実行する必要がある集中タスクに合わせて最適化されています。
