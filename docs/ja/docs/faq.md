# NimoteCode FAQ


## NimoteCode は SSH クライアントのみですか?


いいえ。 NimoteCode は、ローカル プロジェクトを開いたり、Android Local Linux を使用したり、SSH ワークスペースに接続したりすることができ、エクスプローラー、エディター、ターミナル、Git ワークフロー、AI 支援、および診断パネルを同じプロジェクト コンテキストに取り込むことができます。


## Pro なしで使用できますか?


はい。無料には、ローカル、Android ローカル Linux および SSH ワークスペース、エディター、ベースライン ターミナル、AI チャット、および基本的なタスクが含まれます。ローカル Linux には、64 ビット ARM64 または x86_64 デバイス上の Android 8 以降が必要ですが、iOS では利用できません。 AI エージェントとリモート検索は、可用性が拡大するにつれて、Early Access Pro を通じて利用できるようになります。ゲートワークフローについては、[Pro](/pro)を参照してください。


## どの AI プロバイダーを構成できますか?


このアプリには 14 の組み込みプロバイダー テンプレートが含まれており、互換性のあるカスタム エンドポイントをサポートします。プロバイダーの可用性、モデルのアクセス、およびコストは、独自のプロバイダーのアカウントと設定によって決まります。 [構成](/docs/configuration)を参照してください。


## ソース管理は何をサポートしていますか?


ソース管理を使用すると、すべてのユーザーがリポジトリのステータス、差分、履歴を検査できます。 Pro は、コミット、プッシュ、スタッシュ アクションなどのゲートされた Git 書き込みワークフローに必要です。 [ソース管理](/docs/source-control)を読み取ります。


## タスクはローカルですか、それともリモートですか?


タスクは、SSH ワークスペースで反復可能なコマンド ワークフロー用に設計されています。各コマンドを実行する前に、ホスト、プロジェクト ルート、および各コマンドのリスクを明確にしてください。


## LSP とデバッグはすべてのプロジェクトで機能しますか?


これらは、リモートホスト上で構成されている互換性のある言語サーバーまたはデバッグアダプタとプロジェクトのセットアップに依存します。これらはプロのワークフローです。 [LSP](/docs/lsp) および [デバッグ](/docs/debug) を参照してください。
