# NimoteCode よくある質問

## NimoteCode は SSH クライアント専用ですか？

いいえ。ローカルプロジェクト、Android Local Linux、SSH ワークスペースに対応し、Explorer、Editor、Terminal、Git、AI 支援、診断パネルを同じプロジェクトのコンテキストで利用できます。

## Pro なしでも使えますか？

ファイル編集、SSH 接続、検索付きのターミナルを同時に最大 2 つ利用、基本的な LSP 補完・診断・ナビゲーション、自分のモデルサービスでの独立した AI チャット、Git のステージング、ステージ解除、コミット、差分と履歴の閲覧は無料です。基本 LSP には設定済みの言語サーバーが必要です。対応する Android 端末では基本的なローカル Linux 環境も無料です。 無料プランでは内蔵 Agent のタスクを 1 日 3 回、リモートファイルの内容検索を 1 日 10 回利用できます。UTC 0 時にリセットされます。 [Free と Pro](/ja/pro).

## どの AI プロバイダーを設定できますか？

プロバイダーのテンプレートと、互換性のあるカスタムエンドポイントに対応します。利用可能なプロバイダー、モデルへのアクセス、料金は、ご自身のプロバイダーアカウントと設定によって決まります。[設定ガイド](/ja/docs/configuration)を参照してください。

## ソース管理は何に対応していますか？

Free では Git の状態と差分の確認、ステージング、ステージ解除、コミットができます。GUI でのプッシュ、プル、ブランチとスタッシュの操作、Git AI、高度な GitHub 連携には Pro が必要です。

## Tasks はローカルとリモートのどちらで実行しますか？

Tasks は SSH ワークスペースで再利用するコマンドを実行します。接続中のワークスペースで実行され、別のディレクトリを指定しなければ、そのルートが作業ディレクトリになります。

## LSP とデバッグはすべてのプロジェクトで使えますか？

リモートホストに互換性のある言語サーバーやデバッグアダプターが設定されているか、またプロジェクトの構成によって異なります。基本 LSP 診断、補完、ナビゲーションは無料です。コードアクション、言語サーバーのインストール支援、デバッグには Pro と必要なツール設定が必要です。 [LSP](/ja/docs/lsp) と[デバッグ](/ja/docs/debug)を参照してください。
