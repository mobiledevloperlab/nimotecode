# NimoteCode よくある質問

## NimoteCode は SSH クライアント専用ですか？

いいえ。ローカルプロジェクト、Android Local Linux、SSH ワークスペースに対応し、Explorer、Editor、Terminal、Git、AI 支援、診断パネルを同じプロジェクトのコンテキストで利用できます。

## Pro なしでも使えますか？

はい。無料版にはローカル、Android Local Linux、SSH のワークスペース、エディター、基本ターミナル、AI Chat、基本的な Tasks が含まれます。Local Linux は Android 8 以降の 64 ビット ARM64 または x86_64 端末が必要で、iOS では使えません。AI Agent とリモート検索は、提供範囲を拡大中の Early Access Pro で利用できます。対象機能は [Pro](/ja/pro)をご覧ください。

## どの AI プロバイダーを設定できますか？

プロバイダーのテンプレートと、互換性のあるカスタムエンドポイントに対応します。利用可能なプロバイダー、モデルへのアクセス、料金は、ご自身のプロバイダーアカウントと設定によって決まります。[設定ガイド](/ja/docs/configuration)を参照してください。

## ソース管理は何に対応していますか？

すべてのユーザーがリポジトリの状態、差分、履歴を確認できます。コミット、プッシュ、stash などの制限付き Git 書き込み操作には Pro が必要です。[ソース管理](/ja/docs/source-control)を参照してください。

## Tasks はローカルとリモートのどちらで実行しますか？

Tasks は SSH ワークスペースで再利用するコマンドを実行します。接続中のワークスペースで実行され、別のディレクトリを指定しなければ、そのルートが作業ディレクトリになります。

## LSP とデバッグはすべてのプロジェクトで使えますか？

リモートホストに互換性のある言語サーバーやデバッグアダプターが設定されているか、またプロジェクトの構成によって異なります。Pro 機能です。[LSP](/ja/docs/lsp) と[デバッグ](/ja/docs/debug)を参照してください。
