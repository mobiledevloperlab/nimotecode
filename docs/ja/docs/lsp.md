# LSP 診断とコードアクション


LSP パネルは、アクティブなリモート ワークスペースに言語対応のフィードバックを追加します。互換性のある言語サーバーがホスト上に構成されている場合、診断から関連するソース行に移動して、使用可能なコード アクションを適用できます。 LSP は **Pro** ワークフローです。

## 実用的なLSPループ


1. リモートプロジェクトの言語サーバーを設定して確認します。

2. LSP を開き、最も重要なエラーに対して診断をフィルタリングします。

3. ソースの場所にジャンプし、コードアクションが提供されている場合はそれを適用します。

4. [ターミナル](/docs/terminal)で関連するチェックを再実行します。

5. 問題にさらに詳しいコンテキストが必要な場合は、[デバッグ](/docs/debug)または[AIチャットおよびエージェント](/docs/ai)を使用します。


言語サポートは、リモートホストにインストールおよび設定されているツールによって異なります。一部の診断では、使用できないコード アクションは正常です。 AI や LSP がすべての問題を自動的に解決できるという保証はありません。
