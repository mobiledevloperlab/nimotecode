# セキュリティと安全


NimoteCode は、SSH アクセス、プロバイダー資格情報、端末コマンド、ファイル変更を操作できます。このアプリは安全なストレージと制御されたワークフローのメカニズムを提供しますが、安全なリモート開発は依然として各ホストとアクションに対する選択に依存します。


## 資格情報とアクセス


- 機密性の高い環境には、最小権限の別の SSH アカウントを使用します。

- 重要なホストに対して秘密キー認証を優先し、セッションごとにホストとプロジェクトのルートを確認します。

- AI プロバイダーの認証情報を機密情報として扱います。アプリの保護されたストレージ フローでそれらを構成し、必要に応じてプロバイダーとともにローテーションします。

- サブスクリプションの検証を目的のアカウントとプラットフォームストアの ID に関連付けてください。


## AI エージェントと書き込みアクション


AI エージェントは、ツールの実行を単純なチャット応答から分離し、ファイルとコマンドの作業に検証層とロック層を適用します。ただし、特にワークスペースに運用アクセス権がある場合は、提案されたすべてのコマンドと変更を確認してください。コミットまたはプッシュする前に、[ソース管理](/docs/source-control) の差分レビューを使用してください。


## より安全なリモート ルーチン


1. SSH ホスト、ユーザー、およびワークスペースのルートを確認します。

2. 検査またはリスクの低いコマンドから開始します。

3. 端末出力と AI 提案をコンテキスト内で読み取ります。

4. 必要な最小限の変更を加えます。

5. 配信前にテストし、Git の差分を確認します。
