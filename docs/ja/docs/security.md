# 認証情報と操作の確認

## SSH アクセス

プロジェクトに適した権限を持つ SSH アカウントを使用します。セッションを開く際にホスト、ユーザー名、ワークスペースのルートを確認してください。プロキシ設定は接続経路に影響しますが、アカウントの権限は変更しません。

## プロバイダーの認証情報

API キーはプロバイダー設定フォームに入力します。プロンプト、プロジェクトファイル、共有ログには含めないでください。漏えいしたキーはプロバイダー側で失効させ、再発行してください。

## 計画とファイルの変更

Confirm モードでツールを承認する前に Agent の計画を確認します。プラグインのインストールや更新時には要求される権限を確認してください。コミット前には [Git の差分](/ja/docs/source-control)を確認し、関連するプロジェクトのチェックを実行します。
