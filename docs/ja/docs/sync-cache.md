# 同期とキャッシュ

<div class="doc-section">
<div class="doc-section__copy">

## 転送方向を選ぶ

**Sync** はローカルのプロジェクト内容をリモートワークスペースへ転送します。**Cache** はリモートの内容をローカルストレージに保存します。開始前に接続と表示されるパスを確認してください。Sync / Cache には Pro の利用権限が必要です。

</div>

## 転送を開始して確認する

表示位置が目的のプロジェクトでない場合は **Change** で変更してから開始します。完了後に結果と最近の履歴を確認してください。転送前にどちらのコピーを正とするか決めます。キャッシュ履歴はバージョン管理やバックアップの代わりにはなりません。
