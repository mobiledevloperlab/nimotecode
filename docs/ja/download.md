## 最初にすること

1. ローカルプロジェクトを開くか、SSH ワークスペースを追加します。
2. SSH では、ホスト、認証方法、プロジェクトルートを確認します。
3. ファイルを開いて小さな編集を保存し、`pwd`、`ls`、またはプロジェクトのテストを実行します。
4. AI Chat や AI Agent を使う場合だけ、AI プロバイダーを設定します。

無料プランには、ローカル、Android Local Linux、SSH ワークスペース、エディタ、基本の Terminal、Git レビュー、AI Chat、Tasks が含まれます。
