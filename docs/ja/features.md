# NimoteCode の機能

NimoteCode は、開発に必要な流れをモバイルにまとめます。**Explorer → Editor → Terminal → Git → AI** を、ローカルプロジェクト、SSH ホスト、または Android Local Linux で使えます。

## 無料で使える機能

| 機能 | 内容 |
| --- | --- |
| ローカル・SSH ワークスペース | 端末またはリモートホスト上のプロジェクトを開きます。 |
| コードエディタ | タブ、分割表示、保存、コピー＆ペースト、取り消し／やり直しを使えます。 |
| Terminal | ワークスペース内でコマンドを実行し、出力を確認します。 |
| Git レビュー | 状態、差分、ブランチ、履歴を確認できます。 |
| AI Chat と Tasks | コードやエラーの理解、作業の計画、繰り返すコマンドの保存に使えます。 |

## Pro のワークフロー

Early Access Pro では、AI Agent、リモート検索、複数ターミナル、Git 書き込み、LSP、デバッグ、Sync / Cache を提供します。提供状況と価格は、地域とアカウントに応じて Google Play または App Store で表示されます。

Android Local Linux は、対応する Android 8 以降の 64 ビット端末で使える root 不要の Ubuntu ワークスペースです。iPhone と iPad では、ローカルおよび SSH ワークスペースを利用できます。
