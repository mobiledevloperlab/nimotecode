# プライバシーポリシー


**発効日:** 2026 年 4 月 16 日


このプライバシー ポリシーでは、お客様が当社のモバイル アプリおよび関連サポート チャネルを使用する際に NimoteCode がデータを処理する方法について説明します。


## 1.範囲


このポリシーは、NimoteCode モバイル アプリケーションと公式サポート チャネルに適用されます。


## 2.当社が処理するデータ


### 2.1 アカウントとサインインデータ


サインインすると、Firebase Authentication を介して次のようなアカウント データが処理されます。


- ユーザーID

- メールアドレス（メールアドレス/パスワードによるサインイン用）

- サインインプロバイダーのメタデータ (Google サインインなど)


### 2.2 サブスクリプションおよびトライアルデータ


Pro 機能と試用版コントロールを提供するために、次の処理を行います。


- サブスクリプション資格と購入状態（RevenueCat およびアプリストア経由）

- トライアルステータスフィールド（トライアルの開始/終了、トライアルが使用されたかどうかなど）

- 試用版の繰り返しの悪用を防ぐために使用されるハッシュ化されたデバイス試用版識別子


### 2.3 ワークスペースとアプリの設定データ


使用状況に応じて、NimoteCode は以下を保存します。


- SSH プロファイルおよびワークスペース接続設定 (ホスト、ポート、ユーザー名、認証方法、ワークスペース ルートなど)

- アプリの設定と環境設定（テーマ、言語、エディタ、キーボードの環境設定など）

- ワークスペース`.nimote`パス内のワークフローメタデータおよびチャット/エージェント履歴（ワークフローに応じて、ローカルおよび/またはリモート）


SSHパスワードの処理:


- SSH パスワードは、開始した接続の認証にのみ使用されます。

- SSH パスワードはローカル プロファイル (接続設定) に**保存されません**。

- アプリで「パスワードを記憶する」オプションを選択した場合、パスワードはデバイスのプラットフォームの安全なストレージ (iOS キーチェーンまたは Android キーストア) に保存されます。保存された SSH プロファイルまたは接続を削除することで、いつでも削除できます。


### 2.4 AI構成とAIリクエストデータ


AI プロバイダーを構成すると、次の処理が行われます。


- 入力するプロバイダ構成値（プロバイダタイプ、ベースURL、モデル、APIキーなど）

- 送信することを選択したプロンプトとコンテンツ


AI リクエストは、構成したプロバイダエンドポイントにのみ送信されます。


AI API 資格情報ストレージ:


- AI API キーは、プラットフォームの安全なストレージ メカニズム (iOS キーチェーン / Android キーストアによるストレージなど) を使用して保存されます。

- AI API キーは、プレーンなアプリ設定ストレージには保存されなくなりました。


### 2.5 動作診断


当社は、信頼性、トラブルシューティング、セキュリティのために必要な限定的な操作ログを処理する場合があります。


診断の最小化:


- リリース ビルドでは、認証および資格情報のログが削減され、機密フィールドがマスクまたは省略されます。


## 3.データの使用方法


データは次の目的で使用されます。


- ユーザーを認証し、アカウントを保護する

- アプリ機能の提供（ワークスペース、エディタ、ターミナル、ソース管理、AI、タスク）

- サブスクリプションとトライアルの資格を確認する

- サービスの信頼性、セキュリティ、およびサポート業務を維持する


## 4.サードパーティとデータ共有


NimoteCode は、特定の機能についてサードパーティに依存しています。


- Firebase (認証および関連するクラウド バックエンド機能)

- RevenueCat (サブスクリプション資格の同期)

- App Store / Google Play (ストアポリシーに基づくアプリ内購入の請求、更新、払い戻し)

- ユーザーが選択した AI プロバイダー（ユーザーが構成した AI 推論エンドポイント）

- ユーザー選択のリモートサーバー（SSH/SFTP操作）


当社は個人データを販売しません。


## 5.権限とデバイスアクセス


NimoteCode は、写真、カメラ、マイク、連絡先、正確な位置情報などの機密デバイス データへのアクセスを要求しません。 Android と iOS の権限モデルは異なるため、宣言する権限は以下に個別にリストされています。


**Android** では、アプリはマニフェストで制限された権限を宣言します。

- `INTERNET` および `ACCESS_NETWORK_STATE`

- `com.android.vending.BILLING`（Google Play 定期購入の場合）

- `com.google.android.gms.permission.AD_ID`、アプリで使用される Google サービス ライブラリ（Firebase Analytics / Google Sign-In）の一部として宣言されています

- `READ_EXTERNAL_STORAGE` および `WRITE_EXTERNAL_STORAGE` は Android 9 以下でのみ、既存のファイルとワークスペースを開きます。 Android 10 以降では、アプリはストレージ アクセス フレームワークを使用するため、これらの権限は必要ありません


**iOS** では、アプリは写真、カメラ、マイク、連絡先、またはファイルに対する実行時の権限プロンプトを要求しません。


- ネットワーク アクセスは、リモート開発、認証、サブスクリプション チェック、AI/プロバイダー通信に使用されます。

- サブスクリプションとアプリ内購入はApp Storeを通じて請求されます（StoreKit、RevenueCat経由で統合）

- ファイルの選択にはネイティブのドキュメントピッカーが使用されるため、写真またはファイルライブラリへのアクセス権限は必要ありません


権限は、個人データの販売ではなく、アプリの機能に使用されます。


## 6.データの保持


- ローカル データは、ユーザーが削除するまで（たとえば、アプリ データのクリア、ワークスペースのクリーンアップ、`.nimote` の削除）までデバイス/ワークスペースに残ります。

- クラウド アカウント/サブスクリプションの記録は、サービスの運用、詐欺防止、セキュリティ、紛争処理、および法的遵守のために必要に応じて保持されます。

- 保存期間は法的および運用上の要件によって異なる場合があります


## 7.あなたの選択と権利


次のことができます。


- ローカルアプリ/ワークスペースデータを直接管理または削除する

- AI プロバイダー構成を削除して、そのプロバイダーへの新しいリクエストの送信を停止します

- **[設定] -> [アカウントの削除]** を使用して、アプリ内でアカウントの削除を開始します。

- サインインできない場合は、Web削除ページを使用してください: [アカウント削除](/account-delete)

- サポート連絡チャネル経由でアカウント/プライバシーに関するサポートをリクエストする


## 8.セキュリティ


当社は、合理的な技術的および組織的な安全対策を適用します。 100% 安全であることを保証できる送信方法や保存方法はありません。


現在の安全対策には次のものが含まれます。


- AI API 資格情報用の安全なストレージ (プラットフォームの安全なストレージ)

- 接続プロファイルに SSH パスワードを永続的にローカルに保存しない

- リリースビルドでの機密ログの削減および匿名化


## 9.子供たち


NimoteCode は、13 歳（またはお住まいの地域の該当する最低年齢）未満の子供を対象としていません。


## 10.国際処理


設定されたプロバイダーとインフラストラクチャは異なる地域で動作する可能性があるため、データは適用される法律に従って国外で処理される場合があります。
