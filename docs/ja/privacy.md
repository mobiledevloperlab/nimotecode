## 処理するデータ {#data}

| 利用場面 | データと目的 | 保存先・受信者 |
| --- | --- | --- |
| ログイン | ユーザー ID、メール、ログイン提供元の情報。Apple の転送メールやゲスト ID を利用する場合があります。 | Firebase Authentication とクラウドのアカウント管理。 |
| Pro・購入・試用 | 取引、ストア、利用権、有効期限、試用状態。権限確認と不正利用防止。 | RevenueCat、Apple / Google、Firebase。決済情報はストアが処理。 |
| 端末試用確認 | 端末・Firebase インストール識別子、または生成した代替識別子をハッシュ化。匿名化とは限りません。 | 元の識別子は端末で処理。確認用ハッシュと試用記録をバックエンドへ送信。 |
| 接続と設定 | ホスト、ポート、ユーザー名、パス、設定、保存した認証情報。 | メタデータは端末。秘密情報はシステムの安全なストレージ。接続先には認証に必要な情報を送信。 |
| AI・開発ツール | プロンプト、選択内容、関連コード、パス、ツール入出力、応答。依頼・承認した処理の実行。 | 選択した Provider、GitHub、MCP、外部 Agent とその接続先。 |
| 利用解析 | セッション、機能利用、プラットフォーム、バージョン、地域設定、ユーザー種別、ワークスペースのパス、操作メタデータ。ログイン時はユーザー ID と関連付く場合があります。 | Firebase Analytics。送信前に端末でキュー保存する場合があります。 |
| サポート | 送信したメール、説明、添付資料。AI 報告には応答の抜粋、理由、モデル、環境情報を含む場合があります。 | ローカル報告、送信後のサポートメール。公開 Issue は GitHub。 |

## 利用目的と動作診断 {#purposes}

接続設定には認証方式とワークスペースのルートも含まれ、環境設定にはテーマ、言語、エディター、キーボードが含まれます。AI 設定には Provider 種別、base URL、モデル、API Key が含まれます。SSH パスワードは利用者が開始する接続の認証に使い、通常の接続設定とは別の安全なストレージに保存します。現在の AI 設定保存でも API Key と通常の設定を分離します。

認証・アカウント保護、ワークスペース、編集、ターミナル、Source Control、AI、Tasks、購読・試用確認、安定性、安全、サポートのために使用します。

アプリは障害対応、安定性、安全のための動作ログを生成する場合があります。現在の共通ログ処理はリリース版の debug メッセージを抑制しますが、他のログやエラーがすべて匿名化・秘密情報除去済みであることを意味しません。診断ログと Firebase 利用解析は別です。ログや画像を自発的に送る前に認証情報と非公開プロジェクト内容を取り除いてください。

## 認証情報・履歴・ファイル {#storage}

アプリが管理する SSH パスワード、秘密鍵、パスフレーズ、プロキシ認証、AI API Key、GitHub トークン、MCP 設定は iOS Keychain または Android Keystore による暗号化ストレージを使用します。「SSH 認証情報を一切保存しない」という意味ではありません。保存済み SSH 接続や AI 設定を削除すると、対応する安全なストレージの認証情報も削除されます。

現在、AI 履歴は**既定でアプリ内のローカルストレージに自動保存**され、メッセージや復元用のツール・プロジェクト情報を含みます。自動保存の停止と既存履歴の削除は別操作です。AI 報告もローカルに保存され、削除または保存件数上限により除去されます。通常の履歴は認証情報用の安全なストレージとは異なります。

ファイル、同期キャッシュ、ワークフローや外部 Agent の記録は、別途端末、リモートホスト、`.nimote` などのワークスペースにも存在し得ます。アプリ履歴の削除では、それらや第三者が受信済みのデータは削除されません。

## AI と外部サービス {#integrations}

直接のモデル要求は選択した Provider に送信されます。Agent は権限、モード、作業内容に応じて関連ファイルを読み取り、ツール出力をモデルに渡します。初回送信前の AI プライバシー画面と承認内容を確認してください。

HTTP MCP はツール要求を受信し、stdio MCP は選択した端末・Local Linux・SSH 環境で動きます。外部 ACP Agent は独自の認証、通信、ログ、保存先を持つ独立した実行環境です。GitHub の操作や公開・共有により内容が他者に見える場合があります。

BYOK はデータの非保存や学習不使用を保証しません。各受信者の条件を確認し、不要な設定を削除するか、接続・認可を解除してください。送信済みのデータは受信者の削除手続きに従います。

## アプリ解析とサイト解析 {#analytics}

**アプリ：** 現行版は Firebase Analytics を初期化し、上表の利用情報を記録します。完全な匿名情報ではありません。現行アプリには全体の解析を停止するスイッチがなく、サイトでの選択はアプリ解析を停止しません。プライバシーのご依頼はメールで受け付けます。

**サイト：** 許可した場合のみ Google Analytics を読み込み、ページやリンクの利用を計測します。ページパス、リンク文字、接続先パス、キャンペーン、ブラウザー・端末情報、Cookie や識別子を使用する場合があります。拒否しても閲覧・ダウンロードリンクは利用できます。フッターの「サイトのプライバシー設定」から撤回できます。ログインユーザー ID、Google Signals、広告パーソナライズはサイト解析で使用しません。

選択はブラウザーに保存され、サイトデータの消去でリセットされます。ホスティング・配信・安全対策サービスは、ページ提供と不正防止のため IP、リクエスト、接続情報を処理します。

## 権限と提供元 {#providers}

Android はネットワーク、課金、通知、ユーザー開始の SSH 接続を維持する前景サービス、Android 9 以前の外部ストレージ権限を宣言します。`AD_ID` も宣言されており、識別子の扱いは OS と SDK の設定に依存します。iOS / iPadOS はネットワーク、選択した文書へのアクセス、ストア課金、タスク表示用 Live Activities を使用します。これらの機能のためのカメラ、マイク、連絡先、正確な位置情報アクセスは現在宣言されていません。通知・ロック画面の表示はシステム設定で管理できます。

[Firebase](https://firebase.google.com/support/privacy)、[RevenueCat](https://www.revenuecat.com/privacy/)、[Apple](https://www.apple.com/legal/privacy/)、[Google](https://policies.google.com/privacy)、[GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) はそれぞれの機能でデータを処理します。AI・MCP・SSH の接続先は設定次第です。国外で処理される場合があり、実際の構成に応じ適用法の通知・認可・保護要件に従います。個人データを販売しません。法的義務、安全、紛争対応に必要な開示を行う場合があります。

## 保持・削除と権利 {#retention}

アカウント削除成功時に認証アカウントと主ユーザー記録を削除し、現在の購読所有者との関連を解除します。取引、元ユーザー ID を含む削除関連記録、端末試用ハッシュなどは、権限確認、不正防止、紛争、法的義務のため残る場合があります。RevenueCat・解析・サポート資料のすべてが自動削除されるわけではありません。

ローカル履歴・認証情報・ファイルは個別に管理してください。解析・ログはサービスの保持設定と必要な安全・障害対応目的、サポート資料は対応と必要な法的保持に従います。全データ共通の保持日数はありません。例外保持は目的・義務・必要期間に限定され、該当記録の範囲と処理はお問い合わせいただけます。[削除の詳細](/ja/account-delete)。

設定 → アカウント削除、ローカル履歴の削除、連携停止、端末権限、サイト解析の拒否を利用できます。適用法に応じアクセス、訂正、コピー、削除、同意撤回、処理制限・異議申立てをメールで請求できます。必要な本人確認後、進捗、予定、対応できない理由を案内し、法定期限を優先します。パスワードや認証コードを送らないでください。

## 安全・未成年者・変更 {#updates}

安全な保存と認証措置を用いますが、すべての端末や外部環境の安全を保証できません。開発者向けサービスであり、13 歳未満または適用されるより高い最低年齢未満の方はアカウント作成や個人データ送信を行わないでください。ストアのコンテンツ年齢区分とは別の基準です。懸念がある場合はサポートへ連絡してください。

変更時は日付を更新し、データ用途・共有の重要な変更には必要な追加通知や同意手続きを行います。
