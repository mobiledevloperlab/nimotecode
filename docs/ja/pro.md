# NimoteCode Pro

NimoteCode は無料で始められます。ローカルまたは SSH プロジェクトを開き、ファイルを編集し、コマンドを実行して AI Chat を利用できます。Early Access Pro は、より高度なモバイル開発ワークフローのためのプランです。

<PricingFeatureSystem lang="en" mode="full" />

## Pro に含まれるもの

AI Agent、リモート検索、複数 Terminal、Git の書き込み操作、LSP、デバッグ、Sync / Cache を提供します。価格と利用可否は、地域とアカウントにより Google Play または App Store に表示されます。
