## 1.1.7 · 2026 年 9 月 12 日


2026 年 9 月 12 日にリリース (ビルド 41)。このリリースでは、Android Local Linux 開発環境が追加され、HTML とリンクのプレビューが改善され、エディター、AI、タスクの操作の信頼性が向上しました。また、外部 ACP エージェントと統合 SSH ログイン環境も提供されます。


### 新規


- **Android ローカル Linux ワークスペース。** サポートされている ARM64 および x86_64 Android デバイス上で、Bash、Git、SSH を備えたバンドルされた Ubuntu 環境を root アクセスなしで使用します。既存の SSH ワークスペース エクスペリエンスを通じて、環境をインストール、開始、停止、開く、リセット、または削除します。 iOSでは利用できません。

- **HTML スナップショット プレビュー。** ワークスペース CSS、JavaScript、および画像アセットを使用して、未保存の変更を含む現在の HTML エディターのコンテンツをプレビューします。ビルド ステップまたはバックエンドが必要なプロジェクトには、独自の開発サーバーが必要です。

- **リンク ボタン。** 共有ブラウザ アクションを介して、ターミナル、AI 応答、およびツール出力から Web リンクを開きます。

- **ローカル Linux の概要とオープンソース情報。** 環境ページでは、ストレージ、ネットワーク アクセス、プロセス ライフサイクル、削除動作について説明し、バンドルされているオープンソース ライセンスに直接アクセスできます。

- **Unified Agent のスラッシュ コマンド エントリ。** 新しい会話、停止、ステータスに対する組み込みアクションを使用して、タッチまたはキーボードで補完するには `/` と入力します。外部コマンドはアクティブな ACP セッションから取得され、実行中も最新の状態に保たれます。

- **外部 ACP エージェント。** SSH ワークスペースで ACP 互換の外部エージェントを選択して実行します。

- **エージェントの機能とセッション。** 機能、権限リクエスト、セッション状態、および実行の進行状況は 1 つのエクスペリエンスを共有し、組み込みエージェントと外部ランタイムの間で簡単に切り替えることができます。

- **リモート環境の更新。** ターミナル メニューからリモート ユーザーのログイン環境を再読み込みします。 SSH 再接続後も自動的に更新されます。


### 改善されました


- **わかりやすくなったエディタ ツールバー。** シンボル アクションが [その他] 内にグループ化され、ブラウザ ボタンがタイトル バーに移動します。 URL ダイアログは共有スタイルを使用し、アドレスを開く前にアドレスを検証します。

- **ローカライズされたインターフェイスの適用範囲。** ローカル Linux、ブラウザ コントロール、リンク ボタン、タスク アクション、および関連するエディタと AI メタデータは、ステータス、エラー、アクセシビリティ ラベルを含め、英語、簡体字中国語、日本語、韓国語、ロシア語をサポートします。

- **一貫したワークスペースエントリ。** ローカル Linux は、ワークスペース選択カードと標準のダイアログおよびボタンのスタイルを共有します。

- **一貫した AI コンポーザー アイコン。** コマンド、会話アクション、設定、および送信は、主なアクションと選択状態の強調を維持しながら、アプリのアイコン ファミリーとコンパクトなサイズを共有します。

- **シンプルな ACP 設定と一貫した実行プレゼンテーション。** 起動内部はデフォルトで折りたたまれます。未使用のプレースホルダーと実行不可能なオプションは非表示になります。ツールのメタデータと出力を実行すると、共有タイムラインが更新されます。

- **ACP 環境インポート。** リテラル `export` 割り当て、`NAME=value` 行、または JSON `env` オブジェクトを貼り付けます。解析ライブラリは、コマンドを実行せずにデータを検証します。プレビュー値はマスクされ、マージされたドラフトは保存する必要があります。

- **1 つの SSH ログイン環境。** ターミナル、ACP サーバー、エージェントのサブプロセス、タスク、デバッグ、言語サーバー、Git、および外部 CLI は、同じリモート環境リゾルバーを共有します。

- **ユーザーの実際のシェル。** NimoteCode はリモート アカウントのデフォルト シェルを検出し、回避策なしで bash、zsh、fish、およびその他のシェルに通常のログイン環境を読み込みます。
- **完全なカスタム ツールと変数の継承。** ユーザー定義の `PATH`、ロケール、SSH エージェント、およびカスタム サービス変数は、リモート プロセスに自然に流れます。

- **より安全な診断。** API キー、トークン、シークレット、パスワード、および類似の環境値は、ログおよびエージェント起動診断から編集されます。


### 修正済み


- エディターから戻ったときに、長いメッセージや遅延レイアウトを含む最新の AI コンテンツへのスクロールが復元されました。

- 保存が成功する前に変更されるタスクリスト、削除されたタスクが再表示される問題、および同時保存または更新により更新が失われる問題を修正しました。保存と削除は相互に排他的であり、失敗した操作はドラフトを保存し、構成の保存は一時ファイルを置き換えます。

- 重複するデフォルトのタスク ID、デフォルトの構成解析、および編集中に失われるタスクのメタデータを修正しました。

- SSH 権限および接続エラーが欠落ファイルとして扱われる問題を修正し、誤ってデフォルト タスク構成が作成されるのを防ぎます。

- 欠落していたエージェントのファイル変更概要、リモート環境の継承、折り返された行、スクロール、ワイド文字を使用した端末リンクの配置を修正しました。

- ターミナルでは機能するコマンドが、ACP エージェント、クロード コード、コーデックス CLI、タスク、またはデバッグで欠落しているように見える問題を修正しました。

- ACP サーバーが完全なリモート環境なしで起動し、不完全な設定をサブプロセスに渡す問題を修正しました。

- SSH 再接続後の古い環境と無効な `SSH_AUTH_SOCK` パスを修正しました。

- スペース、改行、シェルメタキャラクタを含む環境値の信頼性の低い継承が修正されました。
