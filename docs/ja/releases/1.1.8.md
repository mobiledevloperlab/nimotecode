## 1.1.8 · 2026 年 9 月 14 日 · ビルド 45


バージョン 1.1.8 は **Early Access Pro** を開始し、ワークスペースの切り替えをより柔軟にし、Android Local Linux のインストール、ファイル操作、Git の信頼性を強化し、ソース管理と全体的なビジュアル階層を改良します。


**プラットフォームの可用性:** ローカル Linux の改善は Android のみであり、iOS では利用できません。


### 早期アクセス プロ


Early Access Pro は、AI エージェント、リモート検索、Git 書き込みワークフロー、マルチターミナル、LSP、デバッグ、同期 / キャッシュなどの高度なモバイル ワークフローを、時間の経過とともにより多くのユーザーに公開します。在庫状況と表示価格はストア、アカウント、地域によって異なります。現在のオファーについては、Google Play または App Store を確認してください。


### 新規


- **ワークスペースディレクトリを切り替えます。** アクティブなローカルまたは SSH ワークスペースとして別のディレクトリを選択します。以前に開いたディレクトリは、すぐに戻ることができるように最近の履歴に保持されます。


### 改善されました


- **信頼性の高いローカル Linux (Android のみ)。** PRoot の起動とランタイムの準備がより堅牢になり、ゲストの一時ディレクトリが必要に応じて準備され、Ubuntu Base インストールの互換性が向上します。

- **ファイル アクセス境界の明確化 (Android のみ)。** エディター、検索、言語サービス、Git、ターミナル、およびエージェントの操作は、ローカル Linux で一貫したワークスペース スコープを使用するようになり、ランタイム境界を越えることによって発生するエラーが減少します。

- **より信頼性の高いローカル Linux Git (Android のみ)。** ローカル Linux ワークスペースでの Git 操作 (タスクによるファイル変更を含む) はゲスト環境を通じて実行されるため、ステータス、差分、および履歴は実際のワークスペースを反映します。

- **オープンソース配信の改善 (Android のみ)。** ローカル Linux には、より完全なパッケージ、ライセンス、およびソースの出所記録が含まれるようになりました。

- **視覚的な階層がよりシンプルになりました。** テーマ、パネル、タブ、ターミナル コマンド、および AI 実行タイムラインが改良され、主要なアクションを目立つようにしながら気が散る要素が軽減されました。


### 修正済み


- iPad の外部物理キーボードからの入力が応答しない問題を修正しました。

- ブランチ切り替え後にソース管理がすぐに更新されず、一貫性のないコミット履歴のスタイルが修正されました。

- ローカル Linux の一時ディレクトリのセットアップが不完全なためにコマンドまたはインストール フローが失敗するケースを修正しました。
