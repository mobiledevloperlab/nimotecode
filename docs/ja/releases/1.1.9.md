## 1.1.9 · 2026 年 9 月 27 日 · ビルド 48


バージョン 1.1.9 は、1 つの設計システム上にインターフェイスを再構築します。これは、利用可能なスペース、1 つの密度とステータス言語、IDE スタイルの AI タイムライン、および新しいインターフェイス スケールによって選択されるレイアウトです。これにより、PHP デバッグと幅広い構文ハイライトが追加され、エージェント セッション、エージェント検索、アクセス チェック、および起動の信頼性が向上します。


**プラットフォームの可用性:** ローカル Linux 検索の改善は Android のみであり、iOS では利用できません。


### 新規


- **PHP デバッグ。** Xdebug および PHP デバッグ アダプタを使用してリモート ワークスペースで PHP スクリプトをデバッグします。ブレークポイントを設定し、[デバッグ] パネルから起動して、エディタで Xdebug 環境を構成します。アダプターはスクリプトと同じリモート ホスト上で実行されます。詳細は `docs/php-debugging.md` にあります。

- **より広範な構文の強調表示。** C#、CSS、HTML、Ruby、Lua、Kotlin、XML、PowerShell、SQL および INI、JSX/TSX マッピング、PHP の強調表示 (`<?php` 自動検出を含む) の文法を Markdown コード フェンス内に追加しました。

- **プロバイダー モデルのリスト。** AI チャット ヘッダーとプロファイル エディターは、エンドポイントが実際に提供するモデル (OpenAI 互換の `/models` および Ollama `/api/tags`) を読み取り、オンデマンドで更新し、最後の選択を記憶するようになりました。プロファイルには、自分で名前を付けるまで、そのモデルにちなんで名前が付けられます。

- **エージェント セッション設定。** ハンドシェイク中に構成可能なオプションを報告するエージェントは、起動コマンドごとに記憶される AI ヘッダー内のモデルとセッションの選択を公開するようになりました。

- **インターフェイス スケール。** 設定 → 外観 → インターフェイス スケール (100% ～ 150%) は、アプリ全体 (クロム、アイコン、パネル、ダイアログ、エディター、ターミナル) を 1 つのズームとして拡大します。 iOS は Apple の文字サイズに合わせて 1 ステップアップして開始します。 100% オプトアウトします。


### 改善されました


- **利用可能なスペースによるレイアウト。** ワークスペースは、デバイスの向きではなく、そのスペースに基づいて構造を選択するようになりました。スペースのあるウィンドウは、レール、サイズ変更および折りたたみ可能なパネル、およびエディターに分割されます。ないものは片面の電話シェルを取得します。 Split View、サイズ変更可能なウィンドウ、縦向きのタブレット、横向きの携帯電話が適切なレイアウトに表示されるようになりました。

- **1 つのパネル設計システム。** パネルは 1 つの密度スケールと 1 つのステータス言語で再構築されました。電話機のエクスプローラーには、AI パネル、Git、デバッグ、LSP、およびタスクで、以前は 9 行が表示されていたところに 13 行が表示され、実行中、待機中、成功、警告、エラー、キャンセルの読み取りも同じになります。

- **IDE タイムラインとしての AI 会話。** ターンはチャットバブルではなくなりました。ユーザーのメッセージは引用符で囲まれたブロックであり、計画ステップは実際の状態を伝えます。各ツール呼び出しは等幅コマンドラインと変更されたファイルごとに `+n −m` を含む 1 つのコンパクトな行であり、変更のレビューではファイルごとに 1 行がリストされます。

- **ボタン、アイコン、コントロールに 1 つのスケール。** ボタン、空の状態、アイコン、コンポーザー、および中央パネルのコントロールはすべて 1 つのコントロール サイズを共有し、UI テキストはプラットフォーム フォントを使用し、コードとターミナルは 8 つのテーマすべてで実際の等幅チェーンを使用します。

- **ニュートラルな明るいパレットと暗いパレット。** 明暗はニュートラル グレーを中心に再構築され、状態、半径、ヘアラインに予約されたブランド アクセントが 1 つのはしごに収束され、すべての Git パネル セクションが 1 つのヘッダーを共有するようになりました。

- **1 つのメニュー サーフェス。** アンカー付きポップアップと下部シートは同じ行、アイコンのサイズと配置を描画し、メニューは最も幅の広いエントリに収まり、パネル ヘッダー コマンドはタブレットの幅から上のコマンド バーになります。
- **エクスプローラーの改良点。** ツリーを横にスクロールすると長いファイル名とディレクトリ名にアクセスでき、行には生のマテリアル リスト タイルの代わりにファイルとディレクトリによって共有されるタッチ サイズの 44 ピクセル バンドが使用されます。

- **洗練されたワークスペース クロム。** 縦方向の下部ナビゲーションの高さとアイコン ラベルの間隔が調整され、ワー​​クスペースの端にあるフローティング エージェント ステータス マーカーは丸いボールになり、以前と同じサイズと位置になりました。

- **より高速な、限定されたエージェント検索。** ワークスペース grep は、グローバル結果バジェットを使用して ripgrep を通じて実行され、ローカル Linux/PRoot 検索は、候補ファイルごとに 1 回のリモート読み取りではなく、`find` および `grep` を介してストリーミングされます。リファレンス 1000 ファイル フィクスチャでは約 3 秒から 0.2 秒です。

- **より明確なプロ アクセスのプレゼンテーション。** プロ アクセス カードとサブスクリプション ページでは、試用版、早期アクセス、有料および無料が 1 つのソースから説明されており、残りの試用期間、復元、別のアカウントにリンクされたサブスクリプションについてはより明確な文言が示されています。


### 修正済み


- 保存された接続を再度開いた後、貼り付けまたはインポートされたキー資格情報が失われる SSH 秘密キー接続を修正しました。インポートされたキーは、一時的なファイルピッカー パスに依存するのではなく、安全に保持されるようになりました。

- Android Local Linux Explorer が `/workspace` からゲスト ルートおよび `/home` などのディレクトリに移動できない問題を修正しました。

- 電話の「詳細」メニューとポップアップを修正しました。Git、エディター、およびターミナルのメニューは、残りのアプリが使用するものと同じアンカー付きポップアップを開くようになり、画面いっぱいに表示されるのではなく最も広い行に収まり、ソフトキーボードが起動している間は使用可能なままになり、エントリがページを開いた後に独自のページを画面上に残さなくなりました。

- ターミナルヘッダーを、前端にタブ、後端にコマンドを備えた 1 つの VS Code スタイルのバンドに作り直し、iOS が 1 回の Return キーを 2 回送信する問題を修正しました。

- Android および iOS の起動画面を修正し、ワークスペースが描画されるまで、1 つのネイティブ起動レイヤーがアプリ独自のテーマと言語でブランド マーク、スローガン、読み込みバーを保持するようにしました。

- キル スイッチの欠落または到達不能、RevenueCat ID の再調整の失敗、またはサーバーまたはデバイスのクロック スキューにより、サインインしているユーザーに対して早期アクセスと有料 Pro が拒否される問題を修正しました。

- 履歴のスクロール中に AI トランスクリプトがリーダーの場所を失う問題、ファイルが開いていない状態でエディターに表示される境界線と重複した [ブラウザを開く] ボタンが表示される問題、SSH、エディター検索、Git、設定、およびエクスプローラーのファイル検索シートでモーダル シートを閉じた後のクラッシュを修正しました。

- Git Commit Detail と Diff 上部の間隔と読みやすさ、サイドバーの選択アニメーション、ブラウザ ボタンと衝突する LSP コマンド、一貫性のない URL プロンプト、エージェント パラメータ行および Git 履歴ヘッダーのスタイルを修正しました。
