## 1.2.2 · 2026 年 10 月 9 日 · ビルド 52


バージョン 1.2.2 は、アプリ サンドボックスの外側でプロジェクト フォルダーを開き、Git をランドスケープ エディターに導入し、作業中に Git のステータスとターミナル セッションを最新の状態に保ちます。


### 新規


- **外部プロジェクト フォルダーを開きます。** Android および iPadOS/iPhone では、システム フォルダー ピッカーを使用して、アプリ独自のドキュメント フォルダーの外にあるプロジェクト ディレクトリを開くことができます。 NimoteCode はプラットフォーム許可を通じてアクセスを要求し、再起動後もそれを記憶し、安全なファイル プロバイダーを通じて読み取りと書き込みを行います。これらのワークスペースは、生の URI ではなく分かりやすい場所を表示し、ネイティブ ファイルシステム パス (Git、LSP、デバッグ、タスク、ファイル ウォッチャー、エージェント) を必要とする機能が事前に報告されます。

- **ランドスケープ エディターの Git ページ。** ドッキングされたランドスケープ ワークスペースでは、Git の差分、コミット差分、および競合解決ページがエディター領域 ([設定] が表示されるのと同じ場所) で開くため、IDE コンテキストを離れることなく変更を確認できます。縦向きでは、既存の全画面ページが維持されます。

- **ほぼリアルタイムの Git ステータス。** エクスプローラーの装飾とソース管理パネルは、次のポーリングを待つのではなく、ターミナル、エクスプローラーの操作、または外部ツールからファイルが変更されると更新されるようになりました。


### 改善されました


- **ランドスケープ ディレクトリ ピッカーは全幅を使用します。** ドッキングされたランドスケープ ワークスペースでローカル フォルダーまたはリモート フォルダーを開くと、ピッカーが 2 つのペインに分割されます。左側でフォルダーを参照し、パスを編集し、右側でピッカーが指すフォルダーを表示します。縦向きのウィンドウと狭いウィンドウでは単一列が維持されます。ランドスケープの空の状態でも、そのイラストがアクション リストの横に配置されます。

- **外部ワークスペースのフレンドリ名。** 外部ワークスペースでは、エクスプローラ、エディタのタブ、ブレッドクラム、Markdown プレビュー タイトルおよび検索結果には、生の `content://` アドレスの代わりにプロバイダのフォルダ名とファイル名が表示されます。

- **カードベースのランドスケープ パネル。** ランドスケープの中央パネルがエディタ カードと一致するようになりました。エディタの表面と丸い角を共有し、アクティビティ レールが高さいっぱいに伸び、パネルとエディタの間のドラッグ ストリップは中央に留まります。

- **エクスプローラーの密度が高くなります。** 新規インストールでは、デフォルトのエクスプローラー ディレクトリのテキストが 14、行の高さが 35 に設定されるため、携帯電話やタブレットでは一度により多くのアイテムが表示されます。保存した設定は引き続き有効です。

- **邪魔にならないターミナル プリセット。** 「/」クイック アクセス プリセットが追加され、プリセットをタップしてもソフト キーボードが閉じられなくなりました。プリセットはアクティブな端末に書き込み、端末がすでにキーボードを所有している場合にのみフォーカスを復元します。

- **SSH セッションは短時間の中断でも存続します。** 短いバックグラウンド サイクルの後、NimoteCode は接続が失われたと宣言する前にトランスポートを再チェックするため、ライブ セッションはスクロールバックを維持します。本当に停止したセッションでも再接続されます。


### 修正済み


- 新規インストールでは、デバイス言語に従うか中国語に戻るのではなく、デフォルトで英語になります。明示的な言語の選択はまだ記憶されています。

- ローカル エクスプローラーのヘッダーの下にある重複する分割線を修正し、ローカル エクスプローラーとリモート エクスプローラーが単一のヘアラインを描画できるようにしました。

- テーマが変更されたときに Explorer のセッション履歴とリモート ディレクトリ ピッカー ページが再描画されない問題を修正しました。

- サブディレクトリの変更が欠落しているローカル Git ステータスと追跡されていないファイルを修正しました。

- 外部ワークスペースでファイルを書き込んだり削除した後の Android のクラッシュを修正しました。
