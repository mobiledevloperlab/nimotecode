## Nimoteコード 1.2.5


バージョン 1.2.5 は、日常のプロジェクト管理をより効率的にします。Explorer はバッチ ファイル アクションに加えてファイル サイズとロードされたディレクトリ数を獲得し、AI と SSH ワークフローはより直接的なフィードバックを提供し、IDE は電話、タブレット、デスクトップ間でより一貫性があります。


### 新規


- **バッチエクスプローラーアクション。** 複数のファイルまたはフォルダーを選択して、まとめてコピー、移動、または削除します。ローカル、リモート、および外部ストレージのワークスペースは、サポートするアクションを公開します。

- **エクスプローラーの詳細が強化されました。** ファイル リストにはファイル サイズが表示され、展開されたフォルダーにはロードされたアイテムの数が表示されるようになり、プロジェクト構造を簡単に確認できるようになりました。

- **AI クイック アクション。** 新しい会話を開始したり、空の AI チャットから直接 AI 設定を開いたりできるため、次のタスクはタップするだけです。


### 改善されました


- **より信頼性の高い SSH 接続フィードバック。** 接続すると進行状況がすぐに表示され、重複した接続試行が防止されます。

- **より明確で一貫性のあるワークスペース。** 中央パネルのタイトル、ツールバー、区切り線、タイポグラフィ、アイコンのサイズ、間隔、テーマのコントラストが統一されています。モバイルのフローティング ナビゲーション、Markdown ドキュメントのプレビュー、通知もさらに洗練されています。

- **AI モデルの切り替えが簡素化されました。** モデル メニューと構成切り替えフローで不要な手順が減りました。


### 修正済み


- モーダル シート、パネル、ローカル Git エントリ ポイント間の調整が改善され、視覚的な改良がローカル Git アクセスを妨げなくなりました。
