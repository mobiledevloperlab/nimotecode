# NimoteCode 2.0.0 リリースノート

<LatestReleaseLink />

[すべてのリリースノートを参照](/ja/releases/)

## NimoteCode 2.0.0

NimoteCode 2.0 では、IDE が安全にカスタマイズできるワークスペースへ進化しました。AI Agent 作業を継続しながら、Git、ターミナル、日常の編集をより一貫した操作性で扱えます。

<span id="release-new"></span>

### 新機能 · 5

- **プラグインセンターとカスタムワークスペース。** 機能センターからワークスペース機能を管理し、カスタムプラグインと宣言型パネルを作成できます。ローカルまたは SSH 接続先で、フォーム、ワークフロー、成果物ビュー、スクリプトジョブを利用できます。インストールまたは更新の前に、権限の変更がレビュー用に表示されます。
- **継続的な AI Agent 連携。** 実行中の Agent に追加指示を送り、必要に応じて対話式の質問に回答できます。コンテキスト、履歴、プロンプト編集、実行タイムラインも、長時間の作業に適するよう再構築されました。
- **Git ブランチと差分の改善。** Git ヘッダーからブランチを検索、作成、チェックアウトできます。エディターでは控えめなガターで Git の変更を示し、より明確なシンタックスハイライトで差分を表示します。
- **より直接的なターミナル支援。** ターミナル出力を AI に直接送って分析でき、ターミナルタブの設定にもより簡単にアクセスできます。
- **柔軟なリモート接続。** ネットワーク環境で必要な場合は、SOCKS5 または HTTP CONNECT プロキシ経由で SSH ワークスペースに接続できます。

<span id="release-improved"></span>

### 改善 · 6

- **刷新されたビジュアルとレイアウトシステム。** Material 3 のスタイル、テーマ、設定、Explorer ツールバー、空の状態、Markdown プレビュー、起動アニメーションが、より一貫したデザインになりました。デフォルトの UI スケールは 90% となり、作業のためのスペースをより広く使えます。
- **より堅牢なプラグインランタイム。** プラグインパネルは実行状態を保持し、古い更新を回避します。フォアグラウンドワークフローでは段階的なフォーム入力に対応し、永続的なジョブは対象環境で継続できます。プラグインを削除すると、そのジョブは安全にキャンセルされます。
- **より効率的な AI とリソースの利用。** 長いチャットは会話ラウンドごとに折りたたまれ、履歴は必要に応じて展開できます。非表示のパネルは不要な更新を停止し、エディターとチャット履歴のメモリ使用量も抑えられます。
- **より自然なモバイルワークフロー。** Android の AI エントリーは Dynamic Island スタイルのコントロールになり、アカウント、サブスクリプション、外観、共有入力の各画面は画面サイズに応じてより一貫して適応します。
- **すべてのデバイスで統一されたエディター。** Nimote Editor がスマートフォン、タブレット、デスクトップのデフォルトエディターになりました。テキスト選択、キーボードと IME の動作、取り消し、貼り付け、検索と置換、キャレット処理を、すべてのフォームファクターで一貫して提供します。
- **ワークスペースに合うターミナルカラー。** 設定可能なターミナルカラーパレットを選択できます。ターミナルとモバイルのシステム UI は、アクティブなテーマに合わせて視覚的に統一されます。

<span id="release-fixed"></span>

### 修正 · 5

- プラグインメタデータの互換性、権限更新、パネルスクロール、ジョブキャンセルに関するエッジケースを修正しました。
- 実行タイムライン内での AI フォローアップの配置、共有入力の垂直方向の配置、Explorer ツールバーのレイアウトを修正しました。
- 組み込み Agent ランタイムとワークスペースツールの信頼性およびセキュリティ境界を強化しました。
- 特にモバイルキーボード使用時やセッション再接続時に発生する、エディターとターミナルのフォーカス、選択、行編集、非同期セッションに関するエッジケースを修正しました。
- 長時間実行する Agent タスクの出力を、より明確でコンパクトに改善し、設定したステップ予算に達した際に継続する選択肢を追加しました。
