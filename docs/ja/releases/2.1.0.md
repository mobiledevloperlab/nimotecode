## NimoteCode 2.1.0

2.1.0 では、デバイスをまたぐワークスペースを改善し、大規模コードベース向けの内蔵 Agent をより効率的で安定したものにしました。特に非常に長い行や圧縮されたファイルで効果を発揮します。

<span id="release-improved"></span>

### 改善 · 5

- **より効率的なコード検索。** Agent は検索結果のコンテキストを必要な範囲に絞り、表示するテキストだけを構築します。大きなファイルや圧縮ファイルの検索時に、メモリ使用量と待ち時間を抑えます。
- **より安定したファイル要約。** ファイルを要約する際、Agent は最も関連性の高いコード抜粋を保持しつつ、長いファイルの処理を軽くし、一貫した結果を維持します。
- **デバイス間で統一されたワークスペース。** 外観モードとアクセントカラーを別々に選べます。スマートフォン、タブレット、デスクトップで、レイアウト、コントロール、文字組みがより一貫しました。
- **よりスムーズな横向き表示と編集。** 横向きではワークスペースページと Git 履歴をエディタータブとして開けます。全画面ターミナル後もエディターヘッダーを保持し、描画、ハイライト、Git 差分の文字組みも改善しました。
- **より直接的な検索とモバイル操作。** ファイル検索を直接開け、リモート接続の状態はディレクトリ名の横に表示されます。モバイルの Agent とターミナルでは、ドラッグ、キーボード選択、コピー操作もよりスムーズです。
