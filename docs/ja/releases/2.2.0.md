## NimoteCode 2.2.0

2.2.0 では GitHub ワークフローを NimoteCode に統合しました。専用の GitHub ページでサインインし、リポジトリを参照してプロジェクトを開いた後、使い慣れたワークスペースでブランチ、Issue、プルリクエスト、CI を扱えます。このリリースでは Android Local Linux 向けの実験的な開発ツールキットも追加し、検索の信頼性を高め、アプリ全体のパネルと会話の体験を統一しています。

<span id="release-new"></span>

### 新機能 · 3

- **ネイティブ GitHub 開発ワークフロー。** ブラウザーのデバイス認証またはトークンでサインインし、リポジトリ、ブランチ、リポジトリ詳細を参照して、ローカルまたは SSH ワークスペースにプロジェクトをクローンして開けます。
- **Issue、プルリクエスト、CI のコラボレーション。** Issue、プルリクエスト、レビュー、チェックを参照・絞り込みできます。Issue のコンテキストで Agent タスクを開始し、作業後にブランチ作成、push、fork、プルリクエスト作成を行えます。
- **Android Local Linux ツールキット（実験的機能）。** コマンドラインの基本ツール、Python、Web ツールを必要に応じてインストールできます。Linux の再インストールや既存プロジェクトの上書きをせずに、サンプルプロジェクトを作成、実行、オープンできます。初回インストールにはインターネット接続が必要です。

<span id="release-improved"></span>

### 改善 · 5

- **より安定した GitHub 操作。** サインイン、プロジェクトのクローン、Local Linux ワークスペースの操作がより安定し、push や公開に失敗した場合の復旧手順も明確になりました。
- **より堅牢なワークスペース検索。** 検索結果、ハイライト、モバイル操作の信頼性が向上しました。Android Local Linux のコード検索は追加設定なしで利用できます。
- **より一貫したワークベンチ。** 設定、ソース管理、GitHub、検索などのパネルで、サーフェス、文字組み、コントロール、狭いレイアウト時の挙動を統一しました。会話と概要のレイアウトも見やすくなりました。
- **より分かりやすいツールキットの状態。** インストール前にダウンロード量と必要容量の目安を確認でき、準備後はサンプルとツールチェックに集中できます。タスクログ、再試行、中断のフィードバックで復旧を支援し、ページを離れてもタスクはキャンセルされません。文字組み、間隔、ボタン、確認ダイアログもワークベンチに合わせました。
- **一貫したコピーのフィードバック。** 共通パネルからのコピーで、明確で統一されたフィードバックを表示します。

<span id="release-fixed"></span>

### 修正 · 2

- 一時的な GitHub API の失敗、モバイル HTTPS クローン、キャンセル、クローン先の復旧に対応し、使用すべきでない Git 操作に認証情報が渡らないようにしました。
- リモートワークスペースの検索結果とハイライトを改善し、大きな結果やモバイル操作時の停止・表示問題を軽減しました。
