## NimoteCode 2.3.0

2.3.0 では IDE、ターミナル、AI を切り替えても、同じプロジェクトと Explorer の状態を維持できます。プラグイン、Windows SSH、Agent、ターミナル、モバイル Git レビュー、SSH ホスト上の Docker 開発も改善しました。

<span id="release-new"></span>

### 新機能 · 6

- IDE、ターミナル、AI モードを切り替え、同じプロジェクトと Explorer の状態を引き継げます。
- プラグインはバージョン付きの拡張と依存関係を宣言し、インストール前に検証できます。承認済みのツール、スキル、ワークフローを Agent に提供できます。
- PowerShell/SFTP で Windows のリモートワークスペースを開き、検索、Git、ターミナル、言語サービス、Agent を利用できます。
- 対応 ACP Agent に実行中のタスクへの追加指示を送れます。
- SSH ホストでコンテナ、イメージ、ボリューム、ネットワーク、Compose を管理し、ログ、統計、exec、Docker Hub 検索を利用できます。
- devcontainer.json から Dev Container を作成または再構築し、設定済みの隔離ワークスペースを開けます。

<span id="release-improved"></span>

### 改善

- ターミナル分割、出力から IDE への移動と AI 分析、コマンド履歴、表示設定の保存、ズーム、接続別プロンプトを追加・改善しました。Git レビュー、Windows SSH、Agent 診断、Docker の復旧性と権限状態も改善しました。
