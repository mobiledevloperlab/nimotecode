# NimoteCode 2.4.1 · Host ワークスペースとファイル転送

2026 年 11 月 19 日 · Build 66

<LatestReleaseLink />

[← すべてのリリース](/ja/releases/)

2.4.1 は画面とタブレットのレイアウトを刷新し、リモートのターミナルや Agent セッションを管理する Host ワークスペースを追加します。ファイル転送とプロジェクトタスクの検出に対応し、GitHub CI、ターミナル履歴検索、リモート保存を改善します。

<span id="release-new"></span>

### 新機能

- **Host ワークスペース**：対応する NimoteHost をリモートでインストール・起動し、SSH で接続してリモートのターミナルや Agent セッションを表示・再開できます。
- **Host Agent セッション**：対応セッションで構造化対話、承認、コマンド、モデル設定を利用できます。
- **Host タスク受信箱**：タスク、検証結果、差分を確認し、GitHub Issue を Agent に依頼できます。利用できる機能は Host の機能と設定に依存します。
- **Host プラグイン**：対応する Host プラグインを利用し、プロジェクトタスクをワークスペースのターミナルに関連付けられます。
- **ファイルとフォルダーの転送**：端末と SSH ワークスペース間の転送、ローカルでのインポート・エクスポートに対応します。
- **プロジェクトタスクの検出**：npm、Taskfile、Makefile、justfile、VS Code のタスク定義から対応タスクを検出できます。

<span id="release-improved"></span>

### 改善

- **画面とタブレット対応**：ワークベンチを刷新し、横画面、タブレット、編集操作、モバイルの Git レビューを改善。Explorer に Git 状態の色を表示します。
- **ワークスペースとプラグイン**：IDE・ターミナル・AI の切り替えでプロジェクトと Explorer の状態を維持。プラグイン、対応 Agent への実行中の追加指示、Windows SSH を改善します。
- **ターミナル操作**：応答性、検索、スクロール、クリップボード、対話型プログラムを改善。保持された履歴の検索、全角文字の選択、マウス入力に対応します。
- **ターミナルと開発ツール**：出力内のファイル位置を開き、選択した出力を AI に送り、対応するコマンド記録を確認できます。適応型分割、SSH 上の Docker・Compose 管理、Dev Container 作成に対応します。
- **GitHub CI**：ワークフロー実行を絞り込み、ステップログとエラーの前後を確認できます。
- **設定とアクセシビリティ**：アプリ設定の入口を統合し、視差効果を減らす設定への対応を改善。Agent の音と振動、行番号、横画面のミニマップを設定できます。
- **SSH とリモート保存**：SSH ホストの検証とリモート保存の安定性を改善。Windows ホストへの保存も対象です。

<span id="release-fixed"></span>

### 修正

- 各種不具合を修正。

Host 機能には対応する NimoteHost が必要です。Agent とプラグインの提供状況は Host の機能と設定に依存します。
