# NimoteCode 2.5.0 · ペアリング済み PC への SSH、永続ターミナル、NimoteHost のセットアップ

公開予定 · Build 68

[現在の公開版 · 2.4.1](/ja/releases/2.4.1) · [← リリース履歴](/ja/releases/)

### リモート接続と Host

- 接続選択画面でペアリング済みの PC を選び、同期された Tailscale IP または MagicDNS 名と、普段の SSH パスワードまたは鍵を使います。ペアリング解除と手動 SSH 接続も利用できます。
- Nimote Connect のインターネット経由の接続は計画中です。Free と Pro の利用枠は未定です。通常の SSH と個人用 Tailscale を利用できます。
- 低速・不安定な回線での SSH 接続と復旧、ターミナル入出力、サイズ変更、SFTP 読み取りを改善しました。Android では SSH 鍵ファイルの互換性も向上しました。
- Host パネルで NimoteHost の状態とバージョンを確認し、承認後に SSH 経由でインストール、起動、パネルで案内されるリリースへの更新ができます。エラーの理由と再試行を表示し、更新でセッションの停止が必要なら事前に確認します。
- **ペアリングと復旧。** Relay は認証、PC の確認、トンネル接続、SSH ログインを段階ごとに表示します。ペアリングを解除すると Relay でのアクセス権も取り消されます。対応する Host では、同じ PC の検証済み経路から同じワークスペースを開けます。

### ターミナル

- Pro では、tmux を導入した対応 SSH ホストで、ターミナルメニューから永続セッションを作成・再開できます。ローカルのタブを閉じても処理は継続し、同じメニューからセッション自体を終了できます。
- tmux の履歴スクロール、初回描画、カーソルの位置、横向きでのキーボード操作を改善しました。詳細検索は中国語入力の変換確定を待ちます。
- ダブルタップや幅の広い文字の選択を改善しました。Codex や Claude Code などがマウスを使う場合は、Shift を押してドラッグし、右クリックメニューでコピーできます。再描画後も選択範囲をコピーできます。
- **ターミナル操作。** 履歴やリモート一覧から tmux に戻れます。同じ SSH ユーザーなら別の端末からも再開できます。スマートフォンの横向きでソフトウェアキーボードを開き、十分な高さがある場合は Esc や Ctrl が表示されます。通知の表示中もメニューを使えます。

### ワークベンチ、エディター、Git

- 縦向きのスマートフォンにフローティングナビゲーションを追加しました。IDE と Host の操作を揃え、単一ペインの空のエディターからファイルを開けます。
- ワークスペース検索からファイルを開いて一致箇所を強調表示します。SSH 検索、大きなフォルダーの展開、分割画面のタブ操作、スクロールバーをドラッグするときの選択保持を改善しました。
- エディターから Git ファイル履歴を直接開けます。ファイルの名前変更を追跡し、失敗時に再試行できます。大規模リポジトリの変更一覧は必要に応じて読み込みます。
- 選択範囲のコントラストとコピー、リモートフォルダーの選択、タスク保存・削除中の入力制御を改善しました。
- **Git 履歴と Agent レビュー。** ファイルと行の履歴は、履歴が空の場合と読み込みエラーを区別します。再試行やリモートディレクトリの別名にも対応します。スナップショットがない場合はレビューカードに理由と現在の Git 差分への入口が表示されます。

### AI と対応プラットフォーム

- 内蔵 Codex の応答、キャンセル、ツール呼び出しを改善しました。Agent は中断した履歴を復元してもキャンセル済みターンを保持し、大規模リポジトリでのファイル操作と検索も改善しました。
- Android のローカル Linux がマニフェスト形式の開発ツールキットに対応し、コミュニティが同じ形式で参加できます。iOS の起動処理を改善し、デスクトップのメールログインを修正しました。デスクトップ版の権限はアカウントに基づきます。
- Free では Git の状態と差分の確認、ステージング、ステージ解除、コミットができます。GUI でのプッシュ、プル、ブランチとスタッシュの操作、Git AI、高度な GitHub 連携には Pro が必要です。 Docker と Dev Container には Pro と対応ホストが必要です。 デバッグには Pro と設定済みのデバッグアダプターが必要です。
- **ワークベンチと対応環境。** ワークスペースメニューから GitHub やサンプルにアクセスできます。AI 入力欄のタップ領域が広がり、画面が低い場合は空の会話をスクロールできます。タスクとプラグインは利用可能なターミナルを案内します。ローカル Linux は Android に対応しています。
