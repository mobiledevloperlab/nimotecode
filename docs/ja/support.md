# NimoteCode サポート

お問い合わせには、端末、アプリのバージョン、問題の安全な説明、エラーメッセージを添えてください。パスワード、秘密鍵、API キーは送らないでください。

## よくあるお問い合わせ

- **SSH 接続**：ホスト、ポート、ユーザー名、認証方法、ネットワーク到達性を確認してください。
- **AI プロバイダー**：ベース URL、モデル名、プロバイダーアカウントのアクセスを確認してください。NimoteCode は BYOK です。
- **Pro の復元**：購入に使用したアカウントでサインインし、ストアのサブスクリプションを確認してから、アプリで復元を実行してください。

## お問い合わせ

アカウント、サブスクリプション、非公開のサポート依頼は [support@nimotecode.com](mailto:support@nimotecode.com) へメールしてください。再現可能な不具合と機能提案は [GitHub Issues](https://github.com/mobiledevloperlab/nimote_issues/issues) をご利用ください。

プライバシー、アカウント削除、利用規約は現在 [English support pages](/support) で確認できます。
