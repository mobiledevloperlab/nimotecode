## 最初の確認 {#quick-checks}

**SSH：** host、port、username、認証方式、ネットワーク到達性を確認してください。保存済み接続から開始し、`pwd` などの読み取り専用コマンドで現在のパスを確認します。

**AI Provider / API Key：** base URL、モデル名、Provider のアクセス権を確認してください。モデル利用と API 料金は提供元に従います。API Key をサポートに送らないでください。

## 購入・解約 {#purchases}

元の Apple / Google ストアアカウントを確認し、次に NimoteCode アカウントと **Restore Purchase** を確認してください。両者は別のアカウントです。復元のために再購入しないでください。

| 操作 | Apple | Google Play |
| --- | --- | --- |
| 管理・解約 | [定期購入](https://apps.apple.com/account/subscriptions) | [定期購入](https://play.google.com/store/account/subscriptions) |
| 返金 | [返金申請](https://reportaproblem.apple.com/) | [返金案内](https://support.google.com/googleplay/answer/2479637) |

削除・アンインストール・ログアウトでは購読は解約されません。通常は支払済み期間終了まで利用可能です。アプリの試用・Early Access と、有料化し得るストア試用を区別してください。[利用規約](/ja/terms#billing)。

## AI 応答の報告 {#ai-report}

現在の報告操作はローカル保存後にメール草稿を開きます。**保存・草稿作成だけではサポートに届きません。** 内容を確認して送信してください。メールアプリがない場合は必要な内容だけをメールで送れます。理由、Provider、モデル、版、該当応答の抜粋で十分です。
