# モバイル ワークスペースのデモ

## 重点を置いたモバイル ループ


1。ローカル プロジェクトを開くか、目的の SSH ホストとプロジェクト ルートに接続します。

2。関連するファイルを調べて、エディターで目的の編集を行います。

3。ターミナルを使用して、ログを確認し、テストを実行し、変更された動作を確認します。

4。コミットまたは配信ステップの前に、ソース管理で結果の差分を確認します。


ワークフローは、プロジェクトに必要なレビュー、アクセス制御、検証に代わるものではなく、デスクから離れた実際の限定された作業用に設計されています。
