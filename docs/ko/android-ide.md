# SSH, Git 및 AI 코딩을 위한 Android IDE


Android는 서버 확인 장치 그 이상일 수 있습니다. 올바른 도구를 사용하면 개발 작업을 위한 실용적인 환경이 됩니다. SSH를 통해 자체 개발 시스템에 연결하고, 저장소를 열고, 집중적으로 변경하고 확인하는 등 모든 작업이 휴대폰이나 태블릿에서 가능합니다.


NimoteCode는 해당 워크플로를 중심으로 구축된 **Android IDE**입니다. Explorer, 코드 편집기, SSH 터미널, Git 검토, LSP, 디버거, AI 채팅 및 에이전트를 하나의 모바일 작업 공간에 결합하므로 Android는 여전히 데스크톱, 노트북 또는 서버에 있는 프로젝트를 계속 작업할 수 있는 실용적인 방법이 됩니다.

## Android IDE가 수행해야 하는 작업


Android IDE는 전체 루프를 한 곳에 보관해야 합니다. 즉, 프로젝트 이해, 파일 편집, 명령 실행, 결과 미리보기, 출시 내용 검토 등이 가능합니다. 이는 로컬 파일용 독립 실행형 코드 편집기와 다르며 셸 텍스트만 표시하는 SSH 클라이언트와도 다릅니다. 프로젝트, 터미널 및 Git 기록은 동일한 작업 공간에 속합니다.


## 유용할 때


- 노트북을 사용하지 않아 서비스를 조사하거나 수정해야 합니다.

- 전화나 태블릿에서 차이점을 검토하고 잔돈을 배송하고 싶습니다.

- SSH를 통해 Mac, Linux 박스 또는 서버에 연결하고 터미널 옆에 편집기와 Git 보기를 원합니다.

- 붙여넣은 스니펫 대신 실제 프로젝트를 읽어주는 AI 도움말을 원합니다.


## NimoteCode가 적합한 방식


 [SSH 작업 영역](/docs/ssh)을 사용하여 개발 머신에 연결하고 프로젝트 루트를 선택합니다. 프로젝트는 원격 호스트에 유지됩니다. 파일과 터미널 출력은 SSH 연결을 통해 이동하므로 복사본을 장치에 동기화할 필요가 없습니다. 장치에 저장된 프로젝트의 경우 로컬 탐색기는 동일한 방식으로 작동합니다.


## Android의 실제 워크플로


1. 개발 호스트에 대한 SSH 프로필을 저장하고 프로젝트 루트를 엽니다.

2. 경로를 외워두는 대신 탐색기에서 해당 파일을 찾아보세요.

3. 편집기에서 최소한의 안전한 변경을 하세요.

4.  [터미널](/docs/terminal)에서 해당 테스트, 빌드 또는 로그 명령을 실행합니다.

5. 커밋하거나 전달하기 전에 [Git 변경 사항](/docs/source-control)을 검사하세요.

6. [AI 채팅 및 에이전트](/docs/ai)에게 코드를 설명하거나 필요한 경우 다음 단계를 계획하도록 요청하세요.


## Android 개발 관련 기능


- **SSH 작업 공간** — 재연결 인식 처리를 통한 원격 프로젝트 탐색 및 편집.

- **편집기** — 더 큰 화면의 분할 창과 모바일 키보드 친화적인 입력을 갖춘 탭 편집.

- **터미널** — 프로젝트 컨텍스트 및 출력 검색이 포함된 명령 세션입니다.

- **Git** — 상태, 차이점 및 기록을 검사합니다. Pro를 사용한 게이트 쓰기 작업 흐름.

- **AI 채팅 및 에이전트** — 확인 지향 실행을 통한 작업 공간 인식 지원.

- **LSP 및 디버그** — 원격 호스트에 구성된 언어 서버 및 디버그 어댑터.


## Android IDE의 제한 사항


Android는 모든 작업에 대해 데스크톱을 대체할 수 없습니다. 무거운 로컬 컴파일, 긴 다중 파일 리팩터링 및 다중 모니터 디버깅은 여전히 ​​컴퓨터에서 더 편안합니다. SSH를 통한 원격 작업은 호스트에 대한 안정적인 연결에 달려 있으며 호스트는 무거운 작업을 수행합니다. 전화기는 전력이 부족한 서버를 보상할 수 없습니다. NimoteCode는 수정, 검토, 대기 중인 작업 및 작은 기능 등 집중적이고 가치가 높은 순간을 목표로 합니다.
