# NimoteCode의 새로운 기능


주요 제품 업데이트에 대한 공개 기록입니다. 설정 도움말을 보려면 [문서](/docs/quick-start)를 사용하세요. 계정이나 구독에 문제가 있는 경우 [지원](/support)을 방문하세요.


[전체 출시 내역 읽기 →](/releases/)


## 2026

### 버전 2.0.0 · 2026년 10월 25일

NimoteCode 2.0은 IDE를 안전하게 사용자 지정할 수 있는 작업 공간으로 확장하는 대규모 업데이트입니다. 플러그인을 만들고 실행하며, 후속 지시와 대화형 질문으로 AI Agent 작업을 이어가고, Git 브랜치·터미널 출력·프록시를 통한 SSH 연결을 더 직접적으로 다룰 수 있습니다.

[2.0.0 릴리스 노트 전체 읽기 →](/ko/releases/2.0.0)

### 버전 1.2.5 · 2026년 10월 20일


이 릴리스는 일상적인 프로젝트 관리를 더욱 효율적으로 만듭니다. Explorer는 배치 파일 작업, 파일 크기 및 로드된 디렉터리 수를 추가합니다. 빈 AI 채팅은 직접 단축키를 제공합니다. SSH 연결은 중복 시도를 차단하면서 즉각적인 진행을 제공합니다. 또한 휴대폰, 태블릿, 데스크톱 전반에 걸쳐 IDE를 통합합니다.


[1.2.5 릴리스 노트 전체 읽기 →](/releases/1.2.5)


### 버전 1.2.4 · 2026년 10월 18일


이 릴리스를 사용하면 작업을 더 빠르게 시작하고 재개할 수 있습니다. 최근 로컬 및 SSH 작업 영역을 계속하기가 더 쉽고, 선택적 AI 설정이 더 이상 코딩을 차단하지 않으며, 인앱 업데이트 알림에 이제 현지화된 릴리스 노트가 포함됩니다. 또한 설정, AI 구성, 터미널 검색 및 SSH 유효성 검사도 향상됩니다.


[1.2.4 릴리스 노트 전체 읽기 →](/releases/1.2.4)


### 버전 1.2.3 · 2026년 10월 15일


이 릴리스는 Android Local Linux와 앱 로컬 프로젝트를 공유하고, 앱 외부의 작업 상태 업데이트와 구성 가능한 터미널 컨트롤을 추가하고, SSH 세션의 탄력성을 더욱 향상시킵니다. 또한 기본 어두운 테마를 개선하고 작업 공간 상태 격리 및 SSH 복구 문제를 수정합니다.


[1.2.3 릴리스 노트 전체 읽기 →](/releases/1.2.3)


### 버전 1.2.2 · 2026년 10월 9일


이 릴리스(빌드 52)는 앱 샌드박스 외부의 프로젝트 폴더를 열고, Git 차이점 및 충돌 해결을 랜드스케이프 편집기로 가져오고, 작업하는 동안 Git 상태 및 터미널 세션을 최신 상태로 유지합니다. 또한 더 조밀한 Explorer 기본값, 외부 작업 공간에 대한 친숙한 이름 및 수정 사항 세트를 추가하고 이제 새 설치의 기본값은 영어로 설정됩니다.


[1.2.2 릴리스 노트 전체 읽기 →](/releases/1.2.2)


### 버전 1.2.1 · 2026년 10월 6일


이 릴리스(빌드 51)는 보다 차분한 하나의 시각적 시스템, 즉 더욱 집중된 가로 작업 공간, 컴팩트한 삽입 편집기, 향상된 대형 화면 가독성, 테마와 화면 크기 전반에 걸쳐 더욱 자연스러운 모달 시트로 데스크톱 및 태블릿 IDE를 개선합니다.


[1.2.1 릴리스 노트 전체 읽기 →](/releases/1.2.1)


### 버전 1.2.0 · 2026년 10월 5일


이 릴리스에서는 데스크톱 및 태블릿 작업 공간에 Monaco 편집기를 제공하고, Windows 데스크톱 지원을 개선하고, Explorer 밀도에 대한 더 많은 제어 기능을 제공합니다. 또한 장치 클래스 전반에 걸쳐 편집, 키보드 입력, 선택, 터미널 레이아웃 및 테마 일관성이 향상됩니다.


[전체 1.2.0 릴리스 노트 읽기 →](/releases/1.2.0)


### 버전 1.1.9 · 2026년 9월 27일


이 릴리스(빌드 48)는 사용 가능한 공간에 따라 선택된 레이아웃, 하나의 밀도 및 상태 언어, IDE 스타일 AI 타임라인, 새로운 인터페이스 스케일 등 하나의 디자인 시스템에서 인터페이스를 재구축하고 PHP 디버깅 및 더 광범위한 구문 강조 표시를 추가하는 동시에 에이전트 세션, 에이전트 검색, 액세스 확인 및 시작을 더욱 안정적으로 만듭니다.


[1.1.9 릴리스 노트 전체 읽기 →](/releases/1.1.9)


### 버전 1.1.8 · 2026년 9월 14일


이 릴리스(빌드 45)는 고급 모바일 워크플로를 위한 Early Access Pro를 시작하고 로컬 및 SSH 작업 영역에서 디렉터리를 전환할 수 있게 해줍니다. 또한 Android 로컬 Linux 설치, 파일 작업 및 Git 안정성을 강화하고 소스 제어 및 전반적인 시각적 계층 구조를 개선합니다. 로컬 Linux 개선 사항은 Android에만 해당됩니다.


[1.1.8 릴리스 노트 전체 읽기 →](/releases/1.1.8)


### 버전 1.1.7 · 2026년 9월 12일

이 릴리스에는 Android 로컬 Linux 개발 환경이 추가되고, HTML 및 링크 미리 보기가 개선되며, 편집기, AI 및 작업 작업의 안정성이 향상됩니다. 또한 외부 ACP 에이전트와 통합 SSH 로그인 환경을 제공합니다.


[1.1.7 릴리스 노트 전체 읽기 →](/releases/1.1.7)


### 버전 1.1.6 · 2026년 9월 9일


이 릴리스에서는 첫 번째 실행 온보딩을 통해 더 명확하게 시작할 수 있고, 편집기를 코드 지향 고정 폭 글꼴로 기본 설정하고, 구독 및 테마 프레젠테이션을 개선하고, 편집기, 인앱 브라우저, Git 상태 및 iOS 키보드 입력 문제를 수정합니다.

### 현재 릴리스 채널


- **호환성:** NimoteCode는 Android에서는 [Google Play](https://play.google.com/store/apps/details?id=com.nimote.nimotecode)를 통해, iPhone 및 iPad에서는 [App Store](https://apps.apple.com/app/nimotecode-ssh-client-ide/id6776158253)를 통해 사용할 수 있습니다.

- **사전 체험판 프로:** 이용 가능 여부 및 표시 가격은 매장, 계정 및 지역에 따라 다릅니다.

- **AI 제공자:** AI Chat 및 에이전트는 구성된 제공자 및 API 키(BYOK)를 사용합니다. 제공자 액세스 및 청구는 해당 제공자에게 그대로 유지됩니다.


향후 항목은 변경 사항을 **신규**, **개선됨**, **수정됨** 및 **호환성**으로 그룹화하므로 구독자와 지원 팀이 업데이트를 신속하게 평가할 수 있습니다.
