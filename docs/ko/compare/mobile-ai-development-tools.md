# 모바일 IDE, SSH 클라이언트 및 AI 코딩 도구 비교


<p class="article-meta">Evidence reviewed: October 19, 2026 · NimoteCode Team</p>

이 제품은 다양한 모바일 워크플로우를 제공합니다. Termius와 Blink Shell은 원격 액세스를 강조합니다. Redock, ServerCC 및 Moshi는 호스트에서 에이전트를 조종하는 데 도움을 줍니다. Orca는 데스크톱 에이전트 환경을 모바일로 확장합니다. NimoteCode는 모바일 편집기, 프로젝트 탐색기, Git 검토, SSH 작업 공간 및 지원되는 Android 장치의 경우 로컬 Linux를 결합합니다. 아래 비교에서는 각 기능의 작동 방식과 제품별 증거에 대한 링크를 설명합니다.


NimoteCode의 문서화된 릴리스는 **1.2.4**입니다. [버전 1.2.0](/releases/1.2.0)은 태블릿과 데스크톱에 Monaco를 추가했습니다. [1.2.1](/releases/1.2.1) 가로 레이아웃을 개선했습니다. [1.2.2](/releases/1.2.2)는 시스템 부여 폴더, 랜드스케이프 Git 차이점 및 충돌 페이지, 반응형 Git 상태를 추가했습니다. [1.2.3](/releases/1.2.3) 앱 외부에서 관찰된 작업 상태와 선택적인 Android SSH 포그라운드 지원을 추가했습니다. [1.2.4](/releases/1.2.4)는 최근 작업 공간 복구를 개선했습니다. 알림 또는 복원된 SSH 연결은 호스트 프로세스가 계속 실행 중임을 보장하지 않습니다.


시스템 부여 외부 폴더는 더 좁은 작업 공간 유형입니다. 파일 검색 및 편집을 지원하는 반면 Git, LSP, 디버그, 작업, 파일 감시자 및 에이전트 워크플로에는 기본 파일 시스템 경로가 필요합니다. NimoteCode의 액세스 경계는 [Free 및 Pro](/pro)를 참조하세요.
