# 계정 및 구독

## 계정 상태 확인

**Settings**에서 로그인한 뒤 계정 및 구독 영역을 확인합니다. 표시된 이용 권한에 따라 Pro 기능 접근 여부가 결정됩니다. 이용 가능 여부와 구매 옵션은 스토어, 계정, 지역 및 배포 채널에 따라 다릅니다.

## 구매 복원

이전 구매가 인식되지 않으면 플랫폼 스토어 계정을 확인하고 **Restore Purchase**를 선택합니다. 복원된 권한을 확인한 뒤 해당 기능을 다시 사용하세요. 계정 관련 문제는 [지원](/ko/support)에 문의하세요.

## 기능 이용 권한

Pro 기능에는 AI Agent, 플러그인 워크플로, Git 쓰기 작업, 원격 검색, 다중 터미널, LSP, 디버깅, Sync / Cache가 포함됩니다. 모델 사용료는 제공업체가 별도로 청구합니다. 기능 비교는 [무료 버전과 Pro](/ko/pro)를 참고하세요.
