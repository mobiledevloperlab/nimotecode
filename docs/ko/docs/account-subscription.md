# 계정 및 구독

## 계정 상태 확인

**Settings**에서 로그인한 뒤 계정 및 구독 영역을 확인합니다. 표시된 이용 권한에 따라 Pro 기능 접근 여부가 결정됩니다. 이용 가능 여부와 구매 옵션은 스토어, 계정, 지역 및 배포 채널에 따라 다릅니다.

**Pro 14일 무료 체험** — 앱에서 14일 무료 체험을 시작하세요. 종료 시 유료 구독이나 Early Access 등 유효한 Pro 권한이 없으면 자동으로 무료 버전으로 돌아갑니다. 체험 자격은 앱에서 확인하세요.

## 구매 복원

이전 구매가 인식되지 않으면 플랫폼 스토어 계정을 확인하고 **Restore Purchase**를 선택합니다. 복원된 권한을 확인한 뒤 해당 기능을 다시 사용하세요. 계정 관련 문제는 [지원](/ko/support)에 문의하세요.

## 기능 이용 권한

2.5.0부터 Free에서 GitHub 탐색, 지원되는 SSH의 Docker 버전·컨테이너·이미지 개요, 중단점 관리를 이용할 수 있습니다. GitHub 복제·쓰기, Docker 리소스 관리, 디버깅 시작에는 Pro가 필요합니다.

NimoteCode 2.5.0에서 [지속 SSH 터미널](/ko/docs/terminal#persistent-ssh-terminal)을 만들거나 재개하려면 Pro와 tmux가 설치된 호환 호스트가 필요합니다. 네이티브 데스크톱 빌드는 기본으로 Pro를 적용합니다.

모바일에서 Nimote Connect의 관리형 직접 연결과 릴레이를 사용하려면 Pro가 필요합니다. 일반 SSH, 개인 Tailscale, 데스크톱 정식 버전의 Nimote Connect는 무료입니다.

[무료 버전과 Pro](/ko/pro)를 참고하세요.

AI 모델은 BYOK(자신의 API 키 사용) 방식입니다. AI 제공업체와 API 키를 직접 설정하며, 모델 사용료는 해당 제공업체가 별도로 청구합니다. 모델 크레딧은 포함되지 않습니다.
