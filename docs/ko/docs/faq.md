# NimoteCode 자주 묻는 질문

## NimoteCode는 SSH 클라이언트 전용인가요?

아닙니다. 로컬 프로젝트, Android Local Linux 또는 SSH 작업 공간을 열 수 있으며, 같은 프로젝트 컨텍스트에서 Explorer, Editor, Terminal, Git, AI 지원 및 진단 패널을 제공합니다.

## Pro 없이 사용할 수 있나요?

파일 편집, SSH 연결, 검색을 지원하는 터미널 최대 2개 동시 사용, 기본 LSP 자동 완성·진단·탐색, 자체 모델 서비스를 이용한 독립 AI 채팅, Git 스테이징·스테이징 취소·커밋 및 변경 사항과 기록 조회는 무료입니다. 기본 LSP에는 설정된 언어 서버가 필요합니다. 지원되는 Android 기기에서는 기본 로컬 Linux 환경도 무료입니다. 무료 플랜은 하루에 내장 Agent 작업 3회와 원격 파일 내용 검색 10회를 제공합니다. UTC 00:00에 초기화됩니다. [Free 및 Pro](/ko/pro).

## 어떤 AI 제공업체를 설정할 수 있나요?

제공업체 템플릿과 호환되는 사용자 지정 엔드포인트를 지원합니다. 제공업체 이용 가능 여부, 모델 접근 및 비용은 사용자의 제공업체 계정과 설정에 따라 결정됩니다. [설정](/ko/docs/configuration)을 참고하세요.

## 소스 제어는 무엇을 지원하나요?

Free에서는 Git 상태와 차이 확인, 스테이징, 스테이징 취소 및 커밋을 지원합니다. GUI 푸시·풀·브랜치·스태시, Git AI 및 고급 GitHub 통합에는 Pro가 필요합니다.

## Tasks는 로컬에서 실행되나요, 원격에서 실행되나요?

Tasks는 SSH 작업 공간에서 반복 사용할 명령을 실행합니다. 명령은 연결된 작업 공간에서 실행됩니다. 별도 디렉터리를 지정하지 않으면 작업 공간 루트가 기본 작업 디렉터리입니다.

## 모든 프로젝트에서 LSP와 디버깅을 사용할 수 있나요?

원격 호스트에 호환되는 언어 서버나 디버그 어댑터가 구성되어 있는지, 프로젝트가 어떻게 설정되어 있는지에 따라 다릅니다. 기본 LSP 진단, 완성 및 탐색은 무료입니다. 코드 작업, 언어 서버 설치 지원 및 디버깅에는 Pro와 도구 설정이 필요합니다.  [LSP](/ko/docs/lsp)와 [디버깅](/ko/docs/debug)을 참고하세요.
