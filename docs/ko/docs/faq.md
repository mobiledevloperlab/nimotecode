# NimoteCode FAQ


## NimoteCode는 SSH 클라이언트만 되나요?


아니요. NimoteCode는 로컬 프로젝트를 열거나 Android 로컬 Linux를 사용하거나 SSH 작업 공간에 연결할 수 있으며 탐색기, 편집기, 터미널, Git 워크플로, AI 지원 및 진단 패널을 동일한 프로젝트 컨텍스트로 가져올 수 있습니다.


## Pro 없이 사용할 수 있나요?


예. 무료에는 로컬, Android 로컬 Linux 및 SSH 작업 공간, 편집기, 기본 터미널, AI Chat 및 기본 작업이 포함됩니다. 로컬 Linux에는 64비트 ARM64 또는 x86_64 장치에 Android 8 이상이 필요하며 iOS에서는 사용할 수 없습니다. AI Agent 및 원격 검색은 가용성이 확대됨에 따라 Early Access Pro를 통해 사용할 수 있습니다. 제한적인 워크플로는 [Pro](/pro)를 참조하세요.


## 어떤 AI 공급자를 구성할 수 있나요?


이 앱에는 14개의 기본 제공 공급자 템플릿이 포함되어 있으며 호환되는 사용자 지정 엔드포인트를 지원합니다. 제공업체 가용성, 모델 액세스 및 비용은 귀하의 제공업체 계정 및 설정에 따라 결정됩니다. [구성](/docs/configuration)을 참조하세요.


## 소스 제어는 무엇을 지원하나요?


소스 제어를 통해 모든 사용자는 저장소 상태, 차이점 및 기록을 검사할 수 있습니다. Pro는 커밋, 푸시, 숨김 작업과 같은 게이트형 Git 쓰기 워크플로에 필요합니다. [소스 컨트롤](/docs/source-control)을 읽어보세요.


## 작업은 로컬인가요, 아니면 원격인가요?


작업은 SSH 작업 공간에서 반복 가능한 명령 워크플로를 위해 설계되었습니다. 실행하기 전에 각 명령의 호스트, 프로젝트 루트 및 위험을 명확하게 만드십시오.


## LSP와 디버그는 모든 프로젝트에서 작동하나요?


원격 호스트에 구성된 호환 언어 서버 또는 디버그 어댑터와 프로젝트 설정에 따라 달라집니다. 이는 Pro 워크플로입니다. [LSP](/docs/lsp) 및 [디버그](/docs/debug)를 참조하세요.
