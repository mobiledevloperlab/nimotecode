# 빠른 시작


이 가이드를 사용하여 먼저 워크플로를 검증하세요. 프로젝트를 열고 작은 편집을 한 후 터미널에서 확인하세요. 지원되는 장치의 로컬 프로젝트, SSH 작업 공간 또는 Android 로컬 Linux에서 작동합니다.

## 1. 작업공간 열기


기기의 프로젝트에 대해 **로컬 작업 공간 열기**, 원격 호스트의 경우 **원격 작업 공간 연결** 또는 지원되는 Android 8+ ARM64/x86_64 기기에 번들로 제공되는 Ubuntu의 경우 **로컬 Linux**를 선택합니다. **Demo Workspace 체험하기**를 사용하여 샘플 프로젝트를 즉시 탐색할 수도 있습니다. 로컬 Linux는 루트 액세스가 필요하지 않으며 iOS에서는 사용할 수 없습니다. 설정 및 수명 주기는 [Android 로컬 Linux](/docs/local-linux)를 참조하세요. SSH 작업공간의 경우 호스트, 포트 및 사용자 이름을 입력합니다. 그런 다음 비밀번호, 키 파일 또는 붙여넣은 개인 키 인증을 선택하세요. 작업을 시작하기 전에 프로젝트 루트를 확인하세요.

## 2. 파일 열기, 편집 및 저장


탐색기 또는 [검색](/docs/search)에서 파일을 선택합니다. 탭 편집기에서 열립니다. AI에게 질문할 계획이라면 약간 변경하고 저장한 후 파일을 활성 상태로 유지하세요.


## 3. 터미널에서 확인


동일한 작업 공간에서 [터미널](/docs/terminal)을 열고 `pwd`, `ls` 등 무해한 명령이나 프로젝트의 테스트 명령을 실행하세요. 결과가 길면 출력 검색을 사용하세요.
