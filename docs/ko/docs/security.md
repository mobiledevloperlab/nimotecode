# 인증 정보 및 작업 검토

## SSH 접근

프로젝트에 적절한 권한을 가진 SSH 계정을 사용합니다. 세션을 열 때 호스트, 사용자 이름, 작업 공간 루트를 확인하세요. 프록시 설정은 호스트에 연결하는 경로에 영향을 주지만 계정 권한을 변경하지는 않습니다.

## 제공업체 인증 정보

API 키는 제공업체 설정 양식에 입력합니다. 프롬프트, 프로젝트 파일 또는 공유 로그에 인증 정보를 넣지 마세요. 노출된 키는 제공업체에서 폐기하고 새로 발급하세요.

## 계획 및 파일 변경

Confirm 모드에서 도구 실행을 승인하기 전에 Agent 계획을 검토합니다. 플러그인을 설치하거나 업데이트할 때 요청 권한을 확인합니다. 변경 사항을 커밋하기 전에 [Git diff](/ko/docs/source-control)를 검토하고 관련 프로젝트 검사를 실행하세요.
