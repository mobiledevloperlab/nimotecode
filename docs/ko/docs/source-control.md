# 모바일 Git 소스 제어


소스 제어는 Git의 검토 가능한 부분을 변경 사항을 편집하고 확인한 작업 공간으로 가져옵니다. 저장소 상태, 차이점 및 기록은 모든 사용자가 사용할 수 있습니다. **Pro**는 제공 단계에서 제한적인 Git 쓰기 워크플로가 필요한 경우에만 필요하며 팀의 검토 및 분기 정책을 대체할 수는 없습니다.

## 할 수 있는 작업


- 스테이징된 파일, 스테이지되지 않은 파일 및 충돌된 파일을 검토합니다.

- 파일 차이점 및 저장소 기록을 검사합니다.

- 첫 번째 커밋 리포지토리를 포함하여 활성 작업 공간에서 로컬 및 원격 리포지토리 상태를 새로 고칩니다.

- 선택한 작업을 준비하고 차이점을 검토한 후 커밋을 준비합니다.

- Pro를 사용하면 리포지토리 및 호스트 권한이 허용하는 경우 커밋, 푸시, 숨김 등의 제한 Git 쓰기 작업을 사용할 수 있습니다.

- Git AI를 사용하여 변경 사항을 설명하고 커밋 메시지 초안을 작성하거나 위험 지향 검토를 유도합니다.


## 의도적인 모바일 커밋 흐름


1. 편집 내용을 저장하고 [터미널](/docs/terminal)에서 확인하세요.

2. 소스 제어를 열고 차이점을 읽어보세요. 생성된 요약뿐만 아니라.

3. 의도한 변경 사항을 준비하고 커밋 메시지를 작성하거나 생성합니다.

4. Pro 액세스를 사용하여 커밋한 다음 리포지토리 워크플로에 적합한 경우에만 가져오거나 푸시하세요.
