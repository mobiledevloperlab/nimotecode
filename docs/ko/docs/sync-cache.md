# 동기화 및 캐시


동기화/캐시는 로컬 작업 공간과 원격 작업 공간 간에 프로젝트 콘텐츠를 의도적으로 이동하기 위한 **Pro** 워크플로입니다. 이는 전송에 가시적인 방향을 제공하고 대상을 활성 작업 공간 경계 내부에 유지합니다.

## 두 가지 명확한 방향


- **동기화**는 로컬 프로젝트를 원격 작업 공간으로 이동합니다.

- **캐시**는 원격 프로젝트 콘텐츠를 로컬 작업 공간으로 다시 가져옵니다.
