## 시작하기

1. 로컬 프로젝트를 열거나 SSH 워크스페이스를 추가합니다.
2. SSH에서는 호스트, 인증 방법, 프로젝트 루트를 확인합니다.
3. 파일을 열어 작은 편집을 저장한 뒤 `pwd`, `ls` 또는 프로젝트 테스트를 실행합니다.
4. AI Chat 또는 AI Agent를 사용할 때만 AI 제공업체를 설정합니다.

무료 플랜에는 로컬, Android Local Linux, SSH 워크스페이스, 에디터, 기본 Terminal, Git 검토, AI Chat, Tasks가 포함됩니다.
