<div class="product-reference">

<details>
<summary>검색, 언어 서비스 및 디버깅</summary>

- [프로젝트 검색](/ko/docs/search): SSH 워크스페이스의 파일 내용을 검색하며 대소문자 구분과 정규식을 지원합니다.
- [언어 서비스](/ko/docs/lsp): 실행 대상에 호환 언어 서버를 설치하고 설정하면 진단, 심볼 탐색, 코드 작업을 제공합니다.
- [디버깅](/ko/docs/debug): 설정된 디버그 어댑터로 중단점, 호출 스택, 변수, 감시 표현식을 확인합니다.

</details>

<details>
<summary>GitHub, 작업 및 플러그인</summary>

- [GitHub](/ko/docs/source-control): 기기, Local Linux, SSH 호스트로 저장소를 복제하고 계정 권한에 따라 Issue, PR, 리뷰, 검사, 워크플로 실행을 관리합니다.
- [작업](/ko/docs/tasks): 이름이 있는 명령을 저장하고 SSH 또는 Local Linux의 프로젝트 디렉터리에서 실행합니다.
- [플러그인](/ko/docs/plugins): 폼, 워크스페이스 데이터, 파일 작업, HTTP 요청, 스크립트가 포함된 패널을 만듭니다. 파일, 네트워크, 실행 작업에는 확인이 필요합니다.

</details>

<details>
<summary>모델 제공자 및 외부 도구</summary>

- [모델 설정](/ko/docs/configuration): 제공자, 모델, 인증 정보를 직접 설정합니다. 제공자 계정과 모델 사용 요금은 NimoteCode와 별개입니다.
- [외부 ACP Agent](/ko/docs/ai): 지원 환경에서 별도로 구성된 호환 Agent를 실행합니다. 인증 정보, 도구 권한, 실행 정책은 해당 런타임에서 관리합니다.
- [MCP 서버](/ko/docs/ai): stdio 또는 Streamable HTTP로 도구를 연결합니다. stdio 서버 시작과 MCP 도구 호출에는 승인이 필요합니다.

</details>

<details>
<summary>기능 이용 권한</summary>

현재 계정과 플랫폼에서 사용할 수 있는 기능은 앱에 표시됩니다. Git 쓰기, 다중 터미널, Agent 실행, Docker, LSP, 디버깅은 해당 Pro, 체험, Early Access 권한에 따라 제공됩니다.

권한과 복원은 [계정 및 구독](/ko/docs/account-subscription), 현재 조건은 [Early Access](/ko/pro)에서 확인하세요.

</details>

</div>
