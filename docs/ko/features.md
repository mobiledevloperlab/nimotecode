# NimoteCode 기능

NimoteCode는 모바일에서 필요한 개발 흐름을 연결합니다. 로컬 프로젝트, SSH 호스트 또는 Android Local Linux에서 **Explorer → Editor → Terminal → Git → AI**를 사용할 수 있습니다.

## 무료 기능

| 기능 | 제공 내용 |
| --- | --- |
| 로컬 및 SSH 워크스페이스 | 기기나 원격 호스트의 프로젝트를 엽니다. |
| 코드 에디터 | 탭, 분할 보기, 저장, 클립보드, 실행 취소/다시 실행을 제공합니다. |
| Terminal | 워크스페이스에서 명령을 실행하고 출력을 확인합니다. |
| Git 검토 | 상태, diff, 브랜치, 기록을 확인합니다. |
| AI Chat 및 Tasks | 코드와 오류를 이해하고 작업을 계획하거나 반복 명령을 저장합니다. |

## Pro 워크플로

Early Access Pro에는 AI Agent, 원격 검색, 다중 터미널, Git 쓰기, LSP, 디버깅, Sync / Cache가 포함됩니다. 제공 여부와 가격은 지역 및 계정에 따라 Google Play 또는 App Store에 표시됩니다.

Android Local Linux는 지원되는 Android 8 이상 64비트 기기에서 사용할 수 있는 루트 권한 없는 Ubuntu 워크스페이스입니다. iPhone과 iPad에서는 로컬 및 SSH 워크스페이스를 사용할 수 있습니다.
