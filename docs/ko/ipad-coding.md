# 실제 개발 작업 공간을 이용한 iPad 코딩

iPad는 휴대폰보다 화면 공간이 더 넓지만 작업 공간이 iPad에 맞게 설계되었을 때 iPad에서 코딩하는 것이 가장 잘 작동합니다. 작업 스레드를 잃지 않고 프로젝트 트리, 코드, 터미널 출력 및 Git 변경 사항 사이를 쉽게 이동할 수 있는 방법이 필요합니다.

NimoteCode는 이러한 도구를 iPad에서 **모바일 AI 개발 작업 공간**(편집기 + 탐색기 + SSH + 터미널 + Git + AI 채팅 및 에이전트)으로 통합합니다. Android 릴리스와 동일한 기능 세트로 App Store에서 사용할 수 있습니다.

## 생산적인 iPad 코딩 루프

### 상황에 맞게 더 큰 화면을 사용하세요.

탐색기에서 시작하여 프로젝트 구조를 계속 표시한 다음 편집기 탭에서 관련 파일을 엽니다. 태블릿에서는 추가 시각적 공간을 통해 코드 경로를 더 쉽게 따르거나 구성 변경 사항을 동기를 부여한 명령 출력과 비교할 수 있습니다.

### 원격 환경을 가까이 유지하세요

[SSH 작업 공간](/docs/ssh)을 사용하여 프로젝트에 연결한 다음 터미널을 사용하여 테스트, 로그 확인, 빌드 출력 또는 서비스 상태 등 이해한 내용을 검증하는 명령을 실행하세요. 짧고 집중적인 작업을 의미 있게 만들기 위해 iPad를 데스크탑 대체품으로 바꿀 필요는 없습니다.

### 배송 전 검토

[Git 및 소스 제어](/docs/source-control)를 사용하여 편집으로 생성된 차이점을 검사하세요. 이는 나중에 검토하는 대신 동일한 작업 공간 내에서 루프를 닫으므로 iPad 코딩에 특히 유용합니다.

## AI가 적합한 곳

AI는 명확한 임무가 있을 때 가장 유용합니다. 익숙하지 않은 모듈을 설명하고, 오류를 디버깅 계획으로 전환하거나, 다음 작은 변화를 제안합니다. [AI 채팅 및 에이전트](/docs/ai)는 개발 작업 공간과 통합되어 대화가 실제 파일 및 작업과 계속 연결될 수 있습니다. 원격 또는 프로덕션 작업에 대해 명령 및 변경 검토를 활성화된 상태로 유지합니다.
