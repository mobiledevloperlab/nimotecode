# 업무에 계속 연결되는 모바일 AI 코딩


모바일 AI 코딩은 붙여넣은 코드 조각을 챗봇에 보내는 것 이상이어야 합니다. 프로젝트를 검사하고, 초점을 맞춘 변경 사항을 적용하고, 명령을 실행하고, 컨텍스트를 잃지 않고 차이점을 검토할 수 있을 때 답변이 유용해집니다.


NimoteCode는 편집기, 탐색기, SSH, 터미널 및 Git이 포함된 **모바일 AI 개발 작업 공간**에 AI 채팅과 AI 에이전트를 배치합니다. 이는 작업 공간이 로컬이든 원격 호스트에 연결되어 있든 상관없이 AI가 작업이 발생하는 곳에서 작업을 지원할 수 있음을 의미합니다.

## AI 이해 및 계획을 위한 채팅


단계를 제어하고 싶을 때 AI Chat을 사용하세요. 오류 설명, 기능 명확화, 리팩터링 계획 또는 테스트 계획 준비. 활성 파일과 작업공간은 복사된 조각보다 더 나은 시작점이 되며 설명에서 편집기나 터미널로 직접 이동할 수 있습니다.


## 다단계 작업 제어를 위한 AI 에이전트


AI 에이전트는 관련 파일 검사, 편집 제안, 검사 실행, 결과 요약 등 자연스럽게 여러 작업에 걸쳐 있는 작업을 위한 것입니다. 리뷰를 건너뛰는 이유는 아닙니다. NimoteCode는 제어된 실행 및 확인 지향 워크플로로 구축되었으므로 특히 원격 SSH 작업 공간에서 명령과 변경 사항을 검사할 수 있습니다.


기능 사용 가능 여부 및 공급자 구성은 [AI 채팅 및 에이전트](/docs/ai) 및 [보안 및 안전](/docs/security)을 참조하세요.


## 주변 작업 공간이 중요한 이유


| AI coding need | Mobile workspace advantage |
|---|---|
| Understand an error | Read the code, inspect terminal output and ask a question in one place |
| Prepare a small fix | Move from an AI plan to the precise file and test it immediately |
| Work on a remote project | Keep SSH, remote files and agent context together |
| Review generated changes | Inspect Git diff before a commit or push |
| Continue while mobile | Preserve the current task instead of reconstructing it across apps |

AI는 컨텍스트 전환 비용을 줄여 모바일 작업을 더욱 유용하게 만듭니다. 작업공간에서는 소스 파일, 셸 출력, Git 기록, 의도적 검증 등 엔지니어링 제어 기능을 계속 제공합니다.


## 모바일 AI 코딩의 좋은 사용 사례


- 통화 중에 낯선 서비스에 대해 설명해보세요.

- 편집하기 전에 좁은 범위의 제작 수정을 계획하세요.

- 실패한 명령 또는 진단 메시지를 해석합니다.

- 작은 변경 사항을 검토하고 명확한 커밋 메시지를 작성합니다.

- 노트북을 사용할 수 없을 때 휴대폰이나 태블릿에서 SSH 기반 작업을 계속하세요.


## 모바일 AI 코딩이 제한되는 곳


휴대폰의 AI는 엔지니어링 기본 사항을 변경하지 않습니다. 대규모 크로스 커팅 리팩터링은 작은 화면에서 추론하기가 더 어렵고 긴 에이전트 실행은 여전히 ​​데스크톱 뷰포트의 이점을 누릴 수 있습니다. AI 제안은 실제 프로젝트에 대해 확인되어야 합니다. LLM은 실행 중인 서비스를 볼 수 없습니다. 그리고 생산에 인접한 원격 작업의 경우 명령 및 변경 확인을 유지해야 합니다. 좁고 범위가 넓은 작업에는 모바일 AI 코딩을 사용합니다. 큰 디자인 작업은 데스크탑에서 진행하세요.


## 자주 묻는 질문


### 모바일 AI 코딩은 독립형 AI 채팅과 어떻게 다릅니까?


NimoteCode는 편집기, 프로젝트 탐색기, SSH 터미널 및 Git 컨텍스트와 함께 AI Chat 및 Agent를 유지하므로 실제 작업 공간에서 제안을 검사하고 확인할 수 있습니다.


### AI 에이전트가 원격 작업 공간에서 변경을 할 수 있나요?


AI 에이전트는 다단계 작업을 지원할 수 있지만 원격 및 프로덕션에 인접한 작업은 명령 및 변경 제어가 활성화된 상태에서 검토되어야 합니다.


### AI가 Git 검토를 대체합니까?


아니요. AI는 작업을 설명하고 계획하고 지원하는 데 도움을 줄 수 있습니다. Git 검토와 적절한 테스트 또는 확인 명령은 전달 워크플로의 일부로 유지됩니다.
