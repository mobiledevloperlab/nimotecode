# SSH, Git 및 AI 코딩을 위한 모바일 IDE


대부분의 모바일 코딩 도구는 작업의 한 부분(파일 열기, 서버에 연결 또는 명령 실행)을 해결합니다. **모바일 IDE**는 전체 개발 루프를 함께 유지해야 합니다. 즉, 프로젝트를 탐색하고, 코드를 이해하고, 변경하고, 확인하고, 출시될 제품을 검토해야 합니다.


NimoteCode는 해당 루프를 위한 **모바일 AI 개발 작업 공간**입니다. Android 및 iOS 릴리스에서는 편집기, 탐색기, SSH, 인앱 웹 및 미디어 미리 보기, 터미널, Git, AI Chat 및 에이전트를 하나의 작업 공간으로 가져옵니다. 지원되는 Android 장치에서 로컬 Linux는 루트 액세스 없이 Bash, Git 및 SSH가 포함된 번들 Ubuntu 환경도 제공합니다.

## 모바일 IDE가 실제 작업에 유용한 이유는 무엇입니까?


| Need | A single-purpose app | NimoteCode workspace |
|---|---|---|
| Understand a project | Open individual files | Browse the project in Explorer and keep files in tabs |
| Work remotely | Switch between an SSH app and editor | Connect to an SSH workspace and work on its files |
| Validate a change | Copy commands into another app | Run commands in the workspace terminal |
| Preview a web change | Switch to a separate browser | Open a local or remote web project from the workspace or a Terminal URL |
| Compare related code | Flip between files | Keep two files visible in split editor panes |
| Ship carefully | View a raw diff elsewhere | Review Git changes next to the edited code |
| Get help | Paste snippets into a separate AI chat | Use AI Chat or AI Agent with workspace context |

목표는 긴 코딩 세션마다 데스크톱을 교체하는 것이 아닙니다. 전화나 태블릿만 있으면 생산적인 순간을 만들 수 있습니다. 즉, 대기 중인 조사, 소규모 생산 수정, 여행 중 검토, 이미 진행 중인 작업에 대한 AI 지원 후속 조치 등이 있습니다.


## 앱 호핑이 없는 완전한 워크플로


프로젝트가 장치에 있을 때 로컬 탐색기에서 시작하고, 지원되는 Android 장치에 번들 Ubuntu가 필요할 때 로컬 Linux를 사용하거나, [SSH 작업 공간](/docs/ssh)을 통해 원격 개발 시스템 또는 서버에 연결하세요. 거기에서 편집기에서 파일을 나란히 열고, 저장하기 전에 현재 HTML 콘텐츠를 미리 보거나 필요할 때 로컬 또는 원격 웹 프로젝트를 열고, [터미널](/docs/terminal)에서 테스트 또는 검사 명령을 실행하고, [소스 제어](/docs/source-control)를 사용하여 결과 차이를 검사합니다.


작업에 더 많은 컨텍스트가 필요한 경우 [AI 채팅 및 에이전트](/docs/ai)가 코드를 설명하거나 변경을 계획할 수 있습니다. AI Agent는 제어된 다단계 작업을 위해 설계되었습니다. SSH 작업 공간에서는 구성된 호환 가능한 외부 ACP 런타임을 사용할 수도 있습니다. 제안된 내용을 검토하고 최종 결정을 직접 내릴 수 있습니다.


## 모바일 제약에 맞춰 제작됨


좋은 모바일 개발은 작은 화면에 데스크톱 UI를 압축하는 것이 아닙니다. NimoteCode는 터치, 모바일 키보드, 집중형 패널 및 재연결 인식 원격 작업을 중심으로 설계되었습니다. 또한 현재 릴리스에서는 보다 탄력적인 SSH 처리, 제한된 미리 보기 리소스 및 보다 안정적인 모바일 터미널 입력을 통해 긴 세션을 더욱 안정적으로 만듭니다. 태블릿에서는 디스플레이가 커질수록 분할 편집, 프로젝트 탐색 및 터미널 출력을 위한 더 많은 공간이 제공됩니다. 전화기에서는 동일한 작업 공간이 다음 작업에 계속 집중됩니다.


기능에 대한 자세한 내용은 [기능](/features)을 참조하세요. SSH 설정 및 프로젝트 접속은 [SSH 원격 개발 워크플로](/docs/ssh)를 참조하세요. 설정 지침을 보려면 [빠른 시작](/docs/quick-start)으로 시작하세요.


## 데스크탑이 여전히 승리하는 곳


모바일 IDE는 완전한 대체가 아닌 보완입니다. 길고 중단 없는 기능 작업, 과도한 로컬 컴파일, 광범위한 다중 파일 리팩터링 및 다중 모니터 디버깅이 데스크탑에서 더 잘 유지됩니다. 전화에서는 자연스럽게 다음 구체적인 단계인 검사, 편집, 확인, 검토로 초점이 좁아집니다. 이러한 노동 분업은 이미 가지고 있는 컴퓨팅 성능을 재사용하는 SSH를 통한 원격 개발이 일반적으로 전화기에서 로컬로 대규모 프로젝트를 컴파일하는 대신 생산적인 경로인 이유입니다.
