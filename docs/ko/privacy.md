## 이용 목적과 실행 진단 {#purposes}

연결 설정에는 인증 방식과 작업 공간 루트가, 환경설정에는 테마·언어·편집기·키보드 설정이 포함됩니다. AI 설정에는 Provider 유형, base URL, 모델과 API Key가 포함됩니다. SSH 암호는 사용자가 시작한 연결 인증에 사용되며 일반 연결 설정과 별도의 보안 저장소에 보관됩니다. 현재 AI 설정 저장도 API Key와 일반 앱 설정을 분리합니다.

인증과 계정 보안, 작업 공간·편집기·터미널·Source Control·AI·Tasks 제공, 구독·체험 검증, 안정성·보안·지원에 사용합니다.

앱은 장애 대응, 안정성과 보안을 위한 실행 로그를 생성할 수 있습니다. 현재 공통 로깅 구성요소는 릴리스 빌드에서 debug 메시지를 억제하지만 모든 다른 로그·오류가 익명화되거나 민감한 내용을 제거했다는 뜻은 아닙니다. 진단 로그는 Firebase 사용 분석과 별도입니다. 자발적으로 로그·스크린샷을 보내기 전에 인증 정보와 비공개 프로젝트 내용을 제거하세요.

## 인증 정보·대화·파일 {#storage}

앱이 관리하는 SSH 암호, 개인 키, 키 암호, 프록시 인증, AI API Key, GitHub 토큰과 MCP 설정은 iOS Keychain 또는 Android Keystore 기반 암호화 저장소를 사용합니다. 이는 SSH 인증 정보를 전혀 저장하지 않는다는 뜻이 아닙니다. 저장된 SSH 연결이나 AI 설정을 제거하면 해당 보안 저장소의 인증 정보도 제거됩니다.

현재 AI 대화 기록은 **기본적으로 앱 로컬 저장소에 자동 저장**되며 메시지와 복원용 도구·프로젝트 문맥을 포함합니다. 자동 저장을 끄는 것과 기존 기록 삭제는 별개입니다. AI 신고도 로컬에 저장되며 삭제 또는 저장 개수 제한에 따라 제거됩니다. 일반 기록은 인증 정보용 보안 저장소와 다릅니다.

파일, 동기화 캐시, 워크플로 및 외부 Agent 기록은 기기, 원격 호스트, `.nimote`를 포함한 작업 공간에 별도로 존재할 수 있습니다. 앱 기록 삭제는 이 사본이나 제3자가 받은 데이터를 지우지 않습니다. 프롬프트·프로젝트 파일에 비밀 정보를 넣지 마세요.

## AI와 외부 서비스 {#integrations}

직접 모델 요청은 선택한 Provider로 전송됩니다. Agent는 작업, 권한, 모드에 따라 파일을 읽고 도구 출력을 모델 문맥에 포함할 수 있습니다. 첫 전송 전 AI 개인정보 화면과 승인 내용을 확인하세요.

HTTP MCP는 도구 요청을 받으며 stdio MCP는 선택한 기기·Local Linux·SSH 환경에서 실행됩니다. 외부 ACP Agent는 자체 인증, 네트워크, 로그와 저장소를 가진 독립 실행 환경입니다. GitHub 인증으로 저장소·Issue·Pull Request 등을 처리하며 게시·푸시·공유 시 다른 사람이 내용을 볼 수 있습니다.

BYOK는 제공자의 데이터 미보관이나 학습 미사용을 보장하지 않습니다. 수신자의 조건을 확인하고 불필요한 설정·연결을 제거하거나 권한을 취소하세요. 전송된 데이터는 해당 서비스의 삭제 절차가 적용됩니다.

## 앱 및 웹사이트 분석 {#analytics}

**앱:** 현재 버전은 Firebase Analytics를 초기화하고 위 표의 사용 정보를 기록합니다. 완전히 익명인 정보가 아닙니다. 현재 앱에는 전체 분석을 끄는 스위치가 없으며 웹사이트 선택으로 앱 분석을 끌 수는 없습니다. 개인정보 요청은 이메일로 제출할 수 있습니다.

**웹사이트:** 허용한 경우에만 Google Analytics를 로드하여 방문과 링크 클릭을 측정합니다. 페이지 경로, 링크 문구, 대상 경로, 캠페인, 브라우저·기기 정보와 쿠키·식별자를 사용할 수 있습니다. 거부해도 열람과 다운로드 링크 사용에 영향이 없습니다. 하단의 ‘웹사이트 개인정보 설정’에서 철회할 수 있습니다. 웹 분석에 로그인 사용자 ID, Google Signals 또는 광고 개인화를 사용하지 않습니다.

선택은 브라우저에 저장되며 사이트 데이터 삭제 시 초기화됩니다. 호스팅·콘텐츠 제공·보안 서비스는 페이지 제공과 남용 방지를 위해 IP, 요청 및 기본 연결 정보를 처리합니다.

## 권한과 서비스 제공자 {#providers}

Android는 네트워크, 결제, 알림, 사용자가 시작한 SSH 세션용 포그라운드 서비스와 Android 9 이하의 외부 저장소 권한을 선언합니다. `AD_ID`도 선언하며 실제 식별자 처리는 시스템·SDK 설정에 따릅니다. iOS / iPadOS는 네트워크, 선택한 문서 접근, 스토어 결제와 작업 상태용 Live Activities를 사용합니다. 현재 이러한 기능에 카메라·마이크·연락처·정밀 위치 권한을 선언하지 않습니다. 알림과 잠금화면 상태는 타인에게 보일 수 있으며 시스템 설정에서 관리할 수 있습니다.

[Firebase](https://firebase.google.com/support/privacy), [RevenueCat](https://www.revenuecat.com/privacy/), [Apple](https://www.apple.com/legal/privacy/), [Google](https://policies.google.com/privacy), [GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)는 각 기능에 필요한 데이터를 처리합니다. AI·MCP·SSH 수신자는 설정에 따릅니다. 해외 처리가 발생할 수 있으며 실제 서비스와 구성에 따른 고지·허가·보호 요건을 준수합니다. 개인정보를 판매하지 않습니다. 법적 의무, 보안 또는 분쟁에 필요한 공개가 이루어질 수 있습니다.

## 보관·삭제·권리 {#retention}

계정 삭제가 완료되면 인증 계정과 기본 사용자 기록을 삭제하고 현재 구독 소유권 연결을 해제합니다. 거래, 이전 사용자 ID를 포함한 삭제 연결 기록, 기기 체험 해시는 권한 검증, 남용 방지, 분쟁 및 법적 의무를 위해 남을 수 있습니다. RevenueCat·분석·지원 기록이 모두 자동 삭제되는 것은 아닙니다.

로컬 기록·인증 정보·파일은 각각 관리하세요. 분석·로그는 서비스 보관 설정과 필요한 보안·장애 대응 목적, 지원 기록은 요청 처리와 필요한 법적 보관에 따릅니다. 모든 데이터에 공통인 보관 일수는 없습니다. 예외 보관은 특정 목적·의무·필요 기간으로 한정하며 대상과 처리 방법을 문의할 수 있습니다. [삭제 안내](/ko/account-delete).

설정 → 계정 삭제, 로컬 기록 삭제, 통합 해제, 기기 권한 관리와 사이트 분석 거부를 이용할 수 있습니다. 적용법에 따라 열람, 정정, 사본, 삭제, 동의 철회, 처리 제한·이의를 이메일로 요청할 수 있습니다. 필요한 신원 확인 후 진행 상황, 예상 완료 또는 처리 불가 사유를 안내하며 법정 기한을 우선합니다. 암호·인증 코드를 보내지 마세요.

## 안전·아동·변경 {#updates}

보안 저장과 인증 조치를 사용하지만 모든 기기와 외부 환경의 안전을 보장할 수는 없습니다. 개발자 대상 서비스이며 13세 미만 또는 현지의 더 높은 최소 연령 미만은 계정을 만들거나 개인정보를 제출하지 않아야 합니다. 스토어 콘텐츠 연령 등급은 별도 기준입니다. 관련 우려는 지원팀에 알려주세요.

변경 시 날짜를 갱신하며 데이터 목적·공유의 중대한 변경에는 필요한 추가 고지나 동의를 진행합니다.

## 연락처 {#contact}
