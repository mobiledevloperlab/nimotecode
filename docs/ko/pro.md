# NimoteCode Pro


무료 플랜에는 로컬 및 SSH 작업 공간, 편집기, 기본 터미널과 AI Chat이 포함됩니다. **Early Access Pro**에는 GitHub 연동, 지원 기기의 Android Local Linux, Plugin Center, AI Agent, Git 쓰기, 원격 검색, 다중 터미널, LSP, 디버깅 및 Sync / Cache가 포함됩니다. 이용 가능 여부와 가격은 스토어에서 확인하세요.

## 왜 프로인가


Pro는 diff 확인 후 게이트된 Git 커밋, 한 번에 여러 터미널 컨텍스트, 구성된 LSP 피드백, 디버그 세션 또는 AI 에이전트 작업 등 모바일 작업이 신중하게 검토된 결과로 끝나야 하는 순간을 위해 존재합니다. 특히 프로덕션 시스템에서는 명령, 차이점 또는 AI 제안을 검토할 필요성이 제거되지 않습니다.


구독 확인, 구매 복원 및 액세스 동작에 대해서는 [계정 및 구독](/docs/account-subscription)을 참조하세요.
