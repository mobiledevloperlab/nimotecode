# NimoteCode Pro

NimoteCode는 무료로 시작할 수 있습니다. 로컬 또는 SSH 프로젝트를 열고, 파일을 편집하고, 명령을 실행하고, AI Chat을 사용할 수 있습니다. Early Access Pro는 고급 모바일 개발 워크플로를 위한 플랜입니다.

## Pro에 포함된 기능

AI Agent, 원격 검색, 다중 Terminal, Git 쓰기 작업, LSP, 디버깅, Sync / Cache를 제공합니다. 가격과 이용 가능 여부는 지역 및 계정에 따라 Google Play 또는 App Store에 표시됩니다.
