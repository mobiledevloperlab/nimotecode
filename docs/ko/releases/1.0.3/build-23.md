## 1.0.3 · 빌드 23 · 2026년 6월 20일


NimoteCode는 모바일 개발 작업 공간을 출시합니다.


- **새로운 기능:** 하나의 앱에서 프로젝트 탐색, 코드 편집, 터미널 사용, Git 검토 및 AI 도움말을 받으세요.

- **개선됨:** 터치, 키보드 및 읽기 환경이 휴대폰과 태블릿에 최적화되어 있습니다.
