## 1.1.7 · 2026년 9월 12일


2026년 9월 12일 출시됨(빌드 41). 이 릴리스에는 Android 로컬 Linux 개발 환경이 추가되고 HTML 및 링크 미리 보기가 개선되며 편집기, AI 및 작업 작업의 안정성이 향상됩니다. 또한 외부 ACP 에이전트와 통합 SSH 로그인 환경을 제공합니다.


### 신규


- **Android 로컬 Linux 작업 공간.** 루트 액세스 없이 지원되는 ARM64 및 x86_64 Android 장치에서 Bash, Git 및 SSH가 포함된 번들 Ubuntu 환경을 사용하세요. 기존 SSH 작업 영역 환경을 통해 환경을 설치, 시작, 중지, 열기, 재설정 또는 삭제합니다. iOS에서는 사용할 수 없습니다.

- **HTML 스냅샷 미리보기.** 작업 공간 CSS, JavaScript 및 이미지 자산을 사용하여 저장되지 않은 변경 사항을 포함한 현재 HTML 편집기 콘텐츠를 미리 봅니다. 빌드 단계나 백엔드가 필요한 프로젝트에는 여전히 자체 개발 서버가 필요합니다.

- **링크 버튼.** 공유 브라우저 작업을 통해 터미널, AI 응답 및 도구 출력의 웹 링크를 엽니다.

- **로컬 Linux 소개 및 오픈 소스 정보.** 환경 페이지에서는 번들 오픈 소스 라이선스에 직접 액세스하여 스토리지, 네트워크 액세스, 프로세스 수명 주기 및 삭제 동작을 설명합니다.

- **통합 에이전트 슬래시 명령 항목.** 새 대화, 중지 및 상태에 대한 기본 동작이 포함된 터치 또는 키보드 완성을 위해 `/`를 입력합니다. 외부 명령은 활성 ACP 세션에서 나오며 실행되는 동안 최신 상태를 유지합니다.

- **외부 ACP 에이전트.** SSH 작업 영역에서 ACP 호환 외부 에이전트를 선택하고 실행합니다.

- **에이전트 기능 및 세션.** 기능, 권한 요청, 세션 상태 및 실행 진행 상황은 내장 에이전트와 외부 런타임 간의 간편한 전환을 통해 하나의 경험을 공유합니다.

- **원격 환경 새로 고침.** 터미널 메뉴에서 원격 사용자의 로그인 환경을 다시 읽습니다. SSH 재연결 후에도 자동으로 새로 고쳐집니다.


### 개선됨


- **더 명확해진 편집기 도구 모음.** 기호 작업은 더보기 안에 그룹화되어 있으며 브라우저 버튼은 제목 표시줄로 이동합니다. URL 대화 상자는 공유 스타일을 사용하고 주소를 열기 전에 유효성을 검사합니다.

- **현지화된 인터페이스 적용 범위.** 로컬 Linux, 브라우저 컨트롤, 링크 버튼, 작업 작업, 관련 편집기 및 AI 메타데이터는 상태, 오류 및 접근성 레이블을 포함하여 영어, 중국어 간체, 일본어, 한국어 및 러시아어를 지원합니다.

- **일관된 작업 공간 항목.** 로컬 Linux는 작업 공간 선택 카드와 표준 대화 상자 및 버튼 스타일을 공유합니다.

- **일관된 AI 작성기 아이콘.** 명령, 대화 작업, 설정 및 보내기는 기본 작업 및 선택 상태 강조를 유지하면서 앱의 아이콘 계열과 컴팩트한 크기를 공유합니다.

- **간단한 ACP 설정 및 일관된 실행 프레젠테이션.** 실행 내부는 기본적으로 축소됩니다. 사용하지 않는 자리 표시자와 실행 불가능한 옵션은 숨겨집니다. 도구 메타데이터 및 출력을 실행하면 공유 타임라인이 업데이트됩니다.

- **ACP 환경 가져오기.** 리터럴 `export` 할당, `NAME=value` 행 또는 JSON `env` 개체를 붙여넣습니다. 구문 분석 라이브러리는 명령을 실행하지 않고도 데이터의 유효성을 검사합니다. 미리보기 값은 마스크되어 있으며 병합된 초안은 저장해야 합니다.

- **단일 SSH 로그인 환경.** 터미널, ACP 서버, 에이전트 하위 프로세스, 작업, 디버그, 언어 서버, Git 및 외부 CLI는 동일한 원격 환경 확인자를 공유합니다.

- **사용자의 실제 셸.** NimoteCode는 원격 계정의 기본 셸을 감지하고 해결 방법 없이 bash, zsh, fish 및 기타 셸에서 일반 로그인 환경을 로드합니다.
- **완벽한 사용자 정의 도구 및 변수 상속.** 사용자 정의 `PATH`, 로케일, SSH 에이전트 및 사용자 정의 서비스 변수는 자연스럽게 원격 프로세스로 전달됩니다.

- **더 안전한 진단.** API 키, 토큰, 비밀, 비밀번호 및 유사한 환경 값이 로그 및 에이전트 시작 진단에서 수정됩니다.


### 고정


- 긴 메시지 및 지연된 레이아웃을 포함하여 Editor에서 돌아올 때 최신 AI 콘텐츠로의 스크롤을 복원했습니다.

- 저장이 성공하기 전에 작업 목록이 변경되고, 삭제된 작업이 다시 나타나고, 동시 저장 또는 새로 고침에서 업데이트가 손실되는 문제가 수정되었습니다. 저장과 삭제는 상호 배타적이며 실패한 작업은 초안을 보존하고 구성 저장은 임시 파일을 대체합니다.

- 중복된 기본 작업 ID, 기본 구성 구문 분석 및 편집 중에 작업 메타데이터가 손실되는 문제를 수정했습니다.

- SSH 권한 및 연결 오류가 누락된 파일로 처리되어 실수로 기본 작업 구성이 생성되는 것을 방지했습니다.

- 에이전트 파일 변경 요약, 원격 환경 상속, 줄 바꿈된 줄, 스크롤 및 와이드 문자가 포함된 터미널 링크 배치가 누락된 문제가 수정되었습니다.

- 명령이 터미널에서 작동하지만 ACP 에이전트, Claude Code, Codex CLI, 작업 또는 디버그에서 누락된 것처럼 보이는 문제를 수정했습니다.

- 완전한 원격 환경 없이 시작되고 불완전한 구성을 해당 하위 프로세스에 전달하는 ACP 서버를 수정했습니다.

- SSH 재연결 후 오래된 환경과 잘못된 `SSH_AUTH_SOCK` 경로를 수정했습니다.

- 공백, 줄 바꿈 또는 셸 메타 문자가 포함된 환경 값의 신뢰할 수 없는 상속을 수정했습니다.
