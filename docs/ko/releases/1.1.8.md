## 1.1.8 · 2026년 9월 14일 · 빌드 45


버전 1.1.8에서는 작업 공간 전환을 더욱 유연하게 만들고 Android 로컬 Linux 설치, 파일 작업 및 Git 안정성을 강화하고 소스 제어 및 전반적인 시각적 계층 구조를 개선하면서 **Early Access Pro**를 시작합니다.


**플랫폼 가용성:** 로컬 Linux 개선 사항은 Android에만 해당되며 iOS에서는 사용할 수 없습니다.


### 얼리 액세스 프로


Early Access Pro는 시간이 지남에 따라 더 많은 사용자에게 AI 에이전트, 원격 검색, Git 쓰기 워크플로, 다중 터미널, LSP, 디버그 및 동기화/캐시 등 고급 모바일 워크플로를 제공합니다. 가용성 및 표시 가격은 매장, 계정 및 지역에 따라 다릅니다. 현재 제공되는 혜택은 Google Play 또는 App Store에서 확인하세요.


### 신규


- **작업 영역 디렉터리를 전환합니다.** 활성 로컬 또는 SSH 작업 영역으로 다른 디렉터리를 선택합니다. 이전에 열린 디렉토리는 빠른 복귀를 위해 최근 기록에 유지됩니다.


### 개선됨


- **더 안정적인 로컬 Linux(Android만 해당).** PRoot 시작 및 런타임 준비가 더욱 강력해지고, 필요에 따라 게스트 임시 디렉터리가 준비되며, Ubuntu 기본 설치 호환성이 향상됩니다.

- **더 명확해진 파일 액세스 경계(Android만 해당).** 편집기, 검색, 언어 서비스, Git, 터미널 및 에이전트 작업은 이제 로컬 Linux에서 일관된 작업 영역 범위를 사용하여 런타임 경계를 넘어 발생하는 오류를 줄입니다.

- **더 안정적인 로컬 Linux Git(Android만 해당).** 작업에 의한 파일 변경을 포함하여 로컬 Linux 작업 영역의 Git 작업은 게스트 환경을 통해 실행되므로 상태, 차이점 및 기록이 실제 작업 영역을 반영합니다.

- **향상된 오픈 소스 제공(Android만 해당).** 이제 로컬 Linux에 더욱 완전한 패키지, 라이선스 및 소스 출처 기록이 포함됩니다.

- **더 단순한 시각적 계층 구조.** 테마, 패널, 탭, 터미널 명령 및 AI 실행 타임라인이 개선되어 주요 작업을 눈에 띄게 유지하면서 주의가 산만해지는 것을 줄였습니다.


### 고정됨


- iPad의 외부 물리적 키보드 입력이 응답하지 못하는 문제를 수정했습니다.

- 분기 전환 및 일관되지 않은 커밋 기록 스타일 지정 후 소스 제어가 즉시 새로 고쳐지지 않는 문제를 수정했습니다.

- 불완전한 로컬 Linux 임시 디렉터리 설정으로 인해 명령 또는 설치 흐름이 실패하는 경우가 수정되었습니다.
