## 1.1.9 · 2026년 9월 27일 · 빌드 48


버전 1.1.9는 사용 가능한 공간에 따라 선택된 레이아웃, 하나의 밀도 및 상태 언어, IDE 스타일 AI 타임라인, 새로운 인터페이스 스케일 등 하나의 디자인 시스템에서 인터페이스를 재구축하고 PHP 디버깅 및 더 폭넓은 구문 강조 기능을 추가하고 에이전트 세션, 에이전트 검색, 액세스 확인 및 시작을 보다 안정적으로 만듭니다.


**플랫폼 가용성:** 로컬 Linux 검색 개선 사항은 Android에만 해당되며 iOS에서는 사용할 수 없습니다.


### 신규


- **PHP 디버깅.** Xdebug 및 PHP 디버그 어댑터를 통해 원격 작업 공간에서 PHP 스크립트를 디버그합니다. 중단점을 설정하고, 디버그 패널에서 실행하고, 편집자가 Xdebug 환경을 구성하도록 합니다. 어댑터는 스크립트와 동일한 원격 호스트에서 실행됩니다. 자세한 내용은 `docs/php-debugging.md`에 있습니다.

- **더 폭넓은 구문 강조.** Markdown 코드 펜스 내에서 `<?php` 자동 감지를 포함하여 C#, CSS, HTML, Ruby, Lua, Kotlin, XML, PowerShell, SQL 및 INI, JSX/TSX 매핑, PHP 강조에 대한 문법을 ​​추가했습니다.

- **공급자 모델 목록.** 이제 AI 채팅 헤더와 프로필 편집기는 엔드포인트가 실제로 제공하는 모델(OpenAI 호환 `/models` 및 Ollama `/api/tags`)을 읽고 필요할 때 새로 고치고 마지막 선택을 기억합니다. 프로필 이름은 사용자가 직접 지정할 때까지 해당 모델을 따라 지정됩니다.

- **에이전트 세션 설정.** 핸드셰이크 중에 구성 가능한 옵션을 보고하는 에이전트는 이제 실행 명령별로 기억되는 AI 헤더에 모델 및 세션 선택 사항을 노출합니다.

- **인터페이스 배율.** 설정 → 모양 → 인터페이스 배율(100%~150%)은 크롬, 아이콘, 패널, 대화 상자, 편집기 및 터미널 등 전체 앱을 하나의 확대/축소로 확대합니다. iOS는 Apple의 서체 크기와 일치하도록 한 단계 위로 시작합니다. 100% 거부합니다.


### 개선됨


- **사용 가능한 공간별 레이아웃.** 이제 작업 공간은 장치 방향 대신에 있는 공간에서 구조를 선택합니다. 공간이 있는 창은 레일, 크기 조정 및 접을 수 있는 패널 및 편집기로 분할됩니다. 없는 사람은 단일 표면 전화 껍질을 얻습니다. 분할 보기, 크기 조정 가능한 창, 세로형 태블릿 및 가로형 휴대폰이 이제 올바른 레이아웃에 표시됩니다.

- **하나의 패널 설계 시스템.** 패널은 하나의 밀도 척도와 하나의 상태 언어로 재구성되었습니다. 휴대폰 탐색기에는 AI 패널, Git, 디버그, LSP 및 작업에서 9개와 실행 중, 대기 중, 성공, 경고, 오류 및 취소된 읽기가 동일하게 표시되었던 13개 행이 표시됩니다.

- **IDE 타임라인으로서의 AI 대화.** 차례는 더 이상 채팅 거품이 아닙니다. 사용자의 메시지는 인용된 블록이고, 계획 단계는 실제 상태를 전달하며, 각 도구 호출은 고정폭 명령줄과 변경된 파일당 `+n −m`가 포함된 하나의 압축 행이며, 변경 내용을 검토하면 파일당 하나의 행이 나열됩니다.

- **버튼, 아이콘 및 컨트롤에 대한 단일 스케일.** 버튼, 빈 상태, 아이콘, 작성기 및 중간 패널 컨트롤은 모두 하나의 컨트롤 크기를 공유하고, UI 텍스트는 플랫폼 글꼴을 사용하고, 코드 및 터미널은 8개 테마 모두에서 실제 고정 폭 체인을 사용합니다.

- **중립적인 밝은 색상과 어두운 색상 팔레트.** 상태, 반경 및 가는선용으로 예약된 브랜드 액센트를 사용하여 밝은 색상과 어두운 색상이 하나의 래더에 수렴되었으며 이제 모든 Git 패널 섹션이 하나의 헤더를 공유합니다.

- **하나의 메뉴 표면.** 고정된 팝업과 하단 시트는 동일한 행, 아이콘 크기 및 정렬을 그리고 메뉴는 가장 넓은 항목을 수용하며 패널 헤더 명령은 태블릿 너비에서 명령 모음이 됩니다.
- **탐색기 개선.** 긴 파일 및 디렉터리 이름은 트리를 옆으로 스크롤하여 접근할 수 있으며 행은 원시 재료 목록 타일 대신 파일 및 디렉터리에서 공유하는 터치 크기의 44px 밴드를 사용합니다.

- **세련된 작업 공간 크롬.** 세로 하단 탐색 높이와 아이콘 레이블 간격이 조정되었으며, 작업 공간 가장자리에 있는 부동 에이전트 상태 마커는 이제 이전과 같이 크기와 위치가 둥근 공입니다.

- **더 빠르고 제한된 에이전트 검색.** Workspace grep은 전역 결과 예산이 포함된 ripgrep을 통해 실행되며 로컬 Linux/PRoot 검색은 후보 파일당 하나의 원격 읽기 대신 `find` 및 `grep`를 통해 스트리밍됩니다. 참조 1000개 파일 고정 장치에서 약 3~0.2초가 소요됩니다.

- **Clearer Pro 액세스 프레젠테이션.** Pro 액세스 카드 및 구독 페이지에서는 체험판, 조기 액세스, 하나의 소스에서 제공되는 유료 및 무료를 설명하며 남은 체험판 시간, 복원 및 다른 계정에 연결된 구독에 대한 보다 명확한 표현을 제공합니다.


### 고정


- 저장된 연결을 다시 연 후 붙여넣었거나 가져온 키 자격 증명이 손실되는 SSH 개인 키 연결을 수정했습니다. 이제 임시 파일 선택기 경로에 의존하지 않고 가져온 키가 안전하게 유지됩니다.

- Android 로컬 Linux 탐색기가 `/workspace`에서 게스트 루트 및 `/home`과 같은 디렉터리로 이동할 수 없는 문제를 수정했습니다.

- 휴대폰의 "추가" 메뉴 및 팝업 수정: Git, 편집기 및 터미널 메뉴는 이제 앱의 나머지 부분에서 사용하는 것과 동일한 고정 팝업을 열고, 화면을 채우는 대신 가장 넓은 행을 표시하고, 소프트 키보드가 켜져 있는 동안 계속 사용할 수 있으며, 항목이 열린 후 더 이상 화면에 자체 페이지를 떠나지 않습니다.

- 앞 가장자리에 탭이 있고 뒷 가장자리에 명령이 있는 하나의 VS Code 스타일 밴드로 터미널 헤더를 재작업하고 iOS가 단일 Return 키를 두 번 제출하는 문제를 수정했습니다.

- 작업 영역이 그려질 때까지 하나의 기본 시작 레이어가 앱 자체 테마 및 언어로 브랜드 마크, 슬로건 및 로딩 바를 보유하도록 Android 및 iOS 시작 화면을 수정했습니다.

- 킬 스위치가 없거나 연결할 수 없거나 RevenueCat ID 재조정 실패, 서버 또는 장치 시계 오차로 인해 로그인한 사용자에게 초기 액세스 및 유료 Pro가 거부되는 문제를 수정했습니다.

- 기록을 스크롤하는 동안 AI 성적표가 독자 위치를 잃어버리는 문제, 편집기에 파일이 열리지 않은 상태에서 흩어진 구분선과 중복된 브라우저 열기 버튼이 표시되는 문제, SSH, 편집기 검색, Git, 설정 및 탐색기 파일 검색 시트에서 모달 시트를 닫은 후 충돌이 발생하는 문제를 수정했습니다.

- Git 커밋 세부 정보 및 Diff 상단 간격 및 가독성, 사이드바 선택 애니메이션, 브라우저 버튼과 충돌하는 LSP 명령, 일관되지 않은 URL 프롬프트, 에이전트 매개변수 행 및 Git 기록 헤더 스타일을 수정했습니다.
