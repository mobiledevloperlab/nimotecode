## 1.2.2 · 2026년 10월 9일 · 빌드 52


버전 1.2.2는 앱 샌드박스 외부의 프로젝트 폴더를 열고, Git을 랜드스케이프 편집기로 가져오고, 작업하는 동안 Git 상태와 터미널 세션을 최신 상태로 유지합니다.


### 신규


- **외부 프로젝트 폴더 열기.** Android 및 iPadOS/iPhone에서는 시스템 폴더 선택기를 사용하여 앱 자체 문서 폴더 외부의 프로젝트 디렉터리를 열 수 있습니다. NimoteCode는 플랫폼 부여를 통해 액세스를 요청하고, 다시 시작할 때 이를 기억하며, 보안 파일 공급자를 통해 읽고 씁니다. 이러한 작업공간은 원시 URI 대신 친숙한 위치를 표시하며 기본 파일 시스템 경로(Git, LSP, 디버그, 작업, 파일 감시자 및 에이전트)가 필요한 기능이 미리 보고됩니다.

- **랜드스케이프 편집기의 Git 페이지.** 고정된 랜드스케이프 작업 공간에서 Git diff, 커밋 diff 및 충돌 해결 페이지가 이제 편집기 영역에서 열립니다. 동일한 위치에 설정이 표시되므로 IDE 컨텍스트를 떠나지 않고도 변경 사항을 검토할 수 있습니다. 세로 모드는 기존 전체 화면 페이지를 유지합니다.

- **거의 실시간 Git 상태.** 이제 다음 폴링을 기다리는 대신 터미널, Explorer 작업 또는 외부 도구에서 파일이 변경되면 탐색기 장식 및 소스 제어 패널이 업데이트됩니다.


### 개선됨


- **가로 디렉터리 선택기는 전체 너비를 사용합니다.** 고정된 가로 작업 공간에서 로컬 또는 원격 폴더를 열면 선택기가 두 개의 창으로 분할됩니다. 즉, 왼쪽에서 폴더를 찾아보고, 경로를 편집하고, 오른쪽에서 선택기가 가리키는 폴더를 확인합니다. 세로 창과 좁은 창은 단일 열을 유지합니다. 가로 빈 상태는 또한 작업 목록 옆에 그림을 배치합니다.

- **외부 작업 공간의 친숙한 이름.** 외부 작업 공간에서 탐색기, 편집기 탭, 이동 경로, Markdown 미리 보기 제목 및 검색 결과에는 원시 `content://` 주소 대신 공급자의 폴더 및 파일 이름이 표시됩니다.

- **카드 기반 가로 패널.** 이제 가로 중간 패널이 편집기 카드와 일치합니다. 편집기의 표면과 둥근 모서리를 공유하고 활동 레일이 전체 높이로 실행되며 패널과 편집기 사이의 드래그 스트립이 중앙에 유지됩니다.

- **Denser Explorer 기본값.** 새로 설치하면 기본 Explorer 디렉터리 텍스트가 14로, 행 높이가 35로 설치되므로 휴대폰과 태블릿에서 한 번에 더 많은 항목이 표시됩니다. 귀하가 저장한 기본 설정이 여전히 유효합니다.

- **방해되지 않는 터미널 사전 설정.** "/" 빠른 액세스 사전 설정이 추가되었으며 사전 설정을 탭하면 더 이상 소프트 키보드가 닫히지 않습니다. 사전 설정은 활성 터미널에 기록하고 터미널이 이미 키보드를 소유한 경우에만 포커스를 복원합니다.

- **SSH 세션은 짧은 중단에도 살아남습니다.** 짧은 백그라운드 주기 후에 NimoteCode는 연결이 끊겼다고 선언하기 전에 전송을 다시 확인하므로 라이브 세션은 스크롤백을 유지합니다. 실제로 죽은 세션이 여전히 다시 연결됩니다.


### 고정됨


- 새 설치는 장치 언어를 따르거나 중국어로 돌아가는 대신 기본적으로 영어로 설치됩니다. 명시적인 언어 선택이 여전히 기억됩니다.

- 로컬 및 원격 탐색기가 단일 가는 선을 그릴 수 있도록 로컬 탐색기 헤더 아래 중복 구분선을 수정했습니다.

- 테마가 변경될 때 Explorer 세션 기록 및 원격 디렉터리 선택기 페이지가 다시 그려지지 않는 문제를 수정했습니다.

- 로컬 Git 상태에서 하위 디렉터리 변경 사항이 누락되고 추적되지 않는 파일이 수정되었습니다.

- 외부 작업 공간에서 파일을 쓰거나 삭제한 후 Android 충돌이 수정되었습니다.
