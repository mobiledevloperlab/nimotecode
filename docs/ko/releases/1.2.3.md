## 1.2.3 · 2026년 10월 15일


버전 1.2.3은 공유 로컬 Linux 프로젝트, 보다 탄력적인 SSH 세션, 앱 외부 작업 상태 업데이트, 구성 가능한 터미널 및 세련된 어두운 외관을 통해 모바일 개발 워크플로를 개선합니다.


### 신규


- **로컬 Linux(Android)와 로컬 프로젝트 공유.** 로컬 Linux에서 공유 로컬 프로젝트를 활성화한 다음 Linux 작업 영역의 `/mnt/local`에서 동일한 앱 로컬 프로젝트를 엽니다. 전화번호부를 새 공유 프로젝트로 가져오거나 작업이 끝나면 프로젝트 복사본을 내보낼 수도 있습니다.

- **앱 외부의 작업 상태.** iPhone 및 iPad는 관찰된 AI 및 터미널 작업을 라이브 활동으로 표시할 수 있습니다. Android는 관찰된 AI 및 터미널 작업 상태에 대해 선택적이고 무시할 수 있는 알림을 표시할 수 있습니다. 이러한 표면은 마지막으로 알려진 상태를 보고합니다. 백그라운드에서 작업을 계속 실행하지 않습니다.

- **모바일 단말기 제어.** 일회성 및 잠금 수정자를 사용하여 소형 또는 확장된 추가 키 행을 선택합니다. 새로운 초점 모드는 필요할 때 터미널에 더 많은 공간을 제공합니다.

- **선택적 SSH 백그라운드 지원(Android).** 개방형 SSH 작업 영역은 지원을 중지하거나 시스템 안내를 볼 수 있는 컨트롤과 함께 Android 포그라운드 서비스 알림을 사용할 수 있습니다.


### 개선됨


- **로컬 Linux로 가져온 프로젝트는 안정적으로 열립니다.** 가져온 프로젝트는 이제 공유 Linux 위치에서 직접 열립니다. 새 SSH 작업 영역도 기본적으로 원격 홈 디렉터리에서 시작됩니다.

- **SSH는 더욱 원활하게 복구됩니다.** 백그라운드링은 더 이상 라이브 SSH 세션 또는 Explorer 상태를 즉시 삭제하지 않습니다. iOS는 백그라운드에서 프로브를 일시 중지하고 돌아올 때 전송의 유효성을 검사합니다.

- **더 깊은 다크 테마.** 이제 기본 다크 테마는 표면, 필드, 오버레이 및 대비 색상이 조정된 AMOLED 블랙 캔버스를 사용합니다. 시작 화면은 동일한 팔레트를 사용합니다.

- **더 깔끔해진 터미널 헤더 및 시작 화면.** 터미널 작업은 더 간단한 오버플로 메뉴로 그룹화되었으며, 이제 시작 애니메이션과 색상이 앱과 더 잘 어울립니다.


### 고정


- 작업 공간별 편집기, AI 기록, 인증, Git 기록 및 SSH 상태가 다른 작업 공간으로 유출되는 문제를 수정했습니다.

- SSH EOF 프로브로 인해 불필요한 복구가 발생하는 문제가 수정되었으며 연결 복구 중에 Explorer가 보존되었습니다.

- 앱의 대화 상자 디자인을 따르도록 배경 SSH 지침을 수정했습니다.
