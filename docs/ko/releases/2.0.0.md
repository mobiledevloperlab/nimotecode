## NimoteCode 2.0.0

NimoteCode 2.0은 IDE를 안전하게 사용자 지정할 수 있는 작업 공간으로 확장합니다. AI Agent 작업을 계속 진행하면서 Git, 터미널 및 일상적인 편집을 더 일관된 환경에서 처리할 수 있습니다.

<span id="release-new"></span>

### 새로운 기능 · 5

- **플러그인 센터와 사용자 지정 작업 공간.** 기능 센터에서 작업 공간 기능을 관리하고, 맞춤 플러그인과 선언형 패널을 만들며, 로컬 또는 SSH 대상에서 양식, 워크플로, 결과 보기, 스크립트 작업을 사용할 수 있습니다. 설치나 업데이트를 진행하기 전에 권한 변경 사항이 검토용으로 표시됩니다.
- **연속적인 AI Agent 협업.** 실행 중인 Agent에 후속 지시를 추가하고 필요할 때 대화형 질문에 답할 수 있습니다. 컨텍스트, 기록, 프롬프트 편집 및 실행 타임라인도 장시간 작업에 맞게 새롭게 구성되었습니다.
- **향상된 Git 브랜치와 diff.** Git 헤더에서 브랜치를 검색, 생성, 체크아웃할 수 있습니다. 편집기는 절제된 여백 표시로 Git 변경 사항을 나타내고, diff는 더 명확한 구문 강조로 표시합니다.
- **더 직접적인 터미널 지원.** 터미널 출력을 AI에 바로 보내 분석할 수 있으며, 터미널 탭 설정에도 더 쉽게 접근할 수 있습니다.
- **유연한 원격 연결.** 네트워크 환경상 필요한 경우 SOCKS5 또는 HTTP CONNECT 프록시를 통해 SSH 작업 공간에 연결할 수 있습니다.

<span id="release-improved"></span>

### 개선됨 · 6

- **새로워진 시각 및 레이아웃 시스템.** Material 3 스타일, 테마, 설정, Explorer 도구 모음, 빈 상태, Markdown 미리 보기, 시작 애니메이션이 더 일관된 디자인을 공유합니다. 기본 UI 배율은 작업 공간을 더 확보할 수 있도록 90%로 설정됩니다.
- **더 견고한 플러그인 런타임.** 플러그인 패널은 실행 상태를 유지하고 오래된 업데이트를 방지합니다. 포그라운드 워크플로는 단계적 양식을 지원하며, 지속 작업은 대상 환경에서 계속 실행할 수 있고, 플러그인을 삭제하면 해당 작업이 안전하게 취소됩니다.
- **더 효율적인 AI 및 리소스 사용.** 긴 채팅은 대화 라운드별로 접히고 기록은 필요할 때 펼칠 수 있습니다. 숨겨진 패널은 불필요한 새로 고침을 중지하며, 편집기와 채팅 기록의 메모리 사용량도 제한됩니다.
- **더 자연스러운 모바일 워크플로.** Android의 AI 진입점은 이제 Dynamic Island 스타일 컨트롤을 사용하며, 계정, 구독, 모양 및 공유 입력 표면은 다양한 화면 크기에 더 일관되게 맞춰집니다.
- **모든 기기에서 하나의 편집기.** Nimote Editor가 이제 휴대폰, 태블릿, 데스크톱의 기본 편집기입니다. 모든 기기 형태에서 일관된 텍스트 선택, 키보드 및 IME 동작, 실행 취소, 붙여넣기, 찾기 및 바꾸기, 커서 처리를 제공합니다.
- **작업 공간에 맞는 터미널 색상.** 구성 가능한 터미널 색상표를 선택할 수 있으며, 터미널과 모바일 시스템 UI는 현재 테마와 시각적으로 조화를 이룹니다.

<span id="release-fixed"></span>

### 수정됨 · 5

- 플러그인 메타데이터 호환성, 권한 업데이트, 패널 스크롤 및 작업 취소의 경계 사례를 해결했습니다.
- 실행 타임라인에서 AI 후속 작업의 위치, 공유 입력의 수직 정렬 및 Explorer 도구 모음 레이아웃을 수정했습니다.
- 내장 Agent 런타임과 작업 공간 도구의 안정성 및 보안 경계를 강화했습니다.
- 특히 모바일 키보드를 사용하거나 세션을 다시 연결할 때 편집기와 터미널에서 발생할 수 있는 포커스, 선택, 줄 편집 및 비동기 세션의 경계 사례를 수정했습니다.
- 장시간 실행되는 Agent 작업의 출력을 더 명확하고 간결하게 개선하고, 구성된 단계 예산에 도달했을 때 계속 실행할 수 있는 옵션을 추가했습니다.
