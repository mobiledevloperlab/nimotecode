## NimoteCode 2.1.0

2.1.0은 기기 전반의 작업 공간 경험을 개선하고, 특히 매우 긴 줄이나 압축된 파일이 있는 대규모 코드베이스에서 내장 Agent의 검색과 이해를 더 효율적이고 안정적으로 만듭니다.

<span id="release-improved"></span>

### 개선됨 · 5

- **더 효율적인 코드 검색.** Agent는 검색 결과 컨텍스트를 필요한 범위로 제한하고 표시할 텍스트만 구성하여, 대용량 또는 압축 파일 검색 시 메모리 사용량과 대기 시간을 줄입니다.
- **더 안정적인 파일 요약.** 파일을 요약할 때 Agent는 가장 관련성 높은 코드 발췌를 유지하면서 긴 파일의 처리량을 줄이고 일관된 결과를 보장합니다.
- **기기 전반에서 통일된 작업 공간.** 외관 모드와 강조 색상을 따로 선택할 수 있으며, 휴대폰, 태블릿, 데스크톱에서 작업 공간의 레이아웃, 컨트롤, 타이포그래피가 더 일관됩니다.
- **더 매끄러운 가로 화면 및 편집 경험.** 가로 화면에서 작업 공간 페이지와 Git 기록을 편집기 탭으로 열 수 있고, 전체 화면 터미널 후에도 편집기 헤더가 유지됩니다. 편집기 렌더링, 구문 강조, Git diff 타이포그래피도 개선했습니다.
- **더 직접적인 검색과 모바일 조작.** 파일 검색을 바로 열 수 있고 원격 연결 상태는 디렉터리 옆에 표시됩니다. 모바일 Agent와 터미널의 드래그, 키보드 선택, 복사 조작도 더 부드러워졌습니다.
