## NimoteCode 2.2.0

2.2.0은 GitHub 워크플로를 NimoteCode에 도입합니다. 전용 GitHub 페이지에서 로그인하고 저장소를 탐색하여 프로젝트를 연 다음, 익숙한 작업 공간에서 브랜치, 이슈, 풀 리퀘스트 및 CI를 사용할 수 있습니다. 이번 릴리스에는 Android Local Linux용 실험적인 개발 도구 키트도 추가되었으며, 검색 신뢰성을 높이고 앱 전반의 패널과 대화 경험을 통일했습니다.

<span id="release-new"></span>

### 새 기능 · 3

- **네이티브 GitHub 개발 워크플로.** 브라우저 기기 인증 또는 토큰으로 로그인하고, 저장소, 브랜치 및 저장소 세부 정보를 탐색한 뒤 로컬 또는 SSH 작업 공간에 프로젝트를 복제하여 열 수 있습니다.
- **이슈, 풀 리퀘스트 및 CI 협업.** 이슈, 풀 리퀘스트, 리뷰 및 검사를 보고 필터링할 수 있습니다. 이슈 컨텍스트로 Agent 작업을 시작한 후, 작업이 준비되면 브랜치를 만들고 변경 사항을 push하며 fork 또는 풀 리퀘스트를 만들 수 있습니다.
- **Android Local Linux 도구 키트(실험적 기능).** 명령줄 필수 도구, Python 및 Web 도구를 필요에 따라 설치합니다. Linux를 다시 설치하거나 기존 프로젝트를 덮어쓰지 않고 예제 프로젝트를 만들고 실행하여 열 수 있습니다. 최초 설치에는 인터넷 연결이 필요합니다.

<span id="release-improved"></span>

### 개선됨 · 5

- **더 안정적인 GitHub 작업.** 로그인, 프로젝트 복제 및 Local Linux 작업 공간 작업이 더 안정적이며, 실패한 push와 게시를 복구하는 단계도 더 명확해졌습니다.
- **더 견고한 작업 공간 검색.** 검색 결과, 강조 표시 및 모바일 상호작용이 더 안정적입니다. Android Local Linux의 코드 검색은 추가 설정 없이 동작합니다.
- **더 일관된 워크벤치.** 설정, 소스 제어, GitHub, 검색 및 기타 패널은 이제 더 명확한 표면, 타이포그래피, 컨트롤 및 좁은 레이아웃 동작을 공유합니다. 대화와 개요 레이아웃도 더 쉽게 훑어볼 수 있습니다.
- **더 명확한 도구 키트 상태.** 설치 전에 예상 다운로드와 저장 공간을 보고, 준비가 되면 예제와 도구 확인에 집중할 수 있습니다. 작업 로그, 다시 시도 및 중단 안내가 복구를 돕고 페이지를 떠나도 작업은 취소되지 않습니다. 타이포그래피, 간격, 버튼 및 확인 대화상자도 워크벤치와 일치합니다.
- **일관된 복사 피드백.** 일반 패널에서 복사하면 명확하고 일관된 피드백을 제공합니다.

<span id="release-fixed"></span>

### 수정됨 · 2

- 일시적인 GitHub API 실패, 모바일 HTTPS 복제, 취소 및 복제 대상 복구를 해결하고, 사용해서는 안 되는 Git 작업에는 자격 증명이 전달되지 않도록 했습니다.
- 원격 작업 공간의 검색 결과와 강조 표시를 개선하여 큰 결과나 모바일 상호작용에서 발생하는 중단 및 표시 문제를 줄였습니다.
