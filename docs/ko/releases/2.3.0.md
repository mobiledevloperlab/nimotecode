## NimoteCode 2.3.0

2.3.0에서는 IDE, 터미널, AI 모드를 전환해도 같은 프로젝트와 Explorer 상태를 유지합니다. 플러그인, Windows SSH 작업 공간, Agent 협업, 터미널, 모바일 Git 검토, SSH 호스트 Docker 개발도 개선했습니다.

<span id="release-new"></span>

### 새 기능 · 6

- IDE, 터미널, AI 모드를 전환하면서 프로젝트와 Explorer 상태를 공유합니다.
- 플러그인은 버전이 지정된 기여 및 종속성을 선언하고 설치 전에 검증할 수 있습니다. 승인된 도구, 스킬 및 워크플로를 내장 Agent에 제공할 수 있습니다.
- PowerShell/SFTP로 Windows 원격 작업 공간을 탐색하고 검색, Git, 터미널, 언어 서비스 및 Agent를 사용할 수 있습니다.
- 지원되는 ACP Agent에 실행 중인 작업의 후속 지시를 보낼 수 있습니다.
- SSH 호스트에서 컨테이너, 이미지, 볼륨, 네트워크, Compose를 관리하고 로그, 통계, exec, Docker Hub 검색을 사용할 수 있습니다.
- devcontainer.json에서 Dev Container를 만들거나 다시 빌드하고 구성된 격리 작업 공간을 엽니다.

<span id="release-improved"></span>

### 개선

- 터미널 분할, 출력에서 IDE 이동 및 AI 분석, 명령 기록, 표시 설정 저장, 확대/축소, 연결별 프롬프트를 개선했습니다. Git 검토, Windows SSH, Agent 진단, Docker 복구 및 권한 상태도 향상했습니다.
