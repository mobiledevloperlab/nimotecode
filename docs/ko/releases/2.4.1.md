# NimoteCode 2.4.1 · Host 워크스페이스 및 파일 전송

2026년 11월 19일 · Build 66

<LatestReleaseLink />

[← 모든 릴리스](/ko/releases/)

2.4.1은 인터페이스와 태블릿 레이아웃을 개편하고 원격 터미널 및 Agent 세션을 관리하는 Host 워크스페이스를 추가합니다. 파일 전송과 프로젝트 작업 검색을 지원하며 GitHub CI, 터미널 기록 검색, 원격 저장을 개선합니다.

<span id="release-new"></span>

### 추가

- **Host 워크스페이스**: 호환 NimoteHost를 원격으로 설치하고 시작한 뒤 SSH로 연결해 원격 터미널과 Agent 세션을 확인하고 재개합니다.
- **Host Agent 세션**: 지원되는 세션에서 구조화된 대화, 승인, 명령, 모델 제어를 사용합니다.
- **Host 작업 수신함**: 작업, 검증 결과, Diff를 검토하거나 GitHub Issue를 Agent에 전달합니다. 사용 가능한 기능은 Host의 기능과 설정에 따라 다릅니다.
- **Host 플러그인**: 호환 Host 플러그인을 사용하고 프로젝트 작업을 워크스페이스 터미널에 연결합니다.
- **파일 및 폴더 전송**: 기기와 SSH 워크스페이스 사이에 파일과 폴더를 전송하거나 로컬에서 가져오고 내보냅니다.
- **프로젝트 작업 검색**: npm, Taskfile, Makefile, justfile, VS Code 작업 정의에서 지원되는 작업을 찾습니다.

<span id="release-improved"></span>

### 개선

- **인터페이스 및 태블릿 지원**: 워크벤치를 개편하고 가로 화면, 태블릿, 편집기 조작, 모바일 Git 검토를 개선합니다. 탐색기에 Git 상태 색상을 표시합니다.
- **워크스페이스 및 플러그인**: 프로젝트와 탐색기 상태를 유지하며 IDE, 터미널, AI를 전환합니다. 플러그인, 지원되는 Agent의 실행 중 추가 지시, Windows SSH를 개선합니다.
- **터미널 조작**: 응답성, 검색, 스크롤, 클립보드, 대화형 프로그램 사용을 개선합니다. 보관된 기록 검색, 전각 문자 선택, 마우스 입력을 개선합니다.
- **터미널 및 개발 도구**: 출력의 파일 위치를 열고 선택 내용을 AI로 보내며 지원되는 명령 기록을 확인합니다. 적응형 분할, SSH의 Docker 및 Compose 관리, Dev Container 생성을 지원합니다.
- **GitHub CI**: 워크플로 실행을 필터링하고 단계별 로그와 오류 문맥을 확인합니다.
- **설정 및 접근성**: 앱 설정 진입점을 통합하고 동작 줄이기 지원을 개선합니다. Agent 소리와 진동, 편집기 줄 번호, 가로 화면 미니맵을 설정합니다.
- **SSH 및 원격 저장**: SSH 호스트 확인과 원격 저장 안정성을 개선하며 Windows 호스트 저장도 포함합니다.

<span id="release-fixed"></span>

### 수정

- 여러 버그를 수정했습니다.

Host 기능에는 호환 NimoteHost가 필요합니다. Agent 및 플러그인 제공 여부는 Host 기능과 설정에 따라 다릅니다.
