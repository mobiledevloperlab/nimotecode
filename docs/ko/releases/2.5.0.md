# NimoteCode 2.5.0 · 페어링된 컴퓨터 SSH, 지속 터미널, NimoteHost 설치

출시 예정 · Build 68

[현재 출시 버전 · 2.4.1](/ko/releases/2.4.1) · [← 릴리스 기록](/ko/releases/)

### 원격 연결과 Host

- 연결 선택 화면에서 페어링된 컴퓨터를 고르고, 동기화된 Tailscale IP 또는 MagicDNS 이름을 기존 SSH 비밀번호나 키와 함께 사용하세요. 앱에서 페어링을 해제하거나 수동으로 SSH에 연결할 수 있습니다.
- Nimote Connect의 공용 인터넷 접속은 계획 단계이며 Free 및 Pro 한도는 미정입니다. 일반 SSH와 개인 Tailscale은 사용할 수 있습니다.
- 느리거나 불안정한 네트워크의 SSH 연결과 복구, 터미널 입출력, 창 크기 변경, SFTP 읽기를 개선했습니다. Android의 SSH 키 파일 호환성도 개선했습니다.
- Host 패널에서 NimoteHost의 상태와 버전을 확인하고 승인 후 SSH로 설치, 시작 또는 패널에 표시된 릴리스로 업데이트할 수 있습니다. 오류 원인과 재시도 옵션이 표시되며, 업데이트에 세션 중지가 필요하면 먼저 확인합니다.
- **페어링 보안과 복구.** Relay는 승인, 컴퓨터 확인, 터널 연결, SSH 로그인을 단계별로 표시합니다. 페어링을 해제하면 Relay 접근도 취소됩니다. 호환 Host에서는 같은 컴퓨터의 확인된 경로로 동일한 작업 공간을 열 수 있습니다.

### 터미널

- Pro에서 tmux가 설치된 호환 SSH 호스트의 지속 세션을 터미널 메뉴에서 만들거나 재개할 수 있습니다. 로컬 탭을 닫아도 작업은 계속되며 같은 메뉴에서 원격 세션을 종료할 수 있습니다.
- tmux 기록 스크롤, 첫 화면 표시, 커서 위치와 가로 모드 키보드를 개선했습니다. 고급 검색은 중국어 입력 조합이 끝날 때까지 기다립니다.
- 두 번 탭하여 단어를 선택하거나 폭이 넓은 문자를 선택하기가 쉬워졌습니다. Codex나 Claude Code처럼 마우스 입력을 사용하는 프로그램에서는 Shift를 누른 채 드래그하고 오른쪽 클릭 메뉴에서 복사하세요. 화면을 다시 그려도 선택 내용이 유지됩니다.
- **터미널 조작.** 기록이나 원격 목록에서 tmux에 다시 연결할 수 있으며 같은 SSH 사용자로 다른 클라이언트에서도 이용할 수 있습니다. 가로 모드에서 키보드를 열었을 때 공간이 충분하면 Esc와 Ctrl 등이 표시됩니다. 알림이 표시되는 동안에도 메뉴를 조작할 수 있습니다.

### 작업 공간, 편집기 및 Git

- 세로 모드 휴대전화에 플로팅 탐색 메뉴를 추가했습니다. IDE와 Host의 연결 조작을 통일하고, 단일 창의 빈 편집기에서 파일을 탐색할 수 있습니다.
- 작업 공간 검색에서 일치한 파일을 열고 해당 위치를 강조 표시합니다. SSH 검색, 큰 디렉터리 열기, 분할 탭과 스크롤바 동작을 개선했습니다.
- 편집기에서 Git 파일 기록을 바로 열 수 있습니다. 이름이 바뀐 파일도 추적하고 실패하면 다시 시도할 수 있습니다. 대규모 저장소의 변경 목록은 필요한 항목부터 불러옵니다.
- 선택 영역 대비와 복사, 원격 폴더 선택, 작업 저장·삭제 중 필드 편집 동작을 개선했습니다.
- **Git 기록과 Agent 검토.** 파일과 줄 기록은 결과 없음과 로드 오류를 구분하며 재시도와 원격 폴더 별칭을 지원합니다. 기록된 스냅샷이 없으면 검토 카드에서 이유와 현재 Git diff를 확인할 수 있습니다.

### AI와 플랫폼

- 내장 Codex의 응답, 취소, 도구 호출이 개선됐습니다. Agent는 중단된 기록을 복원할 때 취소된 턴을 유지하며 큰 저장소에서 검색과 파일 처리가 개선됐습니다.
- Android 로컬 Linux가 매니페스트 기반 개발 도구 모음을 지원합니다. 커뮤니티도 같은 형식으로 기여할 수 있습니다. iOS 시작과 수명 주기, 데스크톱 이메일 로그인을 개선했습니다. 데스크톱 권한은 계정에 따라 적용됩니다.
- Free에서는 Git 상태와 차이 확인, 스테이징, 스테이징 취소 및 커밋을 지원합니다. GUI 푸시·풀·브랜치·스태시, Git AI 및 고급 GitHub 통합에는 Pro가 필요합니다. Docker 및 Dev Container에는 Pro와 호환 호스트가 필요합니다. 디버깅에는 Pro 및 구성된 디버그 어댑터가 필요합니다.
- **작업 공간과 플랫폼.** 작업 공간 메뉴에 GitHub와 데모 프로젝트가 표시됩니다. AI 입력창의 터치 영역이 넓어지고 높이가 낮은 화면에서 빈 대화를 스크롤할 수 있습니다. 작업 및 플러그인은 플랫폼에서 사용할 수 있는 실행 대상을 표시합니다. 로컬 Linux는 Android에서 제공됩니다.
