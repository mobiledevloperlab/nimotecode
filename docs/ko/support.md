# NimoteCode 지원

문의할 때 기기, 앱 버전, 문제에 대한 안전한 설명, 오류 메시지를 포함해 주세요. 비밀번호, 개인 키, API 키는 보내지 마세요.

## 자주 묻는 도움말

- **SSH 연결**: 호스트, 포트, 사용자 이름, 인증 방법, 네트워크 연결을 확인하세요.
- **AI 제공업체**: 기본 URL, 모델 이름, 제공업체 계정의 접근 권한을 확인하세요. NimoteCode는 BYOK를 사용합니다.
- **Pro 복원**: 구매에 사용한 계정으로 로그인하고 스토어 구독이 활성화되었는지 확인한 다음 앱에서 복원을 실행하세요.

## 문의하기

계정, 구독, 비공개 지원 요청은 [support@nimotecode.com](mailto:support@nimotecode.com)으로 보내세요. 재현 가능한 제품 버그와 기능 제안은 [GitHub Issues](https://github.com/mobiledevloperlab/nimote_issues/issues)를 사용하세요.

개인정보 처리방침, 계정 삭제, 이용약관은 현재 [English support pages](/support)에서 확인할 수 있습니다.
