## 빠른 확인 {#quick-checks}

**SSH:** host, port, username, 인증 방식과 네트워크 연결을 확인하세요. 저장된 연결에서 시작하고 `pwd` 같은 읽기 전용 명령으로 현재 경로를 확인하세요.

**AI Provider / API Key:** base URL, 모델명과 제공자 계정 권한을 확인하세요. 모델 접근과 API 요금은 제공자가 정합니다. 지원팀에 API Key를 보내지 마세요.

## 구매·취소 {#purchases}

원래 구매한 Apple / Google 스토어 계정부터 확인한 후 NimoteCode 계정과 **Restore Purchase**를 확인하세요. 스토어 계정과 앱 계정은 별도입니다. 복원을 위해 재구매하지 마세요.

| 작업 | Apple | Google Play |
| --- | --- | --- |
| 관리·취소 | [구독 관리](https://apps.apple.com/account/subscriptions) | [구독 관리](https://play.google.com/store/account/subscriptions) |
| 환불 | [환불 요청](https://reportaproblem.apple.com/) | [환불 안내](https://support.google.com/googleplay/answer/2479637) |

계정 삭제·앱 제거·로그아웃으로 구독이 취소되지 않습니다. 일반적으로 결제한 기간까지 이용 가능합니다. 앱 체험·Early Access와 유료로 전환될 수 있는 스토어 체험은 다릅니다. [약관](/ko/terms#billing).

## AI 응답 신고 {#ai-report}

현재 신고 기능은 로컬에 저장한 후 이메일 초안을 엽니다. **저장·초안 작성만으로 지원팀에 전송되지 않습니다.** 내용을 확인하고 보내세요. 메일 앱이 없다면 필요한 내용만 이메일로 보낼 수 있습니다. 사유, Provider, 모델, 버전과 해당 응답 일부로 충분합니다.
