## 집중된 모바일 루프


1. 로컬 프로젝트를 열거나 원하는 SSH 호스트 및 프로젝트 루트에 연결하세요.

2. 관련 파일을 검사한 다음 편집기에서 원하는 대로 편집합니다.

3. 터미널을 사용하여 로그를 확인하고 테스트를 실행하거나 변경된 동작을 확인하세요.

4. 커밋 또는 전달 단계 전에 소스 제어에서 결과 차이점을 검토하세요.


워크플로는 프로젝트에 필요한 검토, 액세스 제어 및 검증을 대체하는 것이 아니라 책상 밖에서 실제적이고 제한적인 작업을 위해 설계되었습니다.
