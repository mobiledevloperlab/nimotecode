# 터미널에서 직접 AI 코딩 도구 실행


NimoteCode 터미널은 일반 쉘 명령으로 제한되지 않습니다. **Codex**, **Claude** 및 **Kimi**와 같은 AI 코딩 도구를 활성 작업 공간에서 직접 실행하여 명령, 출력, 파일 및 다음 편집을 하나의 모바일 개발 환경에 유지할 수 있습니다.

## 프로젝트 컨텍스트에서 AI 도구 유지


현재 작업 중인 프로젝트 디렉터리에서 도구를 실행한 다음 탐색기, 편집기 및 소스 제어와 함께 출력을 검사합니다. 이렇게 하면 생성된 명령을 더 쉽게 따르고, 해당 명령과 관련된 파일을 이해하고, 결과 차이점을 검토할 수 있습니다.


## 실용적인 모바일 단말 루프


1. 원하는 로컬 또는 SSH 작업공간을 열고 프로젝트 루트를 확인합니다.

2. Codex, Claude, Kimi 또는 기타 구성된 명령줄 AI 도구를 터미널에서 실행하세요.

3. 출력을 읽고, 변경된 파일을 검사하고, 프로젝트의 확인 명령을 실행합니다.

4. 작업을 커밋하거나 전달하기 전에 차이점을 검토하세요.


> AI 명령줄 도구는 작업 영역에서 사용 가능한 자격 증명, 권한 및 환경을 사용합니다. 특히 원격 또는 프로덕션에 인접한 호스트에 명령 및 파일 변경 사항을 적용하기 전에 검토하십시오.
