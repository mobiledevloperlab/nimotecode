## Why Pro

Pro exists for the moments mobile work has to end with a carefully reviewed result: a gated Git commit after checking the diff, several terminal contexts at once, configured LSP feedback, a debug session, or an AI Agent task. It does not remove the need to review commands, diffs or AI suggestions — especially on production systems.
