# NimoteCode Pro

Free includes local and SSH workspaces, editing, the basic terminal, and AI Chat. Where offered for your account, **Pro** unlocks additional access to AI Agent, Git and GitHub workflows, multiple terminals, Android Local Linux on supported devices, language services, remote search, custom plugins, and related advanced workflows. Availability and pricing depend on the app version, platform, store, account, and region.

<PricingFeatureSystem lang="en" mode="full" />

## Why Pro

Pro exists for the moments mobile work has to end with a carefully reviewed result: a custom workflow or script job, a Git commit after checking the diff, several terminal contexts at once, configured language feedback, or an AI Agent task that needs follow-up direction. It does not remove the need to review commands, permission changes, diffs, or AI suggestions—especially on production systems.

For subscription verification, purchase restoration and access behavior, see [Account and Subscription](/docs/account-subscription).
