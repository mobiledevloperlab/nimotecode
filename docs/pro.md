# NimoteCode Pro

NimoteCode is free to start: open local or SSH projects, or use Android Local Linux on a supported device; edit files, run commands and use AI Chat on the Free plan. **Early Access Pro** adds Plugin Center and custom workspace plugins, continuous AI Agent collaboration, remote search, multi-terminal, Git writes and branch workflows, LSP, debugging, and Sync / Cache. Availability and displayed pricing vary by store, account, and region.

<PricingFeatureSystem lang="en" mode="full" />

## Why Pro

Pro exists for the moments mobile work has to end with a carefully reviewed result: a custom workflow or script job, a gated Git commit after checking the diff, several terminal contexts at once, configured LSP feedback, a debug session, or an AI Agent task that needs follow-up direction. It does not remove the need to review commands, permission changes, diffs or AI suggestions — especially on production systems.

For subscription verification, purchase restoration and access behavior, see [Account and Subscription](/docs/account-subscription).
