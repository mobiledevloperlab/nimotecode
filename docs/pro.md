## Why Pro

Pro exists for the moments mobile work has to end with a carefully reviewed result: a Git commit after checking the diff, several terminal contexts at once, configured language feedback, or an AI Agent task that needs follow-up direction. It does not remove the need to review commands, permission changes, diffs, or AI suggestions—especially on production systems.
