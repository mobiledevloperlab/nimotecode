# NimoteCode Android Local Linux third-party corresponding source

NimoteCode Android Local Linux includes third-party open-source components distributed in its Ubuntu root filesystem. Corresponding source for applicable components is published as a versioned, external source bundle.

The release-specific URL, filename and SHA-256 are in the App's `source-delivery.json` and the release `SHA256SUMS`. This bundle contains third-party corresponding source only; it does **not** contain NimoteCode proprietary application source.

Website: `LOCAL_LINUX_SOURCE_BASE_URL/<NimoteCode version>/`
GitHub (optional): release tag `local-linux-sources-v<NimoteCode version>` in `LOCAL_LINUX_SOURCE_GITHUB_REPO`.
