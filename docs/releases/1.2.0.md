## 1.2.0 · October 5, 2026

Version 1.2.0 brings the Monaco editor to desktop and tablet workspaces, improves Windows desktop support, and gives you more control over Explorer density. It also improves editing, keyboard input, selection, terminal layout, and theme consistency across device classes.

### New

- **Monaco on desktop and tablets.** NimoteCode now brings Monaco editing to Windows, macOS, Android tablets, and iPad, while phones retain the Nimote Editor. Choose the editor that best suits your workflow in Settings.
- **A more capable editor.** Files, tabs, themes, language-aware editing, diffs, clipboard actions, text selection, and document changes work together more consistently.
- **Improved Windows support.** NimoteCode is more reliable to install and launch on Windows desktops.
- **Explorer display preferences.** Adjust Explorer font size (11–20) and row height (28–48) in Settings. The current file remains visibly selected when opened from a tab, search, or another panel.

### Improved

- **A device-appropriate editor.** The editor adapts to the available window size, improving the experience in split screen, on foldables, and across tablet and desktop windows.
- **Refined editing interactions.** Selection, context actions, scrolling, code folding, line decoration, and diff highlights are more reliable on larger screens.
- **Hardware-keyboard workflow.** Save and undo/redo shortcuts are more reliable on mobile, including while using CJK input methods and external keyboards.
- **Consistent editor and terminal presentation.** Editor surfaces, dividers, search fields, typography, terminal colors, scrollbars, selection handles, and gutter decoration follow the active theme more closely.
- **Better terminal layout.** Landscape terminal commands, tabs, search controls, and content padding remain aligned, with more reliable Windows keyboard input.
- **Clearer Explorer hierarchy.** File and directory rows use stronger selected-state contrast, more consistent text sizing, and a persistent active-file highlight.

### Fixed

- Fixed tablet Monaco sessions that could not reliably receive keyboard input or use the clipboard.
- Fixed editor selection, touch handles, and context-menu interactions regressing while switching or restoring the editor presentation.
- Fixed editor keyboard configuration and text-sizing inconsistencies across mobile and external-keyboard use.
- Fixed editor and terminal theme mismatches, including dividers, search fields, and Explorer selection colors in bundled light and dark themes.
- Fixed terminal layout and input issues in landscape and on Windows.
- Fixed Windows desktop builds that could not be launched reliably.
