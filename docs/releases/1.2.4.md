## NimoteCode 1.2.4

Version 1.2.4 makes it faster to start and resume work: optional AI setup no longer interrupts first use, recent workspaces are easier to continue, and the app gains in-app update notices, clearer settings and AI configuration, and more dependable terminal search.

### New

- **In-app update notices.** NimoteCode can now present available and minimum-version updates with localized release notes, so you can finish a safe stopping point before updating.
- **Recent workspaces.** An empty workspace now lists recently opened local projects and the latest SSH workspace. Local projects reopen immediately; SSH projects return you to the saved remote connection for a secure reconnect.

### Improved

- **A shorter first-workflow path.** Choosing a local project, remote workspace, or demo now opens it directly. AI configuration remains available from its existing entry point without blocking coding.
- **Clearer workspace entry.** Local projects are the primary entry, while the demo is an exploration option. When no workspace is open, continuing recent work comes first.
- **Tools match workspace capabilities.** Search, debug, task, Git, and language-tool destinations that cannot work in the current workspace are no longer presented as dead-end actions.
- **Clearer Settings and AI configuration.** Settings grouping and subscription presentation are easier to scan, and the obsolete custom-tools area has been removed from AI configuration.
- **More dependable terminal search.** Search highlights now stay aligned with terminal scrollback content.

### Fixed

- SSH validates host, user name, and port before attempting a connection, avoiding failures caused by incomplete connection details. Connection and directory validation no longer expose raw lower-level errors.
- Store update gating avoids unnecessarily blocking versions that can continue to run.
