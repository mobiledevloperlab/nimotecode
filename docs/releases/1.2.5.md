## NimoteCode 1.2.5

Version 1.2.5 makes everyday project management more efficient: Explorer gains batch file actions plus file sizes and loaded-directory counts, while AI and SSH workflows provide more direct feedback and the IDE is more consistent across phones, tablets, and desktop.

### New

- **Batch Explorer actions.** Select multiple files or folders to copy, move, or delete them together. Local, remote, and external-storage workspaces expose the actions they support.
- **Richer Explorer details.** File lists now show file sizes, and expanded folders show how many items have been loaded, making project structure easier to scan.
- **AI quick actions.** Start a new conversation or open AI configuration directly from an empty AI chat, so the next task is only a tap away.

### Improved

- **More dependable SSH connection feedback.** Connecting immediately shows progress and prevents duplicate connection attempts.
- **A clearer, more consistent workspace.** Middle-panel titles, toolbars, dividers, typography, icon sizing, spacing, and theme contrast are unified; mobile floating navigation, Markdown document preview, and notifications are more polished too.
- **Simpler AI model switching.** The model menu and configuration-switching flow take fewer unnecessary steps.

### Fixed

- Improved coordination between modal sheets, panels, and local Git entry points so visual refinements do not interfere with local Git access.
