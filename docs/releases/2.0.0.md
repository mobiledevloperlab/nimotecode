## NimoteCode 2.0.0

2.0.0 is a major NimoteCode release. It evolves the IDE from a fixed feature set into a safely customizable workspace: build and run plugins, keep AI Agent work moving, and handle Git, terminals, and everyday editing in a smoother, more cohesive interface.

<span id="release-new"></span>

### New · 5

- **Plugin Center and custom workspaces.** Manage workspace capabilities from Feature Center, create custom plugins and declarative panels, and use forms, workflows, artifact views, and script jobs on local or SSH targets. Permission changes are shown for review before an install or update proceeds.
- **Continuous AI Agent collaboration.** Add follow-up instructions to an active Agent run and answer its interactive questions when needed. Context, history, prompt editing, and the run timeline have also been rebuilt for longer-running work.
- **Better Git branches and diffs.** Search for, create, and check out branches from the Git header. The editor marks Git changes in a quiet gutter and presents diffs with clearer syntax highlighting.
- **More direct terminal assistance.** Send terminal output straight to AI for analysis, and reach terminal-tab settings more easily.
- **Flexible remote connections.** Connect to SSH workspaces through SOCKS5 or HTTP CONNECT proxies when your network requires one.

<span id="release-improved"></span>

### Improved · 6

- **Refreshed visual and layout system.** Material 3 styling, themes, Settings, Explorer toolbar, empty states, Markdown preview, and startup motion now share a more consistent design. The default UI scale is 90% to leave more room for work.
- **A more resilient plugin runtime.** Plugin panels preserve runtime state and avoid stale updates; foreground workflows support incremental forms, durable jobs can continue on their target environment, and deleting a plugin safely cancels its jobs.
- **More efficient AI and resource use.** Long chats fold by conversation round and expand history on demand. Hidden panels pause unnecessary refreshes, while editor and chat-history memory use is bounded.
- **More natural mobile workflows.** Android's AI entry now uses a Dynamic Island-style control, while account, subscription, appearance, and shared input surfaces adapt more cohesively across screen sizes.
- **One editor across every device.** Nimote Editor is now the default on phones, tablets, and desktop. It provides consistent text selection, keyboard and IME behavior, undo, paste, find and replace, and caret handling across form factors.
- **Terminal colors that match your workspace.** Choose configurable terminal color palettes; the terminal and mobile system chrome now stay visually aligned with the active theme.

<span id="release-fixed"></span>

### Fixed · 5

- Addressed edge cases in plugin metadata compatibility, permission updates, panel scrolling, and job cancellation.
- Corrected placement of AI follow-ups in the run timeline, vertical alignment in shared inputs, and Explorer-toolbar layout.
- Strengthened reliability and security boundaries in the built-in Agent runtime and workspace tools.
- Fixed focus, selection, line-editing, and asynchronous-session edge cases in the editor and terminal, especially when using mobile keyboards or reconnecting a session.
- Improved long-running Agent tasks with clearer compact output and the option to continue when a configured step budget is reached.
