## NimoteCode 2.1.0

2.1.0 combines workspace improvements across devices with a more efficient, dependable built-in Agent for large codebases, especially files with very long or minified lines.

<span id="release-improved"></span>

### Improved · 5

- **More efficient code search.** The Agent bounds search-result context and builds only the text it needs to show, reducing memory use and wait time when searching large or minified files.
- **More dependable file summaries.** When summarizing a file, the Agent keeps the most relevant code excerpts with less work on long files, while preserving consistent results.
- **A unified workspace across devices.** Choose appearance mode independently from the accent color, with more consistent workspace layout, controls, and typography on phone, tablet, and desktop.
- **A smoother landscape and editing experience.** Workspace pages and Git history can open as editor tabs in landscape, editor headers remain after fullscreen terminal, and editor rendering, highlighting, and Git diff typography are improved.
- **More direct search and mobile controls.** File search opens directly, remote connection status appears beside its directory, and mobile Agent and terminal drag, keyboard-selection, and copying controls are smoother.
