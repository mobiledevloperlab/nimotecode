## NimoteCode 2.2.0

2.2.0 brings GitHub workflows into NimoteCode. Sign in, browse repositories, and open projects from a dedicated GitHub page, then work with branches, issues, pull requests, and CI from the workspace you already know. This release also adds experimental development toolkits for Android Local Linux, strengthens search reliability, and unifies panels and conversations throughout the app.

<span id="release-new"></span>

### New · 3

- **Native GitHub development workflows.** Sign in with browser device authorization or a token, browse your repositories, branches, and repository details, then clone and open projects in local or SSH workspaces.
- **Issue, pull-request, and CI collaboration.** Browse and filter issues, pull requests, reviews, and checks. Start an Agent task with issue context, then create branches, push changes, fork, and open pull requests when your work is ready.
- **Android Local Linux toolkits (experimental).** Install command-line essentials, Python, and Web tools on demand. Create, run, and open example projects without reinstalling Linux or overwriting existing projects. Initial installation requires internet access.

<span id="release-improved"></span>

### Improved · 5

- **More dependable GitHub operations.** Sign-in, project cloning, and Local Linux workspace operations are more reliable, with clearer steps to recover failed pushes and publication.
- **More robust workspace search.** Search results, highlighting, and mobile interactions are more reliable. Code search in Android Local Linux works without additional setup.
- **A more consistent workbench.** Settings, Source Control, GitHub, Search, and other panels now share clearer surfaces, typography, controls, and narrow-layout behavior. Conversation and overview layouts are easier to scan too.
- **Clearer toolkit states.** See download and storage estimates before installation, then focus on examples and tool checks once ready. Task logs, retry, and interruption feedback help with recovery; leaving the page does not cancel a task. Typography, spacing, buttons, and confirmation dialogs now match the workbench.
- **Consistent copy feedback.** Copying from common panels now gives clear, consistent feedback.

<span id="release-fixed"></span>

### Fixed · 2

- Addressed transient GitHub API failures, mobile HTTPS cloning, cancellation, and clone-target recovery, while keeping credentials out of Git operations that should not use them.
- Improved remote workspace search results and highlighting to reduce stalls and display problems with large results and mobile interaction.
