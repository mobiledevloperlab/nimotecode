## NimoteCode 2.3.0

2.3.0 makes the workspace fit the task: switch between IDE, Terminal, and AI while keeping the project and Explorer state. It also upgrades plugins, Windows SSH workspaces, Agent collaboration, terminal controls, mobile Git review, and Docker development on SSH hosts.

<span id="release-new"></span>

### New · 6

- Switch between IDE, Terminal, and AI modes while keeping the same project and Explorer state.
- Plugins can declare versioned contributions and dependencies, receive validation before installation, and provide approved tools, skills, and workflows to the embedded Agent. Workspace events can trigger controlled automation.
- Browse Windows remote workspaces over PowerShell and SFTP, with search, Git, terminal, language services, and Agent workflows.
- Supported ACP Agents can receive follow-up instructions while a task is running.
- Manage containers, images, volumes, networks, and Compose projects on SSH hosts; inspect details, logs, statistics, use exec, search Docker Hub, and control individual Compose services.
- Create or rebuild Dev Containers from a project devcontainer.json and open an isolated workspace with its configured environment.

<span id="release-improved"></span>

### Improved

- Adaptive terminal panes, terminal-to-editor navigation and AI analysis, command history, saved display preferences, zoom, and per-connection prompts. Mobile Git review, Windows SSH reliability, Agent diagnostics, Docker recovery, and consistent live Pro/trial/Early Access access were improved.
