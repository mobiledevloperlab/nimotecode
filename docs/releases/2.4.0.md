# NimoteCode 2.4.0 · Host workspace, project tasks, and remote reliability





[← All releases](/releases/)

2.4.0 introduces the Host workspace for managing remote sessions and Agent tasks over SSH, alongside improvements to the terminal, editor, and workbench across devices.

<span id="release-new"></span>

### New

- **Host workspace and sessions.** Install and start a compatible NimoteHost on the remote machine, then connect over SSH to browse and resume remote terminal and Agent sessions, inspect history, output, and lifecycle events, and search, filter, pin, and organize sessions. Host is optional; existing SSH workflows remain available.
- **Host Agent collaboration.** Compatible Codex, Claude, and OpenCode sessions offer structured conversations, tool details, approvals, commands, and model selection. Supported sessions accept follow-up instructions while running. Execution policies depend on Host capabilities, and sensitive actions may still require approval.
- **Task inbox and GitHub Issue workflows.** On a compatible Host, review task status, approvals, verification results, and diffs, then continue or archive tasks. Dispatch GitHub Issues to an Agent and handle publication according to the selected policy. Some capabilities depend on the Host version and configuration.
- **Host plugins and project tasks.** Access compatible Host-provided plugins and interfaces from the sidebar; plugins can provide versioned forms, paginated tables, details, and interactive views with permission checks.
- **Project task runner.** Discover supported tasks from package.json, Taskfile, Makefile, justfile, and .vscode/tasks.json and run them in workspace terminals. Make/just discovery requires explicit confirmation; unsupported configurations are explained.
- **Agent alerts and editor settings.** Configure completion, confirmation, and failure alerts across IDE, AI, and Host, including sound and vibration subject to device and system settings, and set editor line numbers and the landscape minimap. Pro is enabled by default on Windows.

<span id="release-improved"></span>

### Improved

- **Sessions and workbench.** Unified session history and environment entry points make SSH connections easier to choose. Navigation, panels, menus, themes, and portrait and landscape layouts are more consistent on phones, tablets, and Windows.
- **Application configuration and accessibility.** Manage core features, panels, and plugins from a unified configuration entry; Agent alerts now live under Agent configuration. Improved landscape workbench colors and tablet title bars, with support for the system reduced-motion preference.
- **GitHub CI monitoring.** Filter runs by branch and workflow, inspect step logs and error context, and see when downloaded logs are incomplete.
- **Terminal experience.** Improved responsiveness and rendering under heavy output, synchronized updates, search highlights, scrolling, software keyboard handling, and held navigation keys. Vim, interactive programs, clipboard access, and Windows paste are more reliable.
- **Editing and Git review.** Improved large-file editing performance, remote saving, and error messages. Git diffs wrap long lines, with change navigation in the footer.
- **Host history and recovery.** Improved reconnection, history loading, task links, and activity status; loaded history is retained if refresh fails. Unified history reduces duplicate records and allows offline deletion of local history entries.

<span id="release-fixed"></span>

### Fixed

- Strengthened SSH host key verification and concurrent known_hosts access on Windows, and improved Windows compatibility with modern macOS SSH servers.
- Fixed editor clipboard and save actions targeting the wrong tab, and improved remote file operations and recovery from write failures.
- Fixed terminal scrolling, Unicode, input method, search, and session reset issues, and improved panel and terminal resizing.
- Updated ACP Agent release and model discovery, with improved startup and command discovery.
- Fixed Agent output duplication or ordering, automatic approval, and session history edge cases, and better protected unsaved edits.
