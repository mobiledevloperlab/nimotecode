# NimoteCode 2.4.1 · Host workspace and file transfers

November 19, 2026 · Build 66

<LatestReleaseLink />

[← All releases](/releases/)

2.4.1 redesigns the interface, improves tablet layouts, and adds a Host workspace for remote terminal and Agent sessions. It also adds workspace file transfers and project task discovery, with improvements to GitHub CI, terminal history search, and remote saves.

<span id="release-new"></span>

### New

- **Host workspace**: Remotely install and start a compatible NimoteHost, then connect over SSH to browse and resume remote terminal and Agent sessions.
- **Host Agent sessions**: Use structured conversations, approvals, commands, and model controls in supported sessions.
- **Host task inbox**: Review tasks, verification results, and diffs, or dispatch GitHub Issues to an Agent. Available functions depend on Host capabilities and configuration.
- **Host plugins**: Access compatible Host plugins and connect project tasks with workspace terminals.
- **File and folder transfers**: Transfer files and folders between the device and SSH workspaces, or import and export them locally.
- **Project task discovery**: Discover supported tasks from npm, Taskfile, Makefile, justfile, and VS Code task definitions.

<span id="release-improved"></span>

### Improved

- **Interface and tablet support**: Redesigned workbench with improved landscape and tablet layouts, editor controls, and mobile Git review. Explorer displays Git status colors.
- **Workspace modes and plugins**: Switch between IDE, Terminal, and AI while retaining the project and Explorer state. Improved plugins, supported Agent follow-up instructions, and Windows SSH workspaces.
- **Terminal workflows**: Improved responsiveness, search, scrolling, clipboard access, and interactive programs. Search retained terminal history, with improved wide-character selection and mouse input.
- **Terminal and workspace tools**: Open file locations from terminal output, send selected output to AI, and review supported command records. Use adaptive split panes, manage Docker and Compose over SSH, and create Dev Containers.
- **GitHub CI**: Filter workflow runs and inspect step logs and error context.
- **Configuration and accessibility**: Unified application configuration entry, with improved reduced-motion support. Configure Agent sound and vibration, editor line numbers, and the landscape minimap.
- **SSH and remote saves**: Improved SSH host verification and remote-save reliability, including saves to Windows hosts.

<span id="release-fixed"></span>

### Fixes

- Fixed various bugs.

Host functions require a compatible NimoteHost. Agent and plugin availability depends on Host capabilities and configuration.
