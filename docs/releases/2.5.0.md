# NimoteCode 2.5.0 · Paired SSH, persistent terminals, and NimoteHost setup

Upcoming · Build 68

[Current release · 2.4.1](/releases/2.4.1) · [← Release archive](/releases/)

### Remote connections and Host

- **Paired computers and personal Tailscale.** Choose a paired computer in the connection picker and use its synced Tailscale IP or MagicDNS name with your existing SSH password or key. Manual SSH and available local environments remain in the picker. You can unpair a device from NimoteCode.
- Nimote Connect public internet access is planned. Free and Pro allowances have yet to be defined. Standard SSH and personal Tailscale are available.
- **More resilient SSH.** Improved connection setup and recovery on slow or unstable networks, terminal input and output, window size updates, and SFTP reads. Android also improves compatibility with SSH key files.
- **Install, start, and update NimoteHost over SSH.** Check installation status and version in the Host panel, then confirm an installation or update using the release offered by the Host panel. Dismiss the notice and reopen it from the Host header. Download or setup failures show a reason and a retry option. If an update needs to stop sessions, the app asks first.
- **Paired-device trust and recovery.** Relay shows authorization, computer confirmation, tunnel setup and SSH sign-in separately. Removing the pairing revokes Relay access. With compatible Host services, verified routes for the same paired computer can reopen the same Host workspace.

### Terminal

- **Persistent SSH terminals.** Pro users can create or resume a persistent session from the terminal menu on compatible SSH hosts with tmux installed. Closing the local tab leaves remote tasks running. You can also end the remote session from the menu.
- Improved tmux history scrolling, initial drawing, and cursor placement. Terminal connections, search, and session actions are easier to find. Landscape keyboard and shortcut handling improved, and advanced search waits for Chinese input composition to finish.
- Improved double-click and double-tap word selection, wide-character selection, and selection contrast. In programs that capture the mouse, such as Codex and Claude Code, Shift-drag and use the right-click menu to copy. The selection is available after the program redraws.
- **Terminal workflow details.** Reopen an existing tmux session from session history or the remote list, including from another client signed in as the same SSH user. On phones in landscape, terminal shortcut keys such as Esc and Ctrl are shown when the on-screen keyboard is open and there is room. Terminal menus remain usable while status messages are displayed.

### Workbench, editor, and Git

- The portrait phone workbench has a floating navigation bar and more consistent IDE and Host headers and connection controls. The single-pane IDE opens to an empty editor with a file browsing action. Recent projects and connection choices are easier to find.
- Workspace search opens and highlights matches in the editor. SSH workspace search and large directory expansion are more responsive. Dragging the editor scrollbar preserves the text selection, and opening a tab at the limit preserves the visible tab in the other split.
- Open Git file history directly from the editor. History follows renamed files and is easier to retry after an error. Git changes load on demand in large repositories.
- Improved selection contrast in the editor and AI panel. Fixed lost selections when opening the copy menu, stale paths from the remote folder picker, and task fields accepting edits during save or deletion.
- **Git history and Agent review.** File and line history distinguish an empty history from a load failure, offer retry, and handle remote directory aliases. Agent review cards explain missing recorded snapshots and link to the current Git diff.

### AI and platforms

- Improved built-in Codex response times, cancellation, and tool calls, along with Agent search and file operations in large repositories. Restoring interrupted Agent history preserves canceled turns, and AI history search waits for results before showing an empty state.
- Android Local Linux supports development toolkits defined by manifests, which community contributors can also use. iOS updates app startup and lifecycle handling. Desktop email sign-in is more reliable, and desktop access follows the signed-in account.
- Free includes Git status, diffs, staging, unstaging and commits. Graphical push, pull, branch and stash operations, Git AI and advanced GitHub integration require Pro. Docker and Dev Containers require Pro and a compatible host. Debug sessions require Pro and a configured debug adapter.
- **Workbench and compatibility.** The workspace menu provides GitHub and demo entry points. The AI composer has a larger tap target and the empty conversation scrolls on short screens. Task and plugin execution guidance now reflects the terminal targets available on the current platform. Android Local Linux remains an Android capability.
