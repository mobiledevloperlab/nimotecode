## The focused mobile loop

1. Open a local project or connect to the intended SSH host and project root.
2. Inspect the relevant file, then make a targeted edit in the editor.
3. Use Terminal to check logs, run a test or verify the changed behavior.
4. Review the resulting diff in Source Control before a commit or delivery step.

The workflow is designed for real, bounded work away from a desk—not as a replacement for the review, access controls and validation your project requires.
