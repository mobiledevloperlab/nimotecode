# 账户与数据删除

<p class="trust-meta">最后更新：2026-11-05 · NimoteCode</p>

你可以在应用内删除账户；无法登录或已卸载应用时，也可从本页直接联系支持发起请求，无需重新安装。

<div class="trust-summary">

**删除账户不会自动取消 Apple / Google 订阅。** 不希望续费时，请独立取消订阅。无需等待订阅到期才能申请删除。

[Apple 订阅管理](https://apps.apple.com/account/subscriptions) · [Google Play 订阅管理](https://play.google.com/store/account/subscriptions)

</div>

## 应用内删除 {#in-app}

1. 打开 NimoteCode **设置 → 删除账号**。
2. 阅读确认说明并输入 `DELETE`。
3. 如提示身份校验，重新登录或完成相应认证，然后确认删除。

成功完成后会删除认证账户和主用户记录，并解除后端订阅所有权关联。若发生错误或未出现成功提示，请联系支持核查结果。

## 网页发起请求 {#request}

<a class="trust-action" href="mailto:support@nimotecode.com?subject=NimoteCode%20account%20and%20data%20deletion">发送账户与数据删除请求 →</a>

邮箱：[support@nimotecode.com](mailto:support@nimotecode.com)。没有默认邮件客户端时，可复制地址并从自己的邮箱发送。点击按钮只会打开邮件草稿，**需要发送邮件才算提交**。

请说明请求删除 NimoteCode 账户及关联个人数据，并提供账户邮箱（如有）、登录方式、平台（iOS / Android）。Apple 隐藏邮箱用户可提供对应转发邮箱。无法识别账户或使用访客功能时，请说明情况，我们会协助确定必要的核验方式。

我们可能通过原账户登录方式或邮箱核验身份。不要发送密码、一次性验证码、私钥或完整支付资料；不要使用公开 GitHub Issues 提交删除请求。

## 删除范围与例外 {#scope}

| 数据 | 删除账户后的处理 |
| --- | --- |
| Firebase 登录账户及主用户记录 | 账户删除成功时移除。 |
| 后端订阅所有权 | 解除与账户的当前所有权关联；交易、防重复认领及删除关联记录可能保留，包括原用户标识。 |
| 设备试用记录 | 用于防止重复试用的哈希和使用记录可能保留；删除账户不会重置试用资格。 |
| RevenueCat、统计和支持资料 | 不应视为随账户自动全部删除；请求中可以明确要求处理这些关联数据，保留例外按适用义务及必要用途处理。 |
| 本地历史、报告、凭据、工作区、远程文件和外部 Agent 记录 | 不因删除 NimoteCode 账户自动清除，请分别在应用、设备、服务器或对应服务中管理。 |
| 商店账户、订阅和你自行选择的 AI / GitHub 等账户 | 不会一并删除或取消；由相应服务管理。 |

应用中可关闭 AI 历史自动保存并删除既有历史、清理报告、移除 AI 配置或已保存的 SSH 连接。移除设备上的令牌不等于在第三方撤销令牌；必要时请到相应提供商撤销。

## 处理进度 {#timing}

应用内自动流程完成时显示结果。邮件请求通常在 2–3 个工作日首次回复；身份核验后会告知处理范围、预计完成时间和完成结果。额外的数据处理可能需要更多时间，适用法定期限优先。需要保留部分记录时，会说明相关范围、理由及适用的保留安排。

你也可以仅申请删除特定个人数据而保留账户，请在邮件中明确范围。进一步说明见[隐私政策](/zh/privacy#retention)，其他问题见[支持中心](/zh/support)。
