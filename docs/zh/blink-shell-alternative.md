# 面向移动编程工作流的 Blink Shell 替代品

Shell 访问是在移动端工作的强大方式。但当工作涉及一个仓库时，命令行只是闭环的一部分。你需要检查项目树、做一处改动、查看输出，并在它变成别人依赖的改动之前审查结果。

NimoteCode 是当你想让这一切发生在同一个移动开发工作区时值得考虑的替代品：**Editor + Explorer + SSH + Terminal + Git + AI Chat 与 Agent**。

## 终端优先访问，工作区优先交付

NimoteCode 保留了终端，让你能运行已习惯的命令，同时让周边任务更容易完成：

- 浏览远程项目文件，而不是只依赖路径与 shell 命令。
- 在与当前任务相邻的标签页中编辑源码与配置文件。
- 追踪问题时，搜索项目内容与终端输出。
- 提交或推送前检查 Git diff、历史与分支。
- 用带工作区感知的 AI 辅助完成解释、规划与受控多步骤工作。

结果对移动端值班、快速配置修正、CI 告警后的审查或一次小规模远程修复很有用。完整流程见[移动端远程热修](/zh/use-cases/remote-hotfix)。

## 按你要完成的工作来选择

如果高品质终端就是全部要求，那么选择适合你平台与习惯的终端体验即可。如果真实需求是从同一台设备完成一个编码任务，就去评估一个代码、SSH、终端与 Git 已经连接好的工作区——这正是 NimoteCode 设计要帮你的地方。

Blink Shell 是其各自权利人的商标。本页与 Blink Shell 无关联，也不断言功能对等。
