# 账户与订阅

## 查看账户状态

打开 **Settings** 登录并查看账户与订阅区域。页面显示的权益决定 Pro 功能的访问权限。可用权益与购买选项取决于商店、账户、地区和发布渠道。

## 恢复购买

已购买但未识别权益时，确认平台商店账户并选择 **Restore Purchase**。检查恢复后的权益状态，再重试对应功能。账户问题可联系[支持](/zh/support)。

## 功能权益

Pro 功能包括 AI Agent、插件工作流、Git 写入、远程搜索、多终端、LSP、调试和 Sync / Cache。模型调用费用由你的 Provider 另行结算。功能对比见[免费版与 Pro](/zh/pro)。
