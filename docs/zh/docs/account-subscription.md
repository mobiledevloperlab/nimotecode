# 账户与订阅

## 查看账户状态

打开 **Settings** 登录并查看账户与订阅区域。页面显示的权益决定 Pro 功能的访问权限。可用权益与购买选项取决于商店、账户、地区和发布渠道。

**免费试用 Pro 14 天** — 在应用内领取 14 天免费试用。到期后，如无付费订阅或 Early Access 等其他有效 Pro 权益，将自动回退到免费版，免费功能可继续使用。试用资格以应用内显示为准。

## 恢复购买

已购买但未识别权益时，确认平台商店账户并选择 **Restore Purchase**。检查恢复后的权益状态，再重试对应功能。账户问题可联系[支持](/zh/support)。

## 功能权益

在 2.5.0 中，Free 用户可以浏览 GitHub、通过受支持的 SSH 连接查看 Docker 版本和容器及镜像概览，并管理断点。GitHub 克隆或写入、管理 Docker 资源和启动调试均需 Pro。相关操作会显示权限标识。

在 NimoteCode 2.5.0 中，创建或恢复 [SSH 持久终端](/zh/docs/terminal#persistent-ssh-terminal) 需要 Pro，以及安装了 tmux 的兼容主机。原生桌面版本默认启用 Pro。

手机和平板通过 Nimote Connect 使用托管直连或 Nimote 中继需要 Pro。普通 SSH、个人 Tailscale 和桌面正式版的 Nimote Connect 免费。

功能对比见[免费版与 Pro](/zh/pro)。

AI 模型采用 BYOK（自备 API Key）方式。需配置自己的模型服务商与 API Key，模型调用费用由服务商另行收取；NimoteCode 不包含模型额度。
