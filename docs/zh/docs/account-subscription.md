# 账户与订阅

NimoteCode 使用账户与订阅状态验证 **Pro** 权益。新用户可通过按设备计算的 14 天试用体验受限工作流。具体购买与恢复入口取决于平台商店和当前发布渠道。

## 登录的用途

- 将已验证的 Pro 权益关联到你的账户。
- 通过支持的平台商店流程恢复符合条件的购买。
- 验证试用与 Pro 受限工作流的访问权限。

## Pro 解锁能力

Pro 提供 Git 写入、进阶多终端、AI Agent、远程搜索、LSP、Debug 与 Sync / Cache。功能会在实际操作点检查，因此每项需要权益的动作都清晰可见。

如果权益显示异常，请确认登录账户、在应用中刷新订阅状态，并在适用时使用恢复购买。临时网络中断时，近期已验证的权益可能会短暂保持可用。

完整对比见 [NimoteCode Pro](/zh/pro)。
