# Nimote Connect 安装包兼容性

请选择开发电脑的系统和 CPU 架构。macOS 和 Linux 支持 App 内引导安装，Windows 请直接在电脑上安装。1.2.0 为以下六种目标提供 CLI 包。只有发布页列出目标电脑对应 GUI 包时，才可选择图形界面。

| 开发电脑目标 | CLI 压缩包 |
| --- | --- |
| `darwin-amd64` | `.tar.gz` |
| `darwin-arm64` | `.tar.gz` |
| `linux-amd64` | `.tar.gz` |
| `linux-arm64` | `.tar.gz` |
| `windows-amd64` | `.zip` |
| `windows-arm64` | `.zip` |
