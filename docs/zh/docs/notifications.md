# 通知

通知会在设备上提示已完成或需要关注的工作区活动。把通知当作回到相关工作区的提醒；在继续操作前，仍应确认当前主机、目录和结果。

<ImagePlaceholder image-key="notifications" alt="NimoteCode 手机上的通知">
  <strong>工作区通知</strong>
</ImagePlaceholder>

## 安全地处理通知

1. 打开相关工作区，不要假定通知仍反映远程环境的当前状态。
2. 检查当前主机和项目目录。
3. 在上下文中阅读终端、任务或 Agent 的结果。
4. 应用前审查每一条建议命令和文件改动。

日常使用时，让 [Tasks](/zh/docs/tasks) 和 [终端](/zh/docs/terminal) 的名称保持明确，通知才能在小屏幕上被快速理解。
