# 自定义插件

自定义插件可将重复的项目工作流做成 NimoteCode 内可复用的小工具。插件可以组合工作区数据、表单、原生面板快捷入口和经批准的操作。它扩展已有的编辑器、终端、Git、Tasks、语言服务和 Agent 工作流，并不会在设备上加载不受限制的可执行扩展。

## 插件可以包含什么

| 组件 | 用途 |
| --- | --- |
| **面板与表单** | 展示项目数据，并收集操作所需输入。 |
| **工作区数据** | 使用可用的工作区、Git、LSP、Tasks、终端或 Agent 上下文。 |
| **原生快捷入口** | 打开内置编辑器、AI、终端、Tasks 或源代码管理面板。 |
| **需确认的操作** | 读取或写入工作区文件、发送 HTTP 请求、运行既有任务、执行终端命令或 Python、JavaScript、Shell 脚本。 |
| **Agent 工具或 Markdown Skill** | 向内置 Agent 暴露符合条件的插件能力，或提供按需使用的说明。 |
| **工作流或事件处理器** | 在 IDE 保持活动时，组合读写操作、传递步骤结果、设置条件、循环和明确重试。 |
| **MCP 引用** | 在工作流需要时引用已配置的 MCP 集成。 |

数据始终属于当前工作区。切换工作区不会复用上一个工作区的上下文。打开文件的快捷操作需要稳定的原生文件路径，因此在文档提供器工作区中不可用。

## 创建和测试插件

先在[AI 配置](/zh/docs/configuration)中完成模型设置，再打开插件要使用的工作区。

1. 打开 **AI custom plugins**，选择 **Create plugin**。
2. 描述所需结果和输入。例如：“显示当前分支、变更文件和 LSP 错误数量，并提供源代码管理入口。”
3. 在同一对话中继续调整标签、字段、数据和操作。
4. 预览结果。预览只验证面板，不会执行文件写入、网络请求、命令或脚本。
5. 在可用时选择 **Test plugin**，检查解析后的输入和权限；确认无误后再保存和安装。

## 权限和执行方式

插件调用的是已注册能力，而非可执行应用扩展。安装、更新和执行操作前，都应检查插件请求的内容。

- 文件读写限定在已打开的工作区；写入前会显示目标路径和内容以供确认。
- HTTP 请求、终端命令、既有任务、打开文件和脚本均须在调用时确认。
- Python、JavaScript 和 Shell 脚本仅在已连接的 SSH 或 Android Local Linux 目标上运行，使用已安装的 `python3`、`node` 或 Shell，并继承该账户权限。
- 插件不会下载运行时、安装依赖，或授予目标账户原本没有的权限。
- 由插件绑定的参数不能被 Agent 调用静默替换。

应像审查来自不可信来源的命令一样审查插件命令或脚本：阅读内容、确认目标与输入，并检查结果。不要将密钥放入自动生成的默认值或插件描述中。

## 安装、更新、停用和恢复

打开 Plugin Center 可查看插件详情、能力和权限，选择 **Open plugin** 可打开面板。**Discover** 用于开始新的 AI 辅助创建流程，**My Plugins** 则列出本地管理的插件。

插件定义和表单配置会分别保留，便于修改面板而无需重新创建全部内容。保存前请预览修订版，更新时检查权限变化，并按需要启用或停用插件。可以恢复最近的版本；如果一个已启用插件依赖另一个插件，应先停用依赖方再移除被依赖项。

内置 Agent 可通过应用的 MCP 集成发现符合条件的插件能力，并在时间线记录工具结果。外部 ACP Agent 保持自身行为，未必支持同样的集成。

## 后台任务与定时运行（Android）

Android 支持在 SSH 和 Android Local Linux 目标上运行可恢复的插件后台工作流。iPhone 与 iPad 支持前台插件操作，但不提供这些后台工作流和定时任务。

后台任务要求目标持续可用，并提供 Python 3.9 或以上版本及 SQLite。部署前请检查确切的计划、输入、重试和运行计划。任务可以立即运行一次或按不重叠的间隔执行；断连后不会补跑每一个错过的间隔。

通过 **Background jobs & schedules** 查看输出、刷新状态、暂停、恢复或取消任务。只要目标持续运行，任务可在应用断开后继续；目标重启或工作进程中断后，可能需要重新连接并恢复。如果外部副作用（如写入、部署或网络调用）期间发生中断，请检查结果并明确选择重试或跳过；系统不承诺“恰好一次”投递。

后台任务会保留已批准的定义。更新、停用或卸载插件不会静默替换已部署的任务；部署替代任务前应先停止旧任务。后台执行不会保留表单中的密钥字段，无人值守场景请使用安全配置的目标端凭据。

面板跳转、LSP 操作和原生配置的 Tasks 仍属于前台操作。向生产工作区授予插件访问权限前，请阅读[安全说明](/zh/docs/security)。

## 带版本的贡献与 Agent 工作流

插件可声明带版本的贡献和依赖，NimoteCode 会在安装前校验，并供你审查权限变化。经批准的插件工具、技能和工作流可提供给内嵌 Agent；工作区事件也可启动受控自动化流程。
