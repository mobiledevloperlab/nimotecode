# 工作区搜索

<div class="doc-section">
<div class="doc-section__copy">

## 搜索文件内容

在 SSH 工作区打开 Search，在 **Search file content** 中输入文本。需要精确区分大小写时启用对应选项，也可开启正则表达式进行模式匹配。点击结果可在命中行打开文件。远程内容搜索需要 Pro 权益。

## 没有搜索结果时

先确认当前工作区，并使用简短的普通文本进行测试。扩大查询范围前，检查大小写选项与正则表达式语法。
