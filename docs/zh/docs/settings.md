设置用于让工作区适配真正使用它的设备。优先调整阅读与输入，再在需要使用 Pro 功能前确认账户与订阅状态。

## 推荐的首次设置

1. 选择不需要反复缩放也能清楚阅读代码的主题和字号。
2. 只启用真正帮助当前语言和 Shell 工作流的键盘控制。
3. 在时间敏感的 Pro 工作流之前确认账户和订阅状态。
4. AI 和 SSH 连接信息建议在平稳时通过 [配置指南](/zh/docs/configuration) 提前准备。

隐私、条款与账户请求入口请以应用内设置或网站页脚为准。
