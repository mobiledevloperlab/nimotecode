# 设置

## 外观与语言

打开 **Settings** 可调整应用主题、编辑器配色、界面缩放和语言。**Follow app** 使编辑器配色跟随应用主题。账户与购买管理也位于此处；下列截图展示的账户状态不同。

## 面板与编辑器偏好 {#panel-and-editor-preferences}

**Plugins** 设置页可控制 LSP、Debug、Sync / Cache 和 Tasks 面板的显示，并提供自动换行、编辑器字号、行高和字体设置。启用面板不会自动安装语言服务、调试适配器或其他运行依赖。
