## 安装后的前五分钟

1. 打开本地项目、创建 Remote Explorer SSH 配置，或在受支持的 Android 设备上安装 Local Linux。
2. 打开一个文件，做一处小修改并保存。
3. 运行 `pwd`、`ls` 或项目测试命令，验证工作区。
4. 只有需要 AI Chat 或 AI Agent 时，再配置 AI Provider。
