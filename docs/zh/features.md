<details>
<summary>2.5.0 新功能</summary>

在 NimoteCode 2.5.0 中，可[通过个人 Tailscale 连接已配对电脑](/zh/docs/ssh#paired-computers)、[用 tmux 恢复 SSH 终端](/zh/docs/terminal#persistent-ssh-terminal)，也可[通过 SSH 安装 NimoteHost](/zh/docs/host/getting-started#install-over-ssh)。

[2.5.0 新功能](/zh/releases/2.5.0)

</details>

<details>
<summary>搜索、语言服务与调试</summary>

- [项目搜索](/zh/docs/search)：搜索 SSH 工作区中的文件内容，支持区分大小写和正则表达式。
- [语言服务](/zh/docs/lsp)：在工作区目标安装并配置兼容的语言服务器后，提供代码诊断、符号导航和代码操作。
- [调试](/zh/docs/debug)：连接已配置的调试适配器，设置断点，查看调用栈、变量和监视表达式。

</details>

<details>
<summary>GitHub、任务与插件</summary>

- [GitHub](/zh/docs/source-control)：将仓库克隆到设备、Local Linux 或 SSH 主机；根据账户权限处理 Issue、拉取请求、评审、检查和工作流运行。
- [任务](/zh/docs/tasks)：保存命名命令，在 SSH 或 Local Linux 的项目目录中执行。
- [插件](/zh/docs/plugins)：创建包含表单、工作区数据、文件操作、HTTP 请求和脚本的面板。文件、网络与执行类操作需用户确认。

</details>

<details>
<summary>模型服务与外部工具</summary>

- [模型配置](/zh/docs/configuration)：自行设置服务商、模型和凭据。服务商账户及模型用量费用与 NimoteCode 分开计算。
- [外部 ACP Agent](/zh/docs/ai)：在受支持的环境中运行独立配置的兼容 Agent。凭据、工具权限和执行策略由该运行时管理。
- [MCP 服务器](/zh/docs/ai)：通过 stdio 或 Streamable HTTP 接入工具。启动 stdio 服务器和调用 MCP 工具均需批准。

</details>

<details>
<summary>功能权限</summary>

应用会显示当前账户与平台对应的功能权限。Git 写操作、多终端、Agent 执行、Docker、LSP 和调试等功能，按适用的 Pro、试用或 Early Access 权益开放。

查看[账户与订阅](/zh/docs/account-subscription)了解权益和恢复方式，或查看 [Early Access](/zh/pro) 当前说明。

</details>
