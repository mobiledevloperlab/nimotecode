# 隐私政策

<p class="trust-meta">原始生效日期：2026-04-16 · 最后更新：2026-11-05</p>

本政策适用于 NimoteCode 应用、官方网站及官方支持渠道。隐私联系邮箱：[support@nimotecode.com](mailto:support@nimotecode.com)。

## 我们处理哪些数据 {#data}

| 场景 | 数据与用途 | 存储或接收方 |
| --- | --- | --- |
| 账户与登录 | 用户 ID、邮箱、登录提供商资料；用于认证和账户管理。Apple 登录可能使用隐藏邮箱，部分功能也使用访客身份。 | Firebase Authentication；账户及权益状态由 Firebase 云端服务处理。 |
| Pro、购买与试用 | 交易和权益状态、商店、到期时间、试用记录；用于验证访问权限和防止重复试用。 | RevenueCat、Apple / Google 商店与 Firebase 后端；支付信息由商店处理。 |
| 设备试用识别 | 平台设备标识、Firebase 安装标识或生成的替代标识，经哈希后用于试用校验；哈希不意味着匿名。 | 原始标识在设备处理；校验哈希及试用记录发送至后端。 |
| 工作区与凭据 | 主机、端口、用户名、路径、偏好，以及你保存的密码、私钥、口令、代理凭据和 API Key。 | 连接元数据在设备；应用管理的敏感凭据使用系统安全存储。连接时由所选服务处理所需认证信息。 |
| AI、工具与代码服务 | 提示词、选定内容、相关代码、文件路径、工具输入输出及模型回复；用于完成你发起或授权的任务。 | 所选 AI Provider、GitHub、MCP 服务或外部 Agent 及其配置的服务。 |
| 使用统计 | 会话、功能使用、平台、版本、地区设置、用户类型、工作区路径及操作元数据；登录后可关联用户 ID。 | Firebase Analytics；发送前可能在设备排队保存。 |
| 支持与问题报告 | 你提交的邮箱、问题说明、脱敏附件；AI 报告可包含回复片段、原因、模型和环境信息。 | 本地报告存储；你发送邮件后由支持邮箱及邮件服务处理。公开 Issues 由 GitHub 处理。 |

## 数据用途与运行诊断 {#purposes}

连接信息还包括认证方式和工作区根路径；应用偏好包括主题、语言、编辑器与键盘设置。AI 配置包括 Provider 类型、base URL、模型名称及你提供的 API Key。SSH 密码用于验证你发起的连接，普通连接配置与安全存储中的密码分别保存。当前 AI 配置保存流程也将 API Key 与普通应用偏好分开保存。

这些信息用于用户认证和账户安全，提供工作区、编辑器、终端、Source Control、AI 与 Tasks 等功能，验证订阅与试用资格，以及保障稳定性、安全和支持服务。

应用可能生成用于排障、稳定性和安全的运行日志。当前发布版本的通用日志组件会抑制 debug 级别消息，但这不代表其他日志或错误信息全部匿名化或已移除所有敏感内容。诊断日志与上文的 Firebase 使用统计是不同的数据类别；主动提供日志或截图前，请检查并移除凭据和私人项目内容。

## 凭据、对话和工作区 {#storage}

应用保存的 SSH 密码、私钥、私钥口令、代理认证信息、AI API Key、GitHub 令牌和 MCP 配置使用平台安全存储（iOS Keychain、Android Keystore 支撑的加密存储）。普通连接配置保留连接元数据，不应理解为“应用完全不存储 SSH 凭据”。删除已保存的 SSH 配置会删除该配置对应的安全存储凭据；删除 AI 配置会移除对应 API Key。

当前版本的 AI 对话历史默认自动保存在**应用本地存储**，包括消息及用于恢复会话的工具和项目上下文。可以关闭自动保存并在历史界面删除记录。AI 问题报告也保存在应用本地，直到清理或超过存储数量限制。关闭保存不会自动删除已有记录。

工作区文件、同步缓存、工作流元数据以及外部 Agent 自身的会话记录可能另存于设备、远程主机或工作区（包括 `.nimote` 目录）。应用历史删除不会自动删除这些副本，或第三方已接收的数据。普通历史与工作区文件不等同于系统安全存储；请勿把密钥写进提示词或项目文件。

## AI、MCP、GitHub 与其他连接 {#integrations}

直接模型请求发送到你选择的 Provider 端点。Agent 任务可读取相关文件，并将工具输出作为模型上下文；数据范围取决于任务、权限与运行模式。首次发送前的 AI 隐私界面用于确认相关设置；请在发送或批准操作前核对内容与接收方。

MCP 的 HTTP 服务接收工具请求；stdio 服务在所选设备、Local Linux 或 SSH 环境中运行。外部 ACP Agent 是独立运行时，可能使用自己的凭据、日志、网络服务和存储。GitHub 授权或个人访问令牌用于你选择的仓库、Issue、Pull Request 等操作；发布、推送或分享可能使内容对他人可见。

使用这些功能前，请了解接收方的保存、训练使用与删除规则。BYOK 不意味着提供商不保留数据，也不意味着所有请求只发送给模型服务。你可移除配置、断开集成或在相应服务中撤销授权；已发送的数据需按接收方的删除流程处理。

## 应用统计与网站访问 {#analytics}

**应用统计：** 当前应用会初始化 Firebase Analytics，并记录上表所列使用信息；这些统计不是完全匿名数据。当前应用未提供通用的统计关闭开关；官网统计选择不会关闭应用统计。隐私请求请通过本页邮箱提交；不要将代码片段、密码或敏感路径作为报障资料直接发送。

**网站统计：** 本网站仅在你选择允许后加载 Google Analytics，分析页面访问和下载、文档等链接点击，包括页面路径、链接文字、目标路径、活动标记和浏览器/设备信息。统计可能使用 Cookie 和在线标识符。你可以拒绝，或随时通过页脚“网站隐私设置”撤回；拒绝不影响阅读与下载链接的使用。网站不会为统计设置登录用户 ID，也不启用广告个性化或 Google Signals。

网站会在浏览器本地保存统计选择；清除网站存储会重置该选择。网站托管、内容分发和安全服务仍需处理 IP 地址、请求和基本连接信息，以提供页面和防止滥用。

## 权限与设备功能 {#permissions}

- **Android：** 网络权限用于连接、认证和订阅验证；计费权限用于 Google Play 购买；通知及前台特殊用途服务用于用户发起的后台 SSH 会话；外部存储权限仅适用于 Android 9 及以下。当前清单还声明广告标识符权限（`AD_ID`），统计 SDK 的实际标识符处理受系统与 SDK 设置影响。
- **iOS / iPadOS：** 使用网络、系统文件选择器和 App Store 购买；任务状态可通过 Live Activities 显示。文件选择器授权只针对你选择的内容。
- 当前应用未声明相机、麦克风、通讯录或精确定位访问用于上述功能。通知与锁屏状态可能被旁人看到，可在系统设置中管理。

## 服务提供商与跨境处理 {#providers}

我们使用 [Google / Firebase](https://firebase.google.com/support/privacy) 提供认证、云端和统计能力，使用 [RevenueCat](https://www.revenuecat.com/privacy/) 同步订阅。商店购买适用 [Apple 隐私政策](https://www.apple.com/legal/privacy/)或 [Google 隐私政策](https://policies.google.com/privacy)。GitHub 集成和公开问题适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。AI、MCP 和远程主机的接收方由你的配置决定。

上述服务的基础设施可能在你所在国家或地区以外。跨境位置及保障取决于实际服务和配置；我们按适用法律处理必要的告知、授权与保障。我们不出售个人数据。必要时可为履行法律义务、保护安全或处理争议披露相关信息。

## 保留与删除 {#retention}

| 数据 | 保留及删除方式 |
| --- | --- |
| 账户 | 在提供账户服务期间保存；账户删除流程移除认证账户与主用户记录。 |
| 订阅与试用 | 为权益校验、重复试用防护、争议和法定义务保存。删除账户会解除订阅所有权关联，但不等于删除全部交易和试用记录；可能保留删除关联记录、原用户标识及设备试用哈希。 |
| 对话、配置、凭据与文件 | 由设备和工作区中的删除操作管理；撤销第三方凭据与删除设备副本是不同操作。 |
| 分析与服务日志 | 受对应服务的保留配置和必要的安全、排障用途约束；账户删除不会自动清除所有历史统计。可申请相关数据的删除。 |
| 支持资料 | 在处理请求、跟进问题及必要的争议或法律保留期间保存。请仅提供必要信息。 |

没有适用于全部数据的统一保留天数。需要例外保留时，应以具体目的、适用义务及必要期限为限。请求涉及保留记录时，可联系我们了解适用范围和处理安排。详情见[账户删除](/zh/account-delete)。

## 你的选择与权利 {#rights}

你可以删除本地历史和配置、停止可选集成、管理系统权限、拒绝网站统计，并在 **设置 → 删除账号** 发起账户删除。无法登录或已卸载时，可通过[网页删除入口](/zh/account-delete)提交请求，无需重新安装。

依适用法律，你可申请访问、更正、复制或删除个人数据，以及撤回同意、限制或反对相关处理。请发邮件至 [support@nimotecode.com](mailto:support@nimotecode.com?subject=NimoteCode%20privacy%20request)，说明请求及必要的账户识别信息。我们可能核验身份，并告知处理进度、预计完成时间或不能执行的理由；适用法定期限优先。不要发送密码、验证码、私钥或完整支付资料。

## 安全、未成年人和更新 {#updates}

我们使用系统安全存储及认证措施保护数据，但无法保证所有设备、用户配置端点和第三方环境绝对安全。服务面向开发者，并非专门面向儿童；未满 13 岁或当地要求的更高最低年龄者不应创建账户或提交个人数据。商店内容年龄评级不等同于个人数据处理的年龄门槛。发现儿童数据问题请联系支持。

政策变更会在本页更新日期；涉及重大数据用途或共享变化时，将按适用要求提供额外通知或取得同意。
