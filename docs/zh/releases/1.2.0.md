## 1.2.0 · 2026 年 10 月 5 日

1.2.0 将 Monaco 编辑器带到桌面与平板工作区，改进 Windows 桌面版支持，并让 Explorer 的显示密度可按需调整；同时提升不同设备上的编辑、键盘输入、选择、终端布局和主题一致性。

### 新增

- **桌面与平板上的 Monaco 编辑器。** Windows、macOS、Android 平板和 iPad 现可使用 Monaco 编辑器；手机继续使用 Nimote Editor。可在设置中选择更适合自己工作流的编辑器。
- **更完整的编辑体验。** 文件、标签页、主题、语言感知编辑、Diff、剪贴板操作、文本选择与文档变更现在协同得更加稳定。
- **改进的 Windows 支持。** NimoteCode 在 Windows 桌面版上的安装和启动更加可靠。
- **Explorer 显示偏好。** 可在设置中调整 Explorer 字体大小（11–20）和行高（28–48）；从标签页、搜索或其他面板打开的当前文件会持续保持选中状态。

### 改进

- **更适合设备的编辑体验。** 编辑器会适应可用窗口空间，在分屏、折叠屏、平板和桌面窗口中均有更好的使用体验。
- **优化编辑交互。** 大屏设备上的文本选择、上下文操作、滚动、代码折叠、行装饰和 Diff 高亮更加可靠。
- **外接键盘工作流。** 手机端保存、撤销/重做快捷键更加可靠，也更好地兼容 CJK 输入法与外接键盘。
- **统一编辑器与终端外观。** 编辑器表面、分割线、搜索框、排版、终端颜色、滚动条、选择手柄和行号栏装饰更贴合当前主题。
- **更好的终端布局。** 横屏终端中的命令、标签、搜索控件和内容内边距保持对齐，Windows 键盘输入也更加可靠。
- **更清晰的 Explorer 层级。** 文件和目录行的选中态对比度更强，文本尺寸更一致，并持续显示当前打开文件的高亮。

### 修复

- 修复平板上的 Monaco 无法稳定接收键盘输入或使用剪贴板的问题。
- 修复切换或恢复编辑器显示时，文本选择、触控手柄和右键/上下文菜单交互异常的问题。
- 修复移动端和外接键盘使用时编辑器键盘配置及文字大小不一致的问题。
- 修复编辑器与终端主题不一致的问题，包括分隔线、搜索框以及内置浅色/深色主题中的 Explorer 选中颜色。
- 修复横屏与 Windows 环境中的终端布局和输入问题。
- 修复 Windows 桌面版无法稳定启动的问题。
