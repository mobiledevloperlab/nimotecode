## 1.2.2 · 2026 年 10 月 9 日 · Build 52

1.2.2 支持打开应用沙盒之外的项目目录，将 Git 页面接入横屏编辑器，并让 Git 状态与终端会话在工作过程中保持实时。

### 新增

- **打开外部项目目录。** 在 Android 和 iPadOS/iPhone 上，你现在可以通过系统文件夹选择器打开应用自身文档目录之外的项目目录：NimoteCode 通过系统授权获取访问权限、在重启后记住该目录，并通过安全的文件 Provider 读写。以此方式打开的工作区会显示友好的位置名称，而非原始 URI；需要原生文件系统路径的功能（Git、LSP、调试、任务、文件监听和 Agent）会提前提示不可用。
- **横屏编辑器内的 Git 页面。** 在停靠式横屏工作区中，Git Diff、提交 Diff 和冲突解决页面现在直接在编辑器区域打开——与设置页出现的位置一致，无需离开当前 IDE 上下文即可查看改动。竖屏仍保留原有的全屏页面。
- **近乎实时的 Git 状态。** Explorer 装饰和源代码管理面板现在会随终端、Explorer 操作或外部工具引起的文件变化即时更新，而不再等待轮询。

### 改进

- **横屏目录选择更充分利用宽度。** 在停靠式横屏工作区打开本地或远程目录时，目录选择器改为左右两栏：左侧浏览文件夹，右侧显示路径输入与当前指向的目录；竖屏与窄窗口仍保持原来的单列。横屏宽面板的空状态也把插图与操作按钮并排，不再把内容挤成中间一列。
- **外部工作区显示友好名称。** 在外部工作区中，Explorer、编辑器标签页、面包屑、Markdown 预览标题和搜索结果会显示文件 Provider 提供的文件夹与文件名，而不是原始的 `content://` 地址。
- **卡片式横屏面板。** 横屏中间面板现在与编辑器卡片保持一致：共享编辑器的表面与圆角，Activity Rail 通栏全高，面板与编辑器之间的拖拽条保持居中。
- **更紧凑的 Explorer 默认值。** 新安装默认将 Explorer 目录文字设为 14、行高设为 35，让手机和平板一屏显示更多条目。你已保存的偏好仍然优先。
- **更好用的终端预置。** 新增 “/” 快捷预置；点击预置不再收起软键盘，预置会写入当前终端，且仅在终端原本持有键盘时恢复焦点。
- **SSH 会话可承受短暂中断。** 应用从后台返回后，NimoteCode 会先重新探测连接再判定连接丢失，短暂切换后台的活跃会话得以保留其回滚内容；真正失效的会话仍会走原有重连流程。

### 修复

- **新安装默认使用英文。** 全新安装不再跟随设备语言或回退到中文；显式选择的语言仍会被记住。
- 修复 Local Explorer 标题下方重复的分隔线，使本地与远程 Explorer 共用一条细线。
- 修复切换主题时 Explorer 会话历史页与远程目录选择页不重绘的问题。
- 修复本地 Git 状态漏报子目录改动和未跟踪文件的问题。
- 修复在外部工作区写入或删除文件后 Android 崩溃的问题。
