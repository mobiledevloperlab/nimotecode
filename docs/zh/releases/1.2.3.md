## 1.2.3 · 2026 年 10 月 15 日

版本 1.2.3 改进了移动端开发工作流：支持与 Local Linux 共享本地项目，提升 SSH 会话韧性，在应用外显示任务状态，并带来可配置终端与更精致的深色外观。

### 新增

- **与 Local Linux 共享本地项目（Android）。** 在 Local Linux 中开启「共享本地项目」后，可在 Linux 工作区的 `/mnt/local` 打开与应用本地项目完全相同的文件；也可以导入手机目录作为新的共享项目，或在完成后导出项目副本。
- **应用外的任务状态。** iPhone 和 iPad 可以通过实时活动显示已观测到的 AI 与终端任务；Android 可以通过可关闭的通知显示已观测到的 AI 与终端任务状态。这些界面仅展示最近一次状态，不会让任务在后台持续运行。
- **移动端终端控制。** 可选择紧凑或扩展的扩展按键行，并使用单次或锁定修饰键；新增专注模式，在需要时为终端腾出更多空间。
- **可选的 SSH 后台支持（Android）。** 已打开的 SSH 工作区可使用 Android 前台服务通知，并可从中停止后台支持或查看系统设置说明。

### 改进

- **导入 Local Linux 的项目可可靠打开。** 导入的项目现在会直接打开到其共享 Linux 位置；新的 SSH 工作区也默认从远端主目录开始。
- **SSH 恢复更平稳。** 进入后台不再立即丢弃仍存活的 SSH 会话或 Explorer 状态；iOS 会在后台暂停探测，并在返回应用后验证传输连接。
- **更深邃的深色主题。** 默认深色主题现采用 AMOLED 纯黑画布，并调整了表面、输入区域、浮层和对比度颜色；启动画面也同步使用这套配色。
- **更简洁的终端标题栏与启动页。** 终端操作归入更简洁的溢出菜单，启动动画与颜色也进一步贴合应用外观。

### 修复

- 修复编辑器、AI 历史、登录、Git 历史和 SSH 等工作区状态可能串到另一个工作区的问题。
- 修复 SSH EOF 探测触发不必要恢复的问题，并在连接恢复期间保留 Explorer。
- 修复 SSH 后台说明与应用弹窗设计不一致的问题。
