## NimoteCode 1.2.5

版本 1.2.5 让日常项目管理更高效：资源管理器新增批量文件操作，并在列表中显示文件大小和已加载的目录数量；同时，AI 和 SSH 工作流获得更直接的操作反馈，整个 IDE 在手机、平板和桌面上的界面层级进一步统一。

### 新增

- **资源管理器批量操作。** 可一次选择多个文件或目录，统一复制、移动或删除；本地、远程和外部存储工作区均会根据可用能力提供相应操作。
- **更丰富的资源管理器信息。** 文件列表现在显示文件大小，已展开目录会显示已加载的项目数量，便于快速判断项目结构和内容。
- **AI 快捷操作。** 在空白 AI 对话中可直接新建对话、查看或调整 AI 配置，更快开始下一项任务。

### 改进

- **更稳定的 SSH 连接反馈。** 发起连接后会立即显示进行状态，并防止重复提交连接请求。
- **更一致、更易读的工作区界面。** 中间面板标题、工具栏、分隔线、字体、图标、间距和主题对比度得到统一；移动端浮动导航、Markdown 文档预览以及通知提示也更加清晰自然。
- **更简洁的 AI 模型切换。** 模型菜单和配置切换流程更直接，减少不必要的操作。

### 修复

- 改善模态窗口、面板和本地 Git 入口的协作方式，避免界面样式调整影响本地 Git 的访问。
