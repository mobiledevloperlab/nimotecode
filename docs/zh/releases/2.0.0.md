## NimoteCode 2.0.0

2.0.0 是 NimoteCode 的一次大版本更新。它将 IDE 从固定功能集扩展为可安全定制的工作台：现在可以创建和运行插件，持续推进 AI Agent 任务，并在更流畅、更统一的界面中完成 Git、终端和日常编辑工作。

<span id="release-new"></span>

### 新增 · 5

- **插件中心与自定义工作台。** 可从功能中心管理工作区能力，创建自定义插件和声明式面板；插件可提供表单、工作流、产物视图及本机或 SSH 目标上的脚本任务。安装或更新权限变化会先清晰展示并等待确认。
- **更连续的 AI Agent 协作。** 正在执行的 Agent 支持追加指令，并可在需要时向你提出交互式问题；上下文、历史记录、提示词编辑和运行时间线也经过重构，更适合长时间任务。
- **Git 分支与差异改进。** 可在 Git 标题栏中搜索、创建和切换分支；编辑器以安静的变更栏标示 Git 改动，差异内容提供更清晰的语法高亮。
- **更直接的终端辅助。** 可直接将终端输出交给 AI 分析；终端标签设置更容易访问。
- **更灵活的远程连接。** 当网络环境有要求时，可通过 SOCKS5 或 HTTP CONNECT 代理连接 SSH 工作区。

<span id="release-improved"></span>

### 改进 · 6

- **焕新的视觉与布局系统。** Material 3 风格、主题设置、设置页、资源管理器工具栏、空状态、Markdown 预览和启动动效全面统一；默认界面缩放调整为 90%，在有限屏幕空间中呈现更多工作内容。
- **更稳健的插件运行时。** 插件面板会保留运行状态并避免过期更新；前台工作流支持逐步填写表单，耐久任务可在目标环境中继续运行，删除插件时会安全取消其任务。
- **更高效的 AI 与资源使用。** 长对话按轮次折叠，历史回复按需展开；隐藏面板会暂停不必要的刷新，编辑器与聊天记录的内存占用也受到控制。
- **移动端工作流更自然。** Android 的 AI 入口更新为动态岛样式；账户与订阅、外观设置和共享输入控件在不同尺寸下更协调。
- **全设备统一编辑器。** Nimote Editor 现已成为手机、平板和桌面的默认编辑器，在各类设备上提供一致的文本选择、键盘与输入法、撤销、粘贴、查找替换和光标体验。
- **贴合工作区的终端配色。** 终端颜色方案可配置；终端和移动端系统栏会随当前主题保持视觉一致。

<span id="release-fixed"></span>

### 修复 · 5

- 修复插件元数据兼容、权限更新、面板滚动和任务取消等边界问题。
- 修复 AI 追问在运行时间线中的位置、共享输入文本垂直对齐，以及资源管理器工具栏布局问题。
- 改进内置 Agent 运行时及工作区工具的可靠性和安全边界。
- 修复编辑器与终端在移动端键盘、行编辑和异步会话重新连接时可能出现的焦点、选择及输入问题。
- 长时间运行的 Agent 任务会以更紧凑的方式显示输出，并可在达到设定步骤预算时选择继续执行。
