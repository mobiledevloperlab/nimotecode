## NimoteCode 2.1.0

2.1.0 合并了跨设备工作区体验改进，并让内置 Agent 在大型代码库中的检索与理解更高效、更稳定，尤其适合处理超长行或压缩后的文件。

<span id="release-improved"></span>

### 改进 · 5

- **更高效的代码搜索。** Agent 会限制搜索结果的上下文范围，并只构建需要显示的内容，减少在大型或压缩文件中搜索时的内存占用和等待时间。
- **更稳健的文件摘要。** Agent 生成文件摘要时会优先保留最相关的代码片段，以更少的资源处理长文件，同时保持摘要结果稳定一致。
- **统一的跨设备工作区。** 外观模式与强调色可独立选择；工作区的布局、控件与排版在手机、平板和桌面端更加一致。
- **更连贯的横屏与编辑体验。** 横屏工作区页面和 Git 历史可作为编辑器标签打开，退出全屏终端后会保留编辑器标题栏；编辑器字体渲染、语法高亮和 Git 差异排版也得到改进。
- **更直接的查找与移动端操作。** 文件搜索可直接打开，远程连接状态显示在目录旁；移动端 Agent 和终端的拖动、键盘选择与复制操作更加顺畅。
