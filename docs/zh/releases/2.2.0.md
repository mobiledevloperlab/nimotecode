## NimoteCode 2.2.0

2.2.0 将 GitHub 工作流带入 NimoteCode：可在独立的 GitHub 页面中登录、浏览仓库并从 GitHub 打开项目，随后在熟悉的工作区内完成分支、议题、拉取请求和 CI 协作。本次还为 Android Local Linux 新增了实验性的开发工具包，进一步增强搜索可靠性，并统一了整个应用的面板和对话体验。

<span id="release-new"></span>

### 新增 · 3

- **原生 GitHub 开发工作流。** 使用浏览器设备授权或令牌登录后，可浏览账户仓库、分支和仓库详情，并将项目克隆到本地或 SSH 工作区后直接打开。
- **Issue、PR 与 CI 协作。** 在 GitHub 页面查看和筛选 Issue、拉取请求、评审及检查状态；可从 Issue 创建带上下文的 Agent 任务，并在完成改动后创建分支、推送、Fork 和拉取请求。
- **Android Local Linux 开发工具包（实验功能）。** 可按需安装基础命令行工具、Python 和 Web 开发工具，安装后可创建、运行并打开示例项目。首次安装需要联网，无需重装 Linux，已有项目会保留。

<span id="release-improved"></span>

### 改进 · 5

- **更可靠的 GitHub 操作。** 登录、项目克隆和 Local Linux 工作区操作更加可靠；推送与发布失败后，可根据明确提示恢复操作。
- **更稳健的工作区搜索。** 搜索结果的显示、高亮与移动端操作更加稳定；Android Local Linux 的代码搜索无需额外配置。
- **更一致的工作台。** 设置、源代码管理、GitHub、搜索及其他面板共享更统一的层级、字体、控件与窄屏布局；会话概览和对话布局也更易浏览。
- **更清晰的工具包状态。** 未安装时显示下载与空间估算，安装后突出示例运行和工具检查；提供任务日志、失败重试和中断提示，离开页面不会取消任务。页面字体、间距、按钮和确认弹窗与工作台保持一致。
- **统一的复制反馈。** 常用面板中的复制操作现在使用一致、明确的反馈。

<span id="release-fixed"></span>

### 修复 · 2

- 修复 GitHub 克隆中的瞬时 API 失败、移动端 HTTPS、取消和目录冲突恢复等边界问题，并避免凭据在不应使用的 Git 操作中泄露。
- 改善远程工作区的搜索结果与高亮，减少大型结果或移动端操作时的卡顿和显示异常。
