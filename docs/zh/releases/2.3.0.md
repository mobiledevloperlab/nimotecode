## NimoteCode 2.3.0

2.3.0 让工作区适配不同任务：可在 IDE、终端和 AI 模式间切换，同时保留项目与资源管理器状态。本次还升级插件、Windows SSH 工作区、Agent 协作、终端控制、移动端 Git 审阅，以及 SSH 主机上的 Docker 开发体验。

<span id="release-new"></span>

### 新增 · 6

- 可在 IDE、终端和 AI 模式间切换，同一项目与资源管理器状态保持同步。
- 插件可声明带版本的贡献和依赖，安装前校验；经批准的工具、技能和工作流可提供给内嵌 Agent，工作区事件也可触发受控自动化。
- 通过 PowerShell/SFTP 浏览 Windows 远程工作区，并使用搜索、Git、终端、语言服务和 Agent。
- 支持该能力的 ACP Agent 在任务执行期间可接收后续指令。
- 在 SSH 主机管理容器、镜像、卷、网络和 Compose 项目；查看详情、日志、统计，使用 exec、搜索 Docker Hub 并控制单个 Compose 服务。
- 从项目 devcontainer.json 创建或重建 Dev Container，并在配置好的隔离工作区中打开项目。

<span id="release-improved"></span>

### 改进

- 新增自适应终端分屏、终端跳转 IDE 与 AI 分析、命令历史、显示偏好保存、缩放和连接专属提示符。移动端 Git 审阅、Windows SSH、Agent 诊断、Docker 恢复及实时 Pro/试用/Early Access 权限均得到改进。
