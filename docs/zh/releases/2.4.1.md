# NimoteCode 2.4.1 · Host 工作区与文件传输

2026 年 11 月 19 日 · Build 66

<LatestReleaseLink />

[← 全部发布记录](/zh/releases/)

2.4.1 重构应用界面，改善平板布局，并新增用于管理远程终端与 Agent 会话的 Host 工作区。本次更新还加入工作区文件传输和项目任务发现，改进 GitHub CI 查看、终端历史搜索与远程保存。

<span id="release-new"></span>

### 新增

- **Host 工作区**：可在远程机器上安装并启动兼容的 NimoteHost，再通过 SSH 连接，浏览和恢复远程终端与 Agent 会话。
- **Host Agent 会话**：在受支持的会话中使用结构化对话、审批、命令和模型控制。
- **Host 任务收件箱**：查看任务、验证结果与 Diff，或将 GitHub Issue 派发给 Agent。具体可用功能取决于 Host 能力与配置。
- **Host 插件**：访问兼容的 Host 插件，并将项目任务与工作区终端关联。
- **文件与文件夹传输**：在设备与 SSH 工作区之间传输文件和文件夹，或在本地导入、导出。
- **项目任务发现**：从 npm、Taskfile、Makefile、justfile 和 VS Code 任务定义中发现受支持的项目任务。

<span id="release-improved"></span>

### 改进

- **界面与平板支持**：重构工作台，改善横屏和平板布局、编辑器操作及移动端 Git 审查。资源管理器显示 Git 状态颜色。
- **工作区模式与插件**：在 IDE、终端和 AI 模式之间切换时保留项目与资源管理器状态；改进插件、受支持的 Agent 运行中追加指令，以及 Windows SSH 工作区。
- **终端操作**：改善响应、搜索、滚动、剪贴板访问和交互式程序使用。支持搜索保留的终端历史，改进宽字符选择与鼠标输入。
- **终端与工作区工具**：从终端输出打开文件位置，将选中输出发送给 AI，并查看受支持的命令记录。支持自适应终端分栏、SSH 主机上的 Docker 与 Compose 管理，以及 Dev Container 创建。
- **GitHub CI**：筛选工作流运行记录，查看步骤日志和错误上下文。
- **配置与辅助功能**：统一应用配置入口，改善减少动态效果支持。可配置 Agent 提示音与震动、编辑器行号和横屏缩略图。
- **SSH 与远程保存**：改进 SSH 主机校验与远程保存可靠性，包括 Windows 主机上的远程保存。

<span id="release-fixed"></span>

### 修复

- 修复若干问题。

Host 功能需要兼容的 NimoteHost。Agent 与插件的可用性取决于 Host 能力及配置。
