# NimoteCode 2.4.1 · Host 工作区、项目任务与远程可靠性





[← 全部发布记录](/zh/releases/)

2.4.1 引入 Host 工作区，方便通过 SSH 管理远程会话和 Agent 任务，并改进终端、编辑器与跨设备工作台。

<span id="release-new"></span>

### 新增

- **Host 工作区与会话。** 先在远程机器安装并启动兼容的 NimoteHost，再通过 SSH 连接，浏览和恢复远程终端与 Agent 会话，查看历史、输出和生命周期；可搜索、筛选、固定和整理会话。Host 是可选功能，原有 SSH 工作流仍可使用。
- **Host Agent 协作。** 支持兼容的 Codex、Claude 和 OpenCode 结构化对话、工具详情、审批、命令与模型选择；支持的会话可在运行中接收后续指令。可根据 Host 能力选择执行策略，敏感操作仍可能需要确认。
- **任务收件箱与 GitHub Issue 工作流。** 在兼容 Host 上查看任务状态、审批、验证结果与 Diff，继续处理或归档任务；可将 GitHub Issue 派发给 Agent，并按所选策略处理发布。部分能力取决于 Host 版本及其配置。
- **Host 插件与项目任务。** 在侧边栏访问兼容 Host 提供的插件和界面；插件可提供带版本的表单、分页表格、详情和交互界面，并沿用权限校验。
- **项目任务运行器。** 从 package.json、Taskfile、Makefile、justfile 和 .vscode/tasks.json 发现支持的任务，在工作区终端运行；Make/just 动态发现需明确确认，不支持的配置会显示说明。
- **Agent 提醒与编辑器设置。** 统一 IDE、AI 和 Host 的任务完成、待确认与失败提醒，支持提示音和震动，实际反馈取决于设备及系统设置；可配置编辑器行号及横屏缩略图。Windows 默认启用 Pro。

<span id="release-improved"></span>

### 改进

- **会话与工作台。** 统一会话历史和环境入口，优化 SSH 连接选择；手机、平板和 Windows 的导航、面板、菜单、主题及横竖屏布局更加一致。
- **应用配置与辅助功能。** 在统一的应用配置入口管理核心功能、面板和插件；Agent 提醒移至 Agent 配置。改进横屏工作台配色、平板标题栏，并遵循系统减少动态效果设置。
- **GitHub CI 监控。** 按分支和工作流筛选运行记录，查看步骤日志与错误上下文，并在日志不完整时显示提示。
- **终端体验。** 优化大量输出时的响应与绘制，改进同步更新、搜索高亮、滚动、软键盘与长按导航键；改进 Vim、交互式程序、剪贴板和 Windows 粘贴。
- **编辑与 Git 审阅。** 改进长文件编辑性能、远程保存和失败提示；Git 差异支持长行换行，变更导航移至底部。
- **Host 历史与恢复。** 改进会话重连、历史加载、任务关联和活动状态显示；历史刷新失败时保留已加载内容；统一历史减少重复记录，并支持离线删除本地历史条目。

<span id="release-fixed"></span>

### 修复

- 加强 SSH 主机密钥校验、Windows known_hosts 并发访问，以及 Windows 连接现代 macOS SSH 服务器的兼容性。
- 修复编辑器对错误标签执行剪贴板或保存操作的问题，并改进远程文件操作和写入失败后的恢复。
- 修复终端滚动、Unicode、输入法、搜索结果与会话重置中的问题，减少调整面板和终端大小时的异常。
- 更新 ACP Agent 版本发现与模型列表获取，改善启动和命令发现。
- 修复 Agent 输出重复或顺序错乱、自动审批及会话历史边界问题，并保护未保存的编辑内容。

### 2.4.1 的进一步改进

- 搜索保留的终端历史，改进宽字符选择和鼠标操作。
- 资源管理器显示 Git 状态颜色；改善编辑器保存基线、Windows SFTP 保存和多进程存储。
- 完善横屏和平板布局、编辑器操作、主题及启动体验。
- 原生 Host Agent 会话接管是默认关闭的实验功能，需要显式构建开关和兼容的 Host 能力。
