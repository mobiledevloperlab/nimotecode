# NimoteCode 2.5.0 · 配对 SSH、持久终端与 NimoteHost 安装

待发布 · Build 68

[当前正式版本 · 2.4.1](/zh/releases/2.4.1) · [← 发行历史](/zh/releases/)

### 远程连接与 Host

- **已配对电脑与个人 Tailscale。** 在连接选择器里选择已配对电脑，可使用该电脑同步的 Tailscale IP 或 MagicDNS 名称，继续用现有 SSH 密码或密钥登录。连接选择器也保留手动 SSH 和可用的本地环境入口。可在 NimoteCode 内解除设备绑定。
- **Nimote Relay 公网接入。** 兼容的已配对电脑开启远程访问后，可通过 Nimote Relay 建立 SSH 连接。桌面客户端加入了 Relay 支持，macOS 需要 12 或更新版本。公网接入仍在发布验收中，跨网络直连和线路切换的验证范围有限。
- **更稳的 SSH。** 改善慢速或不稳定网络下的连接建立和恢复，减少交互输入等待，改进终端输出、窗口尺寸同步和 SFTP 文件读取。Android 也改进了使用密钥文件登录的兼容性。
- **通过 SSH 安装、启动和更新 NimoteHost。** Host 面板显示安装状态和版本，可在确认后使用 Host 面板提供的发行版进行安装或更新。更新提示可关闭，之后仍可从 Host 顶栏打开。遇到下载或安装问题时会显示具体原因和重试入口。若更新需要停止会话，界面会先请求确认。
- **配对设备的信任与恢复。** Relay 分阶段显示授权、电脑确认、隧道建立和 SSH 登录。解除配对会撤销 Relay 访问。兼容的 Host 服务可经同一配对电脑的不同已验证连接方式恢复到同一个 Host 工作区。

### 终端

- **SSH 持久终端。** 在兼容且安装了 tmux 的 SSH 主机上，Pro 用户可从终端菜单创建或恢复持久会话。关闭本地标签后，远端任务可以继续运行。也可以从菜单主动结束远端会话。
- 优化 tmux 历史滚动、首次绘制和光标定位。简化终端连接、搜索和会话管理入口，改善横屏软键盘及快捷键操作。高级搜索会等中文输入法提交后再查询。
- 改善双击选词、宽字符选择和选区对比度。在 Codex、Claude Code 等捕获鼠标的终端程序中，可用 Shift 拖选并右键复制。程序重绘后仍可复制原选区。
- **终端操作细节。** 可从会话历史或远端列表恢复 tmux，同一 SSH 用户也可从另一客户端接入。手机横屏时，如果软键盘已打开且面板有足够空间，会显示 Esc、Ctrl 等终端快捷键。状态提示出现时仍可操作终端菜单。

### 工作台、编辑器与 Git

- 手机竖屏工作台采用浮动导航栏，统一 IDE 和 Host 的面板标题与连接入口。单栏 IDE 从空编辑器启动，可直接浏览文件。最近项目和连接选择也更容易找到。
- 工作区搜索在编辑器中定位并高亮匹配内容，改善 SSH 工作区跨文件搜索和大目录展开。编辑器滚动条拖动与文本选区互不干扰，达到标签上限时保留另一分栏中可见的标签。
- 从编辑器直接打开 Git 文件历史，改进文件改名后查找历史和失败后的重试。大型仓库的 Git 变更列表按需加载。
- 改善编辑器与 AI 面板的选区对比度，修复右键菜单打开后复制丢失选区、远程目录选择器返回旧路径，以及任务保存或删除时仍可误改字段的问题。
- **Git 历史与 Agent 审查。** 文件和行历史能区分历史为空与加载失败，支持在原页重试，并改进了远端目录别名的处理。Agent 文件缺少记录快照时，审查卡会说明原因，并提供查看当前 Git 差异的入口。

### AI 与平台

- 改善内置 Codex 的响应速度、取消和工具调用，并优化大仓库中的 Agent 搜索与文件操作。恢复中断的 Agent 历史时保留已取消的轮次，AI 历史搜索等结果返回后再显示空状态。
- Android 本地 Linux 可通过清单提供开发工具包，社区可使用同一格式贡献配置。iOS 更新了应用启动和前后台切换的处理，桌面端修复邮箱登录流程。原生桌面版本默认启用 Pro。
- **功能权限。** Free 用户可以浏览 GitHub，在兼容的 SSH 工作区查看 Docker 概览，以及管理断点。GitHub 克隆与写入、Docker 管理及启动调试需要 Pro。受限操作会单独显示权限标识。
- **工作台与平台兼容。** 工作区菜单提供 GitHub 与试用项目入口。AI 输入框的键盘触发区域更大，空对话在较矮屏幕上可滚动。任务和插件会按平台提示可用终端；本地 Linux 由 Android 提供。
