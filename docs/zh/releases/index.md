# NimoteCode 发布说明

本页收录全部公开发布记录。NimoteCode 已在 Google Play（Android）和 App Store（iPhone 与 iPad）上架；当前商店链接请见[下载页面](/zh/download)。

## 1.1.7 · 2026 年 9 月 12 日

发布于 2026 年 9 月 12 日（Build 41）。本次更新加入 Android 本地 Linux 开发环境，完善 HTML 与链接预览，并提升编辑器、AI 和 Task 操作的可靠性；同时带来外部 ACP Agent 与统一 SSH 登录环境的改进。

### 新增

- **Android 本地 Linux 工作区。** 在支持的 ARM64 与 x86_64 Android 设备上使用内置 Ubuntu 环境，无需 root 权限，包含 Bash、Git 和 SSH。可安装、启动、停止、打开、重置或删除环境，沿用现有 SSH 工作区体验。iOS 不提供此功能。
- **HTML 快照预览。** 直接在内置浏览器中预览当前 HTML 编辑内容，包括未保存修改；支持工作区内的 CSS、JavaScript 和图片资源。需要构建步骤或后端的项目仍需启动自身开发服务器。
- **一键打开链接。** 终端、AI 回复和工具输出中的网页链接提供统一的浏览器入口。
- **Local Linux 简介与开源信息。** 环境页面说明存储、网络、进程生命周期与数据删除行为，并可直接查看随包提供的开源许可证。
- **统一 Agent 斜杠命令入口。** 聊天输入框支持 `/` 菜单、点选及键盘补全。内置运行时提供新会话、停止和状态快捷操作；ACP 命令由当前会话动态上报，不硬编码命令列表。
- **外部 ACP Agent。** 可在 SSH Workspace 中选择并运行兼容 ACP 的外部 Agent。
- **Agent 能力与会话管理。** 统一呈现 Agent 能力、权限请求、会话状态和运行进度，并支持在内置 Agent 与外部运行时之间切换。
- **刷新远程环境。** 可从 Terminal 菜单主动重新读取远程用户的登录环境；SSH 重连后也会自动刷新。

### 改进

- **更清晰的编辑器工具栏。** 符号操作收入“更多”子菜单；浏览器按钮移至标题栏，网址弹窗统一样式并提供输入校验。
- **补齐界面国际化。** Local Linux、浏览器、链接按钮、Task 操作及相关编辑器和 AI 元数据文案覆盖简体中文、英语、日语、韩语和俄语，包含状态、错误提示和辅助功能标签。
- **一致的工作区入口。** 本地 Linux 与其他工作区共用选择卡片，环境操作采用统一弹窗与按钮样式。
- **统一 AI 输入区图标。** 命令、会话操作、设置与发送图标统一使用应用图标库和紧凑尺寸规范，保留主操作与选中状态的视觉区分。
- **精简 ACP 设置与统一执行展示。** 默认折叠启动命令和参数，隐藏未配置的变量占位项及不可切换的选项。工具执行中的参数、类型和输出持续更新到共用时间线。
- **ACP 环境配置导入。** 支持粘贴多行 `export`、`NAME=value` 或 JSON `env` 对象，使用成熟语法库安全解析，不执行命令。预览会隐藏变量值，合并后需保存并检查。
- **统一 SSH 登录环境。** Terminal、ACP Server、Agent 子进程、Tasks、Debug、语言服务、Git 和外部 CLI 现在共享同一套远程环境解析机制。
- **兼容用户真实 Shell。** 自动识别远程账户的默认 Shell，并加载其正常登录环境，支持 bash、zsh、fish 及其他 Shell，无需针对特定配置手动适配。
- **完整继承自定义工具与变量。** 用户在登录环境中配置的 `PATH`、语言区域、SSH Agent 和自定义服务变量会自然传递给远程进程。
- **更安全的诊断信息。** API Key、Token、Secret、Password 等敏感环境变量在日志和 Agent 启动诊断中会自动脱敏。

### 修复

- 修复从编辑器返回 AI 面板后未定位到最新内容的问题，兼容长消息与延迟布局。
- 修复 Task 保存失败却已更新列表、删除后恢复、并发保存与刷新丢失修改的问题；保存与删除互斥，失败时保留编辑内容，使用临时文件替换保存配置。
- 修复默认任务 ID 重复、默认配置解析异常和编辑时丢失任务元数据的问题。
- 修复 SSH 权限或连接错误被误判为文件不存在的问题，避免错误创建默认任务配置。
- 修复 Agent 文件变更汇总遗漏、远程环境继承及终端链接在软换行、滚动和宽字符场景中的显示问题。
- 修复命令在 Terminal 中可用，但 ACP Agent、Claude Code、Codex CLI、Tasks 或 Debug 中提示找不到的问题。
- 修复 ACP Server 未获得完整远程环境，导致其启动的子进程缺少用户配置的问题。
- 修复 SSH 重连后继续使用旧环境或失效 `SSH_AUTH_SOCK` 路径的问题。
- 修复包含空格、换行或 Shell 特殊字符的环境变量无法可靠继承的问题。

## 1.1.6 · 2026 年 9 月 9 日

本次更新让首次使用更清晰，并修复编辑器、浏览器、源代码管理和 iOS 输入相关问题。

- **更清晰的订阅信息。** 订阅说明会根据应用所在平台呈现。

- **主题即时更新。** 切换主题后，引导页和编辑器空工作区会立即刷新颜色。

### 修复

- 恢复 Explorer 中的 Git 状态标识。
- 修复编辑器和应用内浏览器的回归问题。
- 修复官网等链接已在应用内浏览器成功打开时仍误提示“无法打开链接”的问题。
- 防止 iOS 重复创建键盘客户端，提升键盘和文本输入稳定性。

## 1.1.5 · 2026 年 9 月 6 日

本次更新让移动开发闭环更加完整：可以并排打开两个文件、预览 Web 项目、审查 Git 变更，并让终端与 AI 在长时间使用中保持可靠。

### 新增

- **应用内浏览器预览。** 无需离开工作区即可打开本地或远程 Web 项目，也可从终端 URL 直接进入预览。
- **编辑器双栏分屏。** 并排查看和编辑两个文件，每个分栏保留清晰的标签与导航状态。
- **内置媒体预览。** 直接检查图片，并在应用内播放支持的音频和视频。
- **更丰富的 AI 工作区。** AI Chat 展示最近任务和工作区上下文；紧凑的全局状态条让 Agent 在跨面板时仍清晰可见。
- **可选的编辑器 AI 工具。** 可按自己的工作流决定是否启用 AI 工具栏。
- **开源许可证说明。** 设置中新增开源软件许可证与版权归属信息。

### 改进

- **更可靠的远程开发。** 强化 SSH 连接处理，并通过连接复用降低远程命令与预览连接开销。
- **更流畅的长时间使用。** 隐藏面板暂停不必要工作，浏览器资源受控，编辑器、搜索、终端和 AI 的高频更新更高效。
- **更稳定的 Source Control。** 本地与远程状态刷新、首次提交、当前工作区命令、历史记录与 Diff 渲染更加一致。
- **更清晰的界面。** 优化编辑器菜单、搜索高度、登录、订阅、Explorer、AI 回复和深色主题细节。

### 修复

- 修复终端重复字符丢失、输入法组合文本重复提交及部分键盘输入异常。
- 改善终端恢复、面板切换、媒体连续播放和浏览器预览关闭的稳定性。
