# NimoteCode 发布说明

本页收录全部公开发布记录。NimoteCode 已在 Google Play（Android）和 App Store（iPhone 与 iPad）上架；当前商店链接请见[下载页面](/zh/download)。

## 1.2.0 · 2026 年 10 月 5 日

1.2.0 将 Monaco 编辑器带到桌面与平板工作区，改进 Windows 桌面版支持，并让 Explorer 的显示密度可按需调整；同时提升不同设备上的编辑、键盘输入、选择、终端布局和主题一致性。

### 新增

- **桌面与平板上的 Monaco 编辑器。** Windows、macOS、Android 平板和 iPad 现可使用 Monaco 编辑器；手机继续使用 Nimote Editor。可在设置中选择更适合自己工作流的编辑器。
- **更完整的编辑体验。** 文件、标签页、主题、语言感知编辑、Diff、剪贴板操作、文本选择与文档变更现在协同得更加稳定。
- **改进的 Windows 支持。** NimoteCode 在 Windows 桌面版上的安装和启动更加可靠。
- **Explorer 显示偏好。** 可在设置中调整 Explorer 字体大小（11–20）和行高（28–48）；从标签页、搜索或其他面板打开的当前文件会持续保持选中状态。

### 改进

- **更适合设备的编辑体验。** 编辑器会适应可用窗口空间，在分屏、折叠屏、平板和桌面窗口中均有更好的使用体验。
- **优化编辑交互。** 大屏设备上的文本选择、上下文操作、滚动、代码折叠、行装饰和 Diff 高亮更加可靠。
- **外接键盘工作流。** 手机端保存、撤销/重做快捷键更加可靠，也更好地兼容 CJK 输入法与外接键盘。
- **统一编辑器与终端外观。** 编辑器表面、分割线、搜索框、排版、终端颜色、滚动条、选择手柄和行号栏装饰更贴合当前主题。
- **更好的终端布局。** 横屏终端中的命令、标签、搜索控件和内容内边距保持对齐，Windows 键盘输入也更加可靠。
- **更清晰的 Explorer 层级。** 文件和目录行的选中态对比度更强，文本尺寸更一致，并持续显示当前打开文件的高亮。

### 修复

- 修复平板上的 Monaco 无法稳定接收键盘输入或使用剪贴板的问题。
- 修复切换或恢复编辑器显示时，文本选择、触控手柄和右键/上下文菜单交互异常的问题。
- 修复移动端和外接键盘使用时编辑器键盘配置及文字大小不一致的问题。
- 修复编辑器与终端主题不一致的问题，包括分隔线、搜索框以及内置浅色/深色主题中的 Explorer 选中颜色。
- 修复横屏与 Windows 环境中的终端布局和输入问题。
- 修复 Windows 桌面版无法稳定启动的问题。

## 1.1.9 · 2026 年 9 月 27 日 · Build 48

1.1.9 以统一设计规范重塑界面——按可用空间选择布局、统一的密度与状态样式、IDE 时间线式的 AI 对话和全新的界面缩放；同时加入 PHP 调试与更全面的语法高亮，并提升 Agent 会话、Agent 搜索、权益校验和启动流程的可靠性。

**平台支持：**Local Linux 搜索性能改进仅适用于 Android，iOS 不提供此功能。

### 新增

- **PHP 调试。** 在远端工作区中通过 Xdebug 与 PHP Debug 适配器调试 PHP 脚本：设置断点、从调试面板启动，Xdebug 环境由编辑器自动配置。适配器需与脚本运行在同一台远端主机上，详见 `docs/php-debugging.md`。
- **更全面的语法高亮。** 新增 C#、CSS、HTML、Ruby、Lua、Kotlin、XML、PowerShell、SQL、INI 语法，支持 JSX/TSX 映射，并在 Markdown 代码块中高亮 PHP（含 `<?php` 自动识别）。
- **服务商模型列表。** AI 聊天标题栏和配置编辑器会读取端点实际提供的模型列表（OpenAI 兼容的 `/models` 与 Ollama 的 `/api/tags`），支持按需刷新并记住上次选择；未手动命名时，配置会以所用模型命名。
- **Agent 会话设置。** 在握手阶段上报可选配置的 Agent，现在会在 AI 标题栏提供模型与会话选项，并按启动命令记住选择。
- **界面缩放。** 「设置 → 外观 → 界面缩放」（100%–150%）可整体放大应用，包括界面、图标、面板、弹窗、编辑器和终端；iOS 默认上调一档以贴合 Apple 的字号规范，选择 100% 即关闭。

### 改进

- **按可用空间选择布局。** 工作区不再依据设备方向，而是根据可用空间决定结构：窗口够宽时使用侧边栏、可折叠可调宽的面板和编辑器停靠结构；空间不足时使用单页手机布局。分屏、可调整窗口、竖屏平板和横屏手机现在都能得到正确的布局。
- **统一的面板设计规范。** 面板重建在同一套密度与状态规范之上：手机上 Explorer 由 9 行提升到 13 行，AI 面板、Git、调试、LSP 和任务的运行 / 等待 / 成功 / 警告 / 错误 / 已取消状态保持一致。
- **IDE 时间线式的 AI 对话。** 对话不再是聊天气泡：用户消息是引用块，计划步骤带真实状态，每次工具调用是一行紧凑条目（等宽命令行、每个改动文件显示 `+n −m`），变更确认按文件逐行列出。
- **统一的按钮、图标与控件尺寸。** 按钮、空状态、图标、AI 输入区和中间面板控件使用同一套尺寸规范，界面文字使用系统字体，代码和终端使用真正的等宽字体链，八套主题的字号规范保持一致。
- **中性化的浅色与深色主题。** 两套主题改为以中性灰为主、品牌色只用于状态，圆角与分割线收敛到一套规范，Git 面板各分区使用统一的标题栏。
- **统一的菜单外观。** 锚定弹窗和底部菜单使用相同的行样式、图标尺寸和对齐方式，菜单宽度贴合最宽条目，平板及以上宽度使用命令栏。
- **Explorer 细节优化。** 较长的文件和目录名称可以横向滚动查看，行高统一为适配触摸的 44px，文件与目录列表使用同一种行样式，不再使用原生 Material 列表项。
- **界面细节优化。** 优化竖屏底部菜单栏的高度与图文间距；工作区右侧的 Agent 浮动按钮由方形改为圆形，尺寸与位置保持不变，整个方形区域的点击依然有效。
- **更快且更可控的 Agent 搜索。** 工作区 grep 通过 ripgrep 执行并设有全局结果上限，Local Linux/PRoot 搜索改用 `find` + `grep` 流式执行，不再为每个候选文件发起一次远端读取——在 1000 文件的参考数据上由约 3 秒降至 0.2 秒。
- **更清晰的 Pro 权益呈现。** Pro 权益卡片和订阅页统一由同一来源描述试用、Early Access、已付费和免费状态，试用剩余时间、恢复购买、订阅已绑定其他账号等文案更清晰。

### 修复

- 修复 SSH 私钥连接在重新打开已保存连接后丢失手动粘贴或文件导入的密钥凭据的问题；导入的密钥现会安全保存，不再依赖文件选择器的临时路径。
- 修复 Android Local Linux Explorer 无法从 `/workspace` 返回访客根目录、继而进入 `/home` 等目录的问题。
- 修复手机上「更多」菜单与弹出菜单的多个问题：Git、编辑器和终端菜单统一改用锚定在按钮上的弹出菜单，宽度贴合内容而不再撑满屏幕，软键盘弹起时仍可使用，条目打开页面后也不再残留自身页面。
- 终端页头改为与 VS Code 一致的单条带（标签在最左、命令在最右），并修复 iOS 终端把一次 Return 按键提交两次的问题。
- 修复 Android 与 iOS 的启动界面：由同一个原生启动层显示品牌标志、slogan 和与应用主题及语言一致的加载条，并保持到工作区绘制完成。
- 修复已登录用户被误判无法使用 Early Access 和付费 Pro 的问题：Remote Config 缺失或不可达、RevenueCat 身份校正失败、服务器或设备时钟偏差都不再影响已生效的权益。
- 修复 AI 对话滚动查看历史时被打断、未打开文件时编辑器出现多余分隔线与重复「打开浏览器」按钮，以及关闭 SSH、编辑器搜索、Git、设置和资源管理器文件搜索等弹层后偶发崩溃的问题。
- 修复 Git Commit Detail 和 Diff 页面顶部间距与可读性、侧边栏选中态动画、LSP 与浏览器按钮图标混淆，以及 URL 输入、Agent 参数行和 Git 历史标题栏样式不一致的问题。

## 1.1.8 · 2026 年 9 月 14 日 · Build 45

1.1.8 开启 **Early Access Pro**，同时让工作区切换更灵活，强化 Android Local Linux 的安装、文件操作与 Git 可靠性，并优化源代码管理和整体界面层级。

**平台支持：**Local Linux 相关改进仅适用于 Android，iOS 不提供此功能。

### Early Access Pro

Early Access Pro 会逐步向更多用户开放进阶移动工作流：AI Agent、远程搜索、Git 写入、多终端、LSP、Debug 与 Sync / Cache。具体可用性和显示价格因商店、账号和地区而异，请以 Google Play 或 App Store 的当前内容为准。

### 新增

- **切换工作区目录。** 可在本地或 SSH 工作区中选择其他目录作为当前工作区；已访问的目录会保留在最近记录中，方便快速返回。

### 改进

- **更可靠的 Local Linux（仅 Android）。** 强化 PRoot 环境的启动与运行准备，补齐访客环境所需的临时目录，并改善 Ubuntu Base 的安装兼容性。
- **更清晰的文件访问边界（仅 Android）。** 编辑器、搜索、语言服务、Git、终端和 Agent 在 Local Linux 中使用一致的工作区范围，减少跨环境操作造成的异常。
- **更可靠的 Local Linux Git（仅 Android）。** 对 Local Linux 工作区的 Git 操作和 Task 产生的文件变更使用环境内的 Git 处理，确保状态、差异和提交历史反映实际工作区内容。
- **改进的开源信息交付（仅 Android）。** 随 Local Linux 提供更完整的软件包、许可证和源码来源记录。
- **更简洁的界面层级。** 调整主题、面板、标签、终端命令和 AI 执行时间线的视觉层次，降低干扰并保持主要操作更醒目。

### 修复

- 修复 iPad 外接物理键盘输入无响应的问题。
- 修复源代码管理面板在切换分支后未及时刷新，以及提交历史显示样式不一致的问题。
- 修复 Local Linux 中临时目录未完整准备而导致部分命令或安装流程失败的问题。

## 1.1.7 · 2026 年 9 月 12 日

发布于 2026 年 9 月 12 日（Build 41）。本次更新加入 Android 本地 Linux 开发环境，完善 HTML 与链接预览，并提升编辑器、AI 和 Task 操作的可靠性；同时带来外部 ACP Agent 与统一 SSH 登录环境的改进。

### 新增

- **Android 本地 Linux 工作区。** 在支持的 ARM64 与 x86_64 Android 设备上使用内置 Ubuntu 环境，无需 root 权限，包含 Bash、Git 和 SSH。可安装、启动、停止、打开、重置或删除环境，沿用现有 SSH 工作区体验。iOS 不提供此功能。
- **HTML 快照预览。** 直接在内置浏览器中预览当前 HTML 编辑内容，包括未保存修改；支持工作区内的 CSS、JavaScript 和图片资源。需要构建步骤或后端的项目仍需启动自身开发服务器。
- **一键打开链接。** 终端、AI 回复和工具输出中的网页链接提供统一的浏览器入口。
- **Local Linux 简介与开源信息。** 环境页面说明存储、网络、进程生命周期与数据删除行为，并可直接查看随包提供的开源许可证。
- **统一 Agent 斜杠命令入口。** 聊天输入框支持 `/` 菜单、点选及键盘补全。内置运行时提供新会话、停止和状态快捷操作；ACP 命令由当前会话动态上报，不硬编码命令列表。
- **外部 ACP Agent。** 可在 SSH Workspace 中选择并运行兼容 ACP 的外部 Agent。
- **Agent 能力与会话管理。** 统一呈现 Agent 能力、权限请求、会话状态和运行进度，并支持在内置 Agent 与外部运行时之间切换。
- **刷新远程环境。** 可从 Terminal 菜单主动重新读取远程用户的登录环境；SSH 重连后也会自动刷新。

### 改进

- **更清晰的编辑器工具栏。** 符号操作收入“更多”子菜单；浏览器按钮移至标题栏，网址弹窗统一样式并提供输入校验。
- **补齐界面国际化。** Local Linux、浏览器、链接按钮、Task 操作及相关编辑器和 AI 元数据文案覆盖简体中文、英语、日语、韩语和俄语，包含状态、错误提示和辅助功能标签。
- **一致的工作区入口。** 本地 Linux 与其他工作区共用选择卡片，环境操作采用统一弹窗与按钮样式。
- **统一 AI 输入区图标。** 命令、会话操作、设置与发送图标统一使用应用图标库和紧凑尺寸规范，保留主操作与选中状态的视觉区分。
- **精简 ACP 设置与统一执行展示。** 默认折叠启动命令和参数，隐藏未配置的变量占位项及不可切换的选项。工具执行中的参数、类型和输出持续更新到共用时间线。
- **ACP 环境配置导入。** 支持粘贴多行 `export`、`NAME=value` 或 JSON `env` 对象，使用成熟语法库安全解析，不执行命令。预览会隐藏变量值，合并后需保存并检查。
- **统一 SSH 登录环境。** Terminal、ACP Server、Agent 子进程、Tasks、Debug、语言服务、Git 和外部 CLI 现在共享同一套远程环境解析机制。
- **兼容用户真实 Shell。** 自动识别远程账户的默认 Shell，并加载其正常登录环境，支持 bash、zsh、fish 及其他 Shell，无需针对特定配置手动适配。
- **完整继承自定义工具与变量。** 用户在登录环境中配置的 `PATH`、语言区域、SSH Agent 和自定义服务变量会自然传递给远程进程。
- **更安全的诊断信息。** API Key、Token、Secret、Password 等敏感环境变量在日志和 Agent 启动诊断中会自动脱敏。

### 修复

- 修复从编辑器返回 AI 面板后未定位到最新内容的问题，兼容长消息与延迟布局。
- 修复 Task 保存失败却已更新列表、删除后恢复、并发保存与刷新丢失修改的问题；保存与删除互斥，失败时保留编辑内容，使用临时文件替换保存配置。
- 修复默认任务 ID 重复、默认配置解析异常和编辑时丢失任务元数据的问题。
- 修复 SSH 权限或连接错误被误判为文件不存在的问题，避免错误创建默认任务配置。
- 修复 Agent 文件变更汇总遗漏、远程环境继承及终端链接在软换行、滚动和宽字符场景中的显示问题。
- 修复命令在 Terminal 中可用，但 ACP Agent、Claude Code、Codex CLI、Tasks 或 Debug 中提示找不到的问题。
- 修复 ACP Server 未获得完整远程环境，导致其启动的子进程缺少用户配置的问题。
- 修复 SSH 重连后继续使用旧环境或失效 `SSH_AUTH_SOCK` 路径的问题。
- 修复包含空格、换行或 Shell 特殊字符的环境变量无法可靠继承的问题。

## 1.1.5 · 2026 年 9 月 6 日

本次更新让移动开发闭环更加完整：可以并排打开两个文件、预览 Web 项目、审查 Git 变更，并让终端与 AI 在长时间使用中保持可靠。

### 新增

- **应用内浏览器预览。** 无需离开工作区即可打开本地或远程 Web 项目，也可从终端 URL 直接进入预览。
- **编辑器双栏分屏。** 并排查看和编辑两个文件，每个分栏保留清晰的标签与导航状态。
- **内置媒体预览。** 直接检查图片，并在应用内播放支持的音频和视频。
- **更丰富的 AI 工作区。** AI Chat 展示最近任务和工作区上下文；紧凑的全局状态条让 Agent 在跨面板时仍清晰可见。
- **可选的编辑器 AI 工具。** 可按自己的工作流决定是否启用 AI 工具栏。
- **开源许可证说明。** 设置中新增开源软件许可证与版权归属信息。

### 改进

- **更可靠的远程开发。** 强化 SSH 连接处理，并通过连接复用降低远程命令与预览连接开销。
