# NimoteCode 支持

请选择需要解决的问题。联系时请提供设备、应用版本、安全的问题描述和错误信息；请勿发送密码、私钥或 API Key。

## 常见支持入口

<div class="product-card-grid">
  <div class="product-card"><strong>SSH 连接问题</strong><span>检查 host、port、username、认证方式和网络可达性。建议从已保存的配置开始，并运行 <code>pwd</code> 等无风险命令。</span></div>
  <div class="product-card"><strong>AI Provider 或 API Key</strong><span>确认 base URL、模型名称和 Provider 账户权限。NimoteCode 使用 BYOK，模型访问与计费由 Provider 决定。</span></div>
  <div class="product-card"><strong>恢复 Pro</strong><span>使用购买时的账户登录，确认商店订阅仍有效，然后在应用中使用恢复购买入口。</span></div>
  <div class="product-card"><strong>订阅或账户</strong><span>如有计费、取消、登录、隐私或删除问题，请联系支持并提供适用的平台和购买/账户邮箱。</span></div>
</div>

## 联系支持

账户、订阅和私密支持请求请发送至 [nimotecode@gmail.com](mailto:nimotecode@gmail.com)。可复现的产品问题和功能建议请使用 [GitHub Issues](https://github.com/mobiledevloperlab/nimote_issues/issues)。紧急访问问题通常在 1–2 个工作日内回复，常规请求通常在 2–3 个工作日内回复。

隐私或账户删除请查看[隐私政策](/zh/privacy)和[账户删除](/zh/account-delete)，并仅提供处理请求所需的信息。
