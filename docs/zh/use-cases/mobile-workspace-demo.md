# 移动工作区演示

这段工作流展示 NimoteCode 如何把日常开发闭环带到手机上。无论从本地项目开始，还是连接 SSH 工作区，文件、编辑器、终端和 Source Control 都围绕同一个项目保持关联，让检查到交付的每一步都不必切换工具。

## 聚焦的移动开发闭环

1. 打开本地项目，或连接目标 SSH 主机与项目根目录。
2. 检查相关文件，再在编辑器中完成聚焦修改。
3. 在终端中查看日志、运行测试或验证改动后的行为。
4. 在提交或交付前，通过 Source Control 审查产生的 diff。

它适合离开工位时完成真实且范围明确的工作，但不会替代项目本身要求的评审、权限控制和验证步骤。
