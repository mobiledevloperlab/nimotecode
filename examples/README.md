# NimoteCode Examples and Workflows

These are operational outlines, not sample application code. They use no private API, invented command, or claim that a tool is bundled. Adapt each to the commands and access policy of your own project.

| Workflow | When to use it |
| --- | --- |
| [SSH remote development](ssh-remote-development/README.md) | Work on a project that remains on a workstation, server, or VPS |
| [Android Local Linux](android-local-linux/README.md) | Prepare a small local Ubuntu-based environment on supported Android |
| [Claude Code over SSH](claude-code-over-ssh/README.md) | Use a host-installed Claude Code session from a phone |
| [Codex over SSH](codex-over-ssh/README.md) | Use a host-installed Codex session from a phone |
| [Mobile development workflow](mobile-dev-workflow/README.md) | Follow a safe inspect-edit-test-review loop |

Read the [mobile development resources](../resources/README.md) for background and the [NimoteCode docs](https://nimotecode.com/docs/quick-start) for product setup.
